## 1. 축소법 — 능형회귀·라쏘 (A급 집중, 7~8차시)

**Q1 [A·유도] 1차원 라쏘 (y − β)² + λ|β| 를 최소화하는 β̂를 경우를 나눠 구하라. (교수님: "이거 여기서 한번 풀어보세요 — 손으로 풀 수 있는 세팅")**
- 답안 핵심: ① |β|의 미분은 sign(β)(β ≠ 0). ② β > 0: −2(y − β) + λ = 0 → β̂ = y − λ/2, 성립 조건 y > λ/2. ③ β < 0: β̂ = y + λ/2, 조건 y < −λ/2. ④ −λ/2 ≤ y ≤ λ/2이면 β̂ = 0 (목적함수가 0에서 꺾여 최소). ⑤ 종합: β̂ = sgn(y)(|y| − λ/2)₊ — soft thresholding. 작은 값은 0으로 지우고 큰 값은 λ/2만큼만 줄인다(변수 선택의 원리). ⑥ 비교: 능형 (y − β)² + λβ² → β̂ = y/(1 + λ), 비율로 줄이고 0이 되지 않음.
- 흔한 실수: 문턱을 λ로 씀(손실이 ½(y − β)²이면 문턱 λ, (y − β)²이면 λ/2 — 식을 먼저 밝힐 것). 숫자 예: λ = 4, y = −1.5 → 0, y = 5 → 3.
- 근거: 8차시 §2.12(판서 20:46–20:47, 녹음3 00:00·00:57), 교재 식 (6.15) · 모범답안: 예상문제 모음 6부 Q9·Q22·Q24.
- 프롬프트: Q1.

**Q2 [A·유도·계산] 관측 하나 y = β + ε, Var(ε) = σ²에서 (y − β)² + λβ²의 해, 기댓값·분산·MSE, 최적 λ를 구하라.**
- 답안 핵심: ① β̂ = y/(1 + λ). ② E(β̂) = β/(1 + λ) → 편향 −λβ/(1 + λ)("shrinkage 때문에 bias가 생긴다"). ③ Var(β̂) = σ²/(1 + λ)² (OLS의 σ²보다 작음). ④ MSE = (λ²β² + σ²)/(1 + λ)². ⑤ dMSE/dλ = 0 → λ* = σ²/β² > 0 — 적당한 축소는 항상 OLS(λ = 0)보다 MSE가 작다. ⑥ β = 2, σ² = 1이면 λ* = 0.25, MSE = 0.16 + 0.64 = 0.80 < 1. ⑦ λ*가 모르는 β·σ²에 달려 있으니 "매 문제마다 풀 수 없어 CV로 고른다".
- 흔한 실수: 분산을 σ²/(1 + λ)로 씀. λ → ∞이면 β̂ → 0(편향 최대, 분산 0).
- 근거: 8차시 §2.8(판서 20:13, 녹음2 28:21–30:20) · 모범답안: 예상문제 모음 6부 Q21.
- 프롬프트: Q2.

**Q3 [A·유도] 능형회귀 목적함수 (Y − Xβ)ᵀ(Y − Xβ) + λβᵀβ를 미분해 닫힌 해를 구하고, λ = 0·λ → ∞의 극한과 p > n에서의 의미를 쓰라.**
- 답안 핵심: ① ∂/∂β = −2Xᵀ(Y − Xβ) + 2λβ = 0 → (XᵀX + λI)β = XᵀY → β̂ᴿ = (XᵀX + λI)⁻¹XᵀY. ② 2계 도함수 2(XᵀX + λI)가 양정치 → 유일한 최소. ③ λ = 0 → OLS, λ → ∞ → β̂ → 0(절편은 벌하지 않으므로 ȳ만 남음). ④ XᵀX의 고윳값 dⱼ²에 λ가 더해져 dⱼ² + λ > 0 → p > n이어도 역행렬 존재, 해 유일(OLS는 불가). ⑤ 해 경로: λ가 커지며 계수가 0 쪽으로 가지만 "중간에 0을 터치하지 않는다".
- 흔한 실수: 절편까지 벌점에 넣음. 표준화 없이 적합(→ Q6).
- 근거: 8차시 §2.6(판서 19:54), 7차시 §2.12, 교재 p.215 · 모범답안: 예상문제 모음 6부 Q8·Q20.
- 프롬프트: Q3.

**Q4 [A·서술·그림] 능형·라쏘의 제약 형태와 벌점 형태를 쓰고 라그랑지안으로 연결하라. 왜 라쏘만 계수를 정확히 0으로 만드는지 p = 2 그림으로 설명하라.**
- 답안 핵심: ① 제약형 min RSS s.t. Σβⱼ² ≤ s(원) / Σ|βⱼ| ≤ s(마름모) ⟺ 벌점형 min RSS + λΣβⱼ² / RSS + λΣ|βⱼ|. ② 라그랑지안: "제약조건이 있는 최적화를 제약 없는 다른 형태로 바꾸는 것" — 각 s마다 같은 해를 주는 λ ≥ 0이 있다. s↑ ⟺ λ↓; s ≥ ‖β̂_OLS‖이면 λ = 0. ③ 그림: OLS 해를 중심으로 한 타원형 RSS 등고선을 키워 가며 허용 영역과 **처음 닿는 점**이 해. ④ 마름모는 꼭짓점(한 좌표가 0)이 축 위에 있어 등고선이 꼭짓점에 먼저 닿을 확률이 n이 커져도 0으로 가지 않는다 → 정확한 0 → 자동 변수 선택(sparse). 원은 모서리가 없어 0이 아닌 점에서 접함 → 능형은 "0에 가까이 갈 뿐 0이 되지 않는다". ⑤ 좌표축만 허용(십자가) = best subset, 변이 볼록한 마름모 = elastic net.
- 흔한 실수: "s가 크면 λ도 크다"(반대). 제약형과 벌점형의 해가 다르다고 씀(동치).
- 근거: 7차시 §2.11–2.13(판서 21:07·21:11, 녹음3 23:58–26:14, 55:33–58:08), 8차시 §2.5(판서 19:24·19:33), 교재 p.220–222 · 모범답안: 예상문제 모음 5부 Q33–Q34, 6부 Q7, 7부 Q28.
- 프롬프트: Q4.

**Q5 [A·서술] 계수에 제약을 걸면 왜 예측이 좋아질 수 있는가? 편향–분산으로 설명하라. ("세상에 공짜가 없습니다")**
- 답안 핵심: ① OLS는 불편이지만 p가 n에 가깝거나 상관이 높으면 분산 폭발. ② 계수를 원점 근처 영역에 가두면 분산이 크게 줄고 대신 편향이 생긴다("무조건 좋은 게 생기면 나쁜 게 뭔지 봐야 하는 게 모든 methodology의 기본"). ③ 기대 검정 MSE = 편향² + 분산 + σ²이므로 분산 감소 > 편향² 증가이면 이득 — 교재 Fig 6.5의 U자(λ에 따른 MSE). ④ n = 50, p = 45처럼 p ≈ n이면 OLS가 null 모형만큼 나쁘고 축소의 이득이 큼. ⑤ 두 단계 변환: (1) 제약으로 다른 문제(답이 달라짐) (2) 라그랑지안으로 동치인 벌점 문제(답 같음).
- 근거: 7차시 §2.11(녹음3 15:11–16:41), 8차시 §2.5·§2.8, 교재 p.218 Fig 6.5 · 모범답안: 예상문제 모음 5부 Q34(a).
- 프롬프트: Q5.

**Q6 [A·유도·실습] 척도 동변성(scale equivariance)을 정의하고 OLS에서는 성립하지만 능형에서는 깨짐을 보여라. 그 결과와 해결책(표준화 식, 범주형, glmnet vs scikit-learn)을 쓰라.**
- 답안 핵심: ① 설명변수를 c배 하면 계수가 1/c배가 되고 예측은 그대로인 성질. OLS: (XᵀX)⁻¹XᵀY에서 X → cX이면 β̂ → β̂/c(상쇄). ② 능형: (c²XᵀX + λI)⁻¹cXᵀY — λ가 상쇄되지 않아 실효 벌점이 λ/c²로 바뀜 → 단위(m/cm) 선택이 어떤 변수를 얼마나 줄일지를 정한다. 실습: 키 m→cm에서 OLS 예측 차이 2.8e-14, 표준화 안 한 능형은 최대 6.39. ③ "작은 계수를 보고 그 변수가 안 중요하다고 오해". ④ 해결: 표준화 x̃ᵢⱼ = xᵢⱼ/√((1/n)Σᵢ(xᵢⱼ − x̄ⱼ)²)(중심화 포함) 후 적합. ⑤ glmnet은 기본 standardize = TRUE로 적합 후 원래 단위로 되돌려 줌; scikit-learn은 안 하므로 make_pipeline(StandardScaler(), Ridge/Lasso). ⑥ 범주형은 0/1 가변수로 넣고 역시 표준화("fair하게").
- 근거: 8차시 §2.6(노트 p.12 손글씨, 녹음2 06:42–14:43), 교재 p.217 식 (6.6) · 모범답안: 예상문제 모음 6부 Q10·Q23, 7부 Q30·Q35.
- 프롬프트: Q6.

**Q7 [A·서술·실습] 조절모수 λ는 왜·어떻게 고르는가? 절차를 쓰고, 패키지·AI가 정한 λ 격자의 함정과 대처를 쓰라.**
- 답안 핵심: ① λ는 모형의 모수가 아니라 연구자가 정하는 값 — RSS + λP(β)를 β와 λ에 대해 함께 최소화하면 P ≥ 0이라 항상 λ = 0(OLS) → 바깥 기준(예측 성능)이 필요 → CV("모르면 일단 CV"). ② 절차: 넓은 로그 간격 λ 격자 → 각 λ에서 K-fold CV 오차 → 곡선이 "내려갔다 올라오는" 최솟값 λ(또는 1-SE 규칙) → 그 λ로 **전체 자료 재적합** = 최종 모형. ③ CV 곡선이 U자인 이유 = 편향–분산. ④ 함정: 패키지가 범위를 좁게 정해(RidgeCV 기본 0.1·1·10) 최솟값이 격자 끝에 걸려도 **오류가 뜨지 않는다** → "항상 의심". 실습: λ = 10(격자 끝) → 넓히자 47.6, 검정 MSE 51.0 → 45.6. ⑤ 대처: "λ 범위를 아주 넓게 잡아 U자를 놓치지 않게 해 줘", "CV 곡선을 보여 줘", 끝에 걸리면 범위 확대 후 재실행. ⑥ AIC·BIC로도 고를 수 있어 빠르지만(σ² 필요, 자유도 정의) 범용은 CV.
- 근거: 7차시 §2.12(녹음3 27:51–30:27), 8차시 §2.7·§2.16, 6-4 실습 Q34 · 모범답안: 예상문제 모음 6부 Q12·Q14, 7부 Q32·Q34.
- 프롬프트: Q7, 코드는 P6.

**Q8 [A·비교] sparse / dense 설정을 정의하고 각각 라쏘·능형 중 무엇이 유리한지, 모를 때는 어떻게 하는지, oracle property가 무엇인지 쓰라.**
- 답안 핵심: ① sparse = 몇 개 계수만 크게 0이 아니고 나머지는 0(희귀 유전질환의 한두 변이); dense = 많은 변수가 조금씩 기여(당뇨 같은 common disease). ② sparse → 라쏘(불필요한 것을 날림, 0인 변수를 미리 알고 버린 뒤 적합한 것과 같은 **oracle** 성능); dense → 능형(버리지 않고 분산을 잡음). 교재 Fig 6.8(45개 모두 관련 → 능형 우세)·6.9(2개만 → 라쏘 우세). ③ "몇 개부터 sparse냐는 규칙은 없다" — 보통 모르므로 **둘 다 돌려 CV 오차가 낮은 쪽**. ④ 실습 100회: sparse에서 라쏘 11.0 < 능형 14.6 < OLS 18.2, dense에서 능형 13.8 < 라쏘 14.9 < OLS 18.9(σ² = 9가 하한). ⑤ 라쏘가 상관된 묶음에서 하나만 남기는 한계 → elastic net(개념).
- 근거: 8차시 §2.9(판서 20:20, 녹음2 31:31–36:40), 6-4 실습 Q36 · 모범답안: 예상문제 모음 6부 Q11, 7부 Q31·Q36.
- 프롬프트: Q8.

**Q13 [A·서술] AIC와 BIC를 −2logL 꼴로 쓰고, 철학(참 모형 가정·목표)과 이론적 근거를 비교하라. BIC가 더 단순한 모형을 고르는 이유와 "두 장점을 모두 갖는 기준은 없다"의 뜻을 쓰라.**

**Q14 [A·유도] AIC 유도의 큰 그림: KL 발산에서 출발해 공통항 상쇄 → 로그가능도 비교 → 낙관 편향 ≈ p → AIC = −2ℓ(θ̂) + 2p까지 단계별로 설명하라. KL이 거리가 아닌 이유와 분포족이 다른 모형 비교 가능성도 쓰라.**

MLE = KL 최소화 추정량. ② 같은 g로 재므로 정규 vs 감마처럼 분포족이 달라도 비교 가능(단 같은 반응 척도 — 변환하면 자코비안). ③ KL은 비대칭이고 삼각부등식이 없어 distance가 아니다("divergence"). ④ θ̂를 같은 자료로 고르고 평가하면("y를 두 번 쓴다") ℓ(θ̂)는 낙관적 — 편향 b = E[ℓ(θ̂)] − nη. 두 번의 2차 테일러 전개(θ₀ 주위, θ̂ 주위)의 이차형식이 크기 같고 부호 반대 → b ≈ tr(J⁻¹I); 모형이 맞으면 정보 항등식 I = J → b ≈ p("이 항등식이 2p가 나오는 곳"). ⑤ 로그가능도 척도에서 p, −2배 척도에서 2p → AIC. 오지정이면 TIC = −2ℓ + 2tr(Ĵ⁻¹Î)(실제로 AIC와 거의 안 다름), 소표본(n/p < 40)이면 AICc. ⑥ AIC는 상대적 기준: 후보가 모두 garbage면 고른 것도 garbage.

**Q21 [A·서술] 유전자 5000개·환자 50명에서 "전체 자료로 상관 상위 100개 선별 → 로지스틱 → 5-fold CV"가 왜 틀렸는지, 올바른 절차와 최종 모형, 무관한 변수일 때 두 방식의 CV 오류(정답 0.5)를 쓰라. ("퀴즈입니다 — 한번 생각해 보세요")**
- 답안 핵심: ① 선별 단계에서 나중에 평가할 fold의 레이블이 이미 쓰임 → information leakage → 대원칙("평가 자료는 학습에 절대 사용 금지") 위반 → "모두 다 틀린 방식, 무조건 reject". ② 올바름: fold마다 훈련 40명만으로 선별 + 적합, 떼어 둔 10명으로 평가 × 5 — "모든 step이 CV 안쪽에"; fold마다 선별 변수가 달라도 정상(평가 대상 = 절차 전체). ③ 최종 모형: 고른 절차를 **전체 자료에 다시 적합**; 선별 기준까지 튜닝하면 nested CV. ④ 무관한 난수 변수면 올바른 CV ≈ 0.5, 틀린 CV ≈ 0(전체판 모의실험 0.00–0.01 vs 0.52–0.54). ⑤ 사례: Nature 2001 등 "싹 다 틀렸다", Ambroise & McLachlan(PNAS 2002) — "이 페이퍼 하나만 기억".

**Q22 [A·유도·서술] k-fold CV 식, LOOCV의 지름길 공식과 성립 조건, K 선택의 편향–분산을 쓰라(교재 기준으로 쓰되 강의 표현과의 차이를 밝혀라).**
- 답안 핵심: ① CV₍ₖ₎ = Σₖ (nₖ/n)·MSEₖ = (1/n)Σᵢ(yᵢ − ŷ₋ₖ₍ᵢ₎)² — 모든 관측이 정확히 한 번 검증(cross); 분류는 I(yᵢ ≠ ŷᵢ). ② LOOCV = n-fold: 분할의 randomness가 없어 "누구라도 똑같은 결과", 대신 n번 적합. ③ 지름길: 최소제곱(가우시안 선형·다항회귀)에서만 CV₍ₙ₎ = (1/n)Σ[(yᵢ − ŷᵢ)/(1 − hᵢ)]², hᵢ = hat 행렬 대각(레버리지) → 한 번 적합. 이진·카운트에는 없고 그 근사가 AIC("AIC는 LOOCV를 빨리 한 것"). ④ 교재: K↑(LOOCV) → 편향↓·분산↑(훈련셋이 거의 겹쳐 적합 간 상관)·계산↑; K↓(2) → 편향↑ → K = 5·10이 절충. 강의는 "LOOCV는 variance가 없고 bias가 크다"고 표현했는데 '분산 없음'은 분할의 무작위성이 없다는 뜻 → 답안은 교재 방향으로 쓰고 결론(5·10)은 같다고 밝힘. ⑤ CV 값은 최종 예측오차가 아니라 최솟값의 **위치**만 믿는다; 10-fold는 seed가 달라도 같은 모형을 고른다.
- 근거: 7차시 §2.2–2.3(판서 18:49, 녹음1 07:34–25:30), 6차시 §2.14, 교재 식 (5.2)·(5.3), p.183–184 · 모범답안: 예상문제 모음 5부 Q36, 4부 Q37, 4부(7차시) Q1–Q3·Q17.

**Q24 [A·계산·서술] 부트스트랩 표본으로 학습하고 전체 자료로 평가하면 왜 안 되는가? (1 − 1/n)ⁿ을 계산하고 OOB와 결론(예측오차는 CV)을 쓰라.**

## 4. 분류기 성능 평가 (5~6차시)

**Q27 [A·유도] AUC = c-통계량 P(S_D > S_D̄)임을 증명하라. 세로 띠의 높이·너비, 전확률 법칙이 쓰이는 단계, 그리고 "AUC는 rank에만 의존"이 따라오는 이유를 쓰라. ("고등학교 구분구적법이면 된다")**
- 답안 핵심: ① c = P(S_D > S_D̄) + ½P(S_D = S_D̄)(동점 ½은 이산 점수의 technical한 약속); 표본에서는 concordant pair 비율(예 13/16 = 0.8125) = Mann–Whitney U/(n₁n₀). ② ROC = 임계값 s를 훑으며 (FPR, TPR) = (P(S_D̄ > s), P(S_D > s)). ③ 아래 면적을 세로 띠로 자르면 높이 = TPR(s) = P(S_D > s), 너비 = dFPR = f_D̄(s)ds("D가 아니라 D bar — 확대해서 보세요"). ④ AUC = ∫ P(S_D > s) f_D̄(s) ds = ∫ P(S_D > s | S_D̄ = s) f_D̄(s) ds(두 점수 독립) = P(S_D > S_D̄)(전확률 법칙 — 한쪽을 s로 고정하고 모두 더함). ⑤ 확률은 부등호만 쓰므로 점수에 단조변환(+5, ×2)을 해도 불변 → rank-based measure → 보정에 눈먼 한계로 이어짐.

**Q28 [A·서술] discrimination과 calibration의 차이, AUC의 네 가지 한계(교수님이 "3번이 굉장히 중요"), 그리고 보고할 지표 세트를 쓰라.**
- 답안 핵심: ① 판별 = 환자·비환자 점수가 얼마나 분리되나(AUC); 보정 = 점수 0.2인 사람들의 실제 발병률이 0.2인가 — 모든 확률에 0.5를 더하면 AUC는 그대로지만 보정은 깨짐; 확인은 10등분 보정 플롯(y ≈ x), Brier score. ② 한계: (1) 보정에 눈멂 (2) 임상에서 안 쓰는 임계값까지 전 구간 평균(부분 AUC) (3) **증분이 작다** — odds ratio가 큰 변수를 넣어도 순위가 안 바뀌면 ΔAUC ≈ 0.01 → AUC 증분으로 변수 중요도 평가는 위험 (4) 오류 비용·유병률 무시. ③ 학습 손실(cross-entropy)과 평가지표(AUC)의 불일치 = "철학적 issue" → 실용: 민감도·특이도·PPV·NPV·F1·보정을 세트로 보고(TRIPOD), 유병률 낮은 문맥에서 PPV·F1이 낮은 것은 설명.

**Q29 [A·계산] 민감도 0.99·특이도 0.98인 검사의 PPV를 Bayes 정리로 전개하고 유병률 10%, 1%, 1/1000, 10만 명당 10건에서 계산하라. 왜 민감도·특이도는 유병률과 무관한데 PPV·NPV는 아닌가?**

## 5. 분류 모형 — 로지스틱·판별분석·naive Bayes (3~5차시)

**Q32 [B·유도·서술] 로지스틱 회귀에서 0-1 손실 → 우도 → −log 우도(cross-entropy) → 경사법/Newton–Raphson으로 이어지는 흐름을 쓰고, odds ratio 해석과 confounding 예(student 계수 +0.40 → −0.65)를 설명하라.**
- 답안 핵심: ① p(X) = e^{β₀+β₁X}/(1 + e^{β₀+β₁X}), logit = β₀ + β₁X; OR = e^{β₁}(X 1 증가 → odds e^{β₁}배). ② 0-1 손실은 계단함수라 미분 불가 → 대리(surrogate) 손실: 베르누이 우도 Π pᵢ^{yᵢ}(1 − pᵢ)^{1−yᵢ} → −ℓ = −Σ[yᵢ log pᵢ + (1 − yᵢ)log(1 − pᵢ)] = cross-entropy, β에 볼록, 닫힌 해 없음. ③ 경사법 β ← β − η∇(−ℓ), η = learning rate("art"); Newton–Raphson β ← β − [∇²ℓ]⁻¹∇ℓ(IRLS). SE = 정보행렬 역행렬 대각의 제곱근 → z = β̂/SE. ④ confounding: student 단독 +0.4049이지만 balance를 넣으면 −0.6468 — 학생은 balance가 높아서 default가 많아 보였을 뿐, 같은 balance에서는 덜 default. ⑤ 다범주는 다항(multinomial) 우도 → softmax; "통계의 우도에 로그 취하고 마이너스 붙여 loss로 보고 gradient로 최소화 — 신경망도 같다".

**Q33 [A·유도] 환자-대조군 자료에 로지스틱 회귀를 적합하면 무엇을 믿을 수 있고 무엇을 믿으면 안 되는가? 선택지표 S로 증명하라. ("70·80년대 역학·보건통계의 역사적으로 가장 중요한 결론 중 하나")**
- 답안 핵심: ① S = 1(분석에 포함) 도입; 환자-대조군의 핵심 가정 P(S=1|y, x) = P(S=1|y) — 선택이 y에만 의존하고 x에는 의존하지 않음. ② P(y=1|x, S=1) = P(S=1|y=1)p(y=1|x) / [P(S=1|y=0)p(y=0|x) + P(S=1|y=1)p(y=1|x)]; 분자·분모를 P(S=1|y=0)p(y=0|x)로 나누면 c·e^{β₀+β₁x}/(1 + c·e^{β₀+β₁x}), c = P(S=1|y=1)/P(S=1|y=0) → e^{(β₀ + log c) + β₁x}: **절편만 log c만큼 이동, 기울기 불변**. ③ 믿을 것: 기울기 = log OR, z·p-value; 믿으면 안 되는 것: 절편·예측확률(½ 규칙 닫힘). ④ 유병률 π를 알면 절편 복원 β̂₀* = β̂₀ + log[π/(1 − π)] − log[π̃/(1 − π̃)](남아공 자료: 환자 비율 0.346, 유병률 0.051 → ≈ −2.32). ⑤ "1 + exp라는 특수한 꼴" 때문에 로지스틱만 가능(일반 회귀·랜덤포레스트·부스팅은 보존 안 됨); 코호트는 시간·비용, 환자-대조군은 논리를 뒤집는 설계; 대조군은 환자의 약 5배까지 이득.

**Q34 [A·유도] 2클래스·p = 1·공통분산에서 Bayes 분류기(사후확률 ≥ ½)로부터 LDA 판별점수 δₖ(x)를 유도하라. 어떤 항이 왜 사라지며 분산이 다르면 무엇이 달라지는가? 모수 추정식과 "왜 로지스틱 대신 판별분석인가"(complete separation)도 쓰라.**
- 답안 핵심: ① Bayes 정리: P(Y=k|x) = πₖfₖ(x)/Σₗπₗfₗ(x); ½ 규칙 ⟺ π₁f₁(x) ≥ π₀f₀(x) ⟺ f₁/f₀ ≥ π₀/π₁(사전확률 같으면 밀도 높이 비교). ② fₖ = N(μₖ, σ²) 대입 후 로그: log πₖ − ½log(2πσ²) − (x − μₖ)²/(2σ²); 양변 공통인 −½log(2πσ²)와 x²/(2σ²)이 지워짐 → δₖ(x) = x·μₖ/σ² − μₖ²/(2σ²) + log πₖ(x의 1차식 = Linear). 경계: π 같으면 (μ₁ + μ₂)/2. ③ 분산이 다르면 log σₖ²·x²/σₖ² 항이 남아 2차식 → QDA("σ²은 경계의 복잡도를 조절"). ④ 추정: π̂ₖ = nₖ/n, μ̂ₖ = 클래스 평균, σ̂² = ΣₖΣᵢ(xᵢ − μ̂ₖ)²/(n − K)(평균 개수만큼 자유도 보정). 덧셈·뺄셈만으로 구해져 수십억 건도 가능(로지스틱은 역행렬 n³). ⑤ complete separation: x의 어떤 경계로 y가 완전히 갈리면 로지스틱 우도가 β → ±∞로 "박살" — 계수·신뢰구간이 터무니없이 커짐(rare outcome에서 흔함); 판별분석은 y별로 X 분포를 따로 적합하므로 이런 일이 없음. ⑥ 로지스틱 = p(y|x) 직접(X 분포 불필요, 생성 불가) vs 판별분석 = p(x|y)·p(y)(생성형, X 분포가 맞아야). 교수님: "LDA·QDA는 실무에서 거의 안 쓰고 naive Bayes를 이해하기 위한 순서".

## 6. 기초 — 통계적 학습·편향–분산·선형회귀 (1~3차시)

**Q37 [A·유도] 기대 검정 MSE의 편향–분산 분해를 유도하라. 어떤 가정이 필요하고 교차항은 왜 사라지는가? ("연습 삼아서라도 유도를 해 보세요. 꼭 필요하다고 생각합니다")**
- 답안 핵심: ① 설정: y₀ = f(x₀) + ε, E(ε) = 0, Var(ε) = σ², ε은 훈련자료로 만든 f̂과 독립(x₀는 훈련에 쓰지 않은 점). ② m = E[f̂(x₀)]로 두고 y₀ − f̂ = ε + (f − m) + (m − f̂)로 쪼개 제곱: E(y₀ − f̂)² = σ² + (f − m)² + E(m − f̂)² = Var(ε) + Bias² + Var(f̂). ③ 교차항: E[ε(f − f̂)] = 0(독립·평균 0), (f − m)E(m − f̂) = 0(m의 정의), E[ε(m − f̂)] = 0. ④ 기댓값은 "같은 분포에서 훈련셋을 반복 추출해 x₀에서 평가"한 평균; 모든 x₀에서 평균하면 교재 Fig 2.12의 곡선. ⑤ 해석: 유연할수록 편향↓·분산↑ → U자("U shape이 universal"), 필요한 변수가 다 들어온 뒤에는 분산만 늘어남; σ²는 환원 불가능한 하한. ⑥ 1차시의 "최적 예측자 E[Y|X]" 유도와 같은 완전제곱 + 교차항 소거 기법.
- 근거: 2차시 §2.6(노트 p.36, 녹음3 11:17–13:54), 3차시 §2.1, 교재 식 (2.7) · 모범답안: 예상문제 모음 1부(2차시) 서술형.

**Q38 [C·서술] Y = f(X) + ε에서 f를 왜 추정하는가(prediction vs inference)? 환원·비환원 오차를 쓰고 제곱오차 아래 최적 예측자가 E[Y|X]임을 보여라.**

**Q39 [C·비교] parametric vs non-parametric, KNN 회귀와 차원의 저주, 유연성–해석력 trade-off를 설명하라.**
- 답안 핵심: ① 모수적: f의 형태를 가정(선형) → 계수 추정으로 축소; 적은 자료·해석 쉬움, 형태가 틀리면 나쁨. 비모수적: 형태 가정 없음(spline, KNN); 넓은 f를 맞추지만 많은 자료 필요. ② KNN 회귀 f̂(x₀) = (1/K)Σ_{N₀} yᵢ; K 작을수록 유연(훈련오차↓, 분산↑). ③ 차원의 저주: p ≤ 4·N 큼이면 잘 되지만 고차원에서는 이웃이 멀어짐 — 10차원에서 자료의 10%를 잡으려면 각 좌표의 80%를 덮음; 독립 N(0,1) 성분이면 d(X, 0) ≈ √p, d(X, Y) ≈ √(2p), 각 ≈ 90° → "가깝다"가 의미를 잃음. ④ 유연할수록 해석력↓(subset/lasso → OLS → GAM/trees → bagging/boosting/SVM); 예측만 목적이어도 단순한 모형이 과적합을 피해 더 정확할 때가 많음; "표본 수에 따라 허용되는 복잡도가 제한 — 희귀 질환일수록 단순한 모형".

**Q40 [C·서술] 훈련 MSE vs 검정 MSE, 과적합의 뜻, Bayes 분류기와 Bayes 오류율, KNN 분류, double descent를 한 줄씩 설명하라.**

**Q41 [C·비교] 선형회귀를 보는 두 관점(true model vs projection), likelihood와 MLE = OLS, Fisher 정보, 경사하강 → 신경망("One idea, many models")을 설명하라.**
- 답안 핵심: ① True model view: E(Y|X) = xᵀβ가 실제 생성 메커니즘, β는 참값 — 통계학(검정·CI); projection view: β* = argmin E(Y − Xᵀb)² 최선의 선형 근사 — 기계학습(예측). "참 관계가 선형이라고 믿는 일은 드물다"(교재 각주). ② L(β) = Π(2πσ²)^{−1/2}exp{−(yᵢ − xᵢᵀβ)²/2σ²}; log → const − RSS/(2σ²) → MLE = OLS; 로그가능도의 곡률(−2계 미분) = Fisher 정보 = XᵀX/σ² → Var(β̂) = σ²(XᵀX)⁻¹ → s.e.·CI·검정은 모두 우도에서. ③ ML은 분포 대신 손실(제곱오차)을 최소화; "통계의 −log 우도 = ML의 loss"; hinge loss처럼 분포에 대응하지 않는 손실도 있음. ④ 경사하강 β ← β − η∇RSS, ∇RSS = −2Xᵀ(y − Xβ); 같은 손실에 비선형 층을 쌓으면 신경망; 로지스틱 → cross-entropy → softmax도 같은 틀. ⑤ Ch.3 나머지(추론·변수선택·R²·KNN 비교)는 "이미 끝난 것"으로 교재 자습.
- 근거: 3차시 §2.3–2.6(판서 19:26·20:08), §2.9 · 모범답안: 예상문제 모음 1부·2부(3차시).
- 프롬프트: Q41.

**Q42 [B·서술] "문헌을 볼 때 가장 먼저 확인할 것은 loss function"이라는 말의 뜻을 설명하고, 0-1 손실·제곱오차·cross-entropy·hinge가 각각 어떤 문제의 정의인지 쓰라.**
- 답안 핵심: ① 손실함수는 "연구자가 문제 자체를 정의하는 것" — 어떤 오차를 줄이려 하는지가 곧 방법의 목표; 같은 자료도 손실이 다르면 다른 모형이 최선. ② 제곱오차(연속, 미분 쉬움, OLS와 연결) → 최적 예측자 E[Y|X]; 0-1 손실(분류의 표준이지만 미분 불가, "무조건 써야 하는 건 아님") → Bayes 분류기; cross-entropy = 베르누이/다항 −log 우도(0-1의 대리); hinge(SVM, 분포에 대응 없음, 확률 해석 없음 — 확률 경로 vs 경계 경로의 "역사의 분기점"). ③ 손실을 "갈아 끼우면" 같은 최소화 틀(경사법)로 풀린다 — 전형적 supervised learning.
- 근거: 1차시 §2.6, 2차시 §2.5·§2.7(노트 p.30·p.37), 3차시 §2.9.
- 프롬프트: Q42.

## 8. 유형별 답안 틀

- **유도형**(Q1–Q3·Q14–Q16·Q22·Q27·Q33–Q34·Q37): 설정과 가정 → 식 세우기 → 미분/전개 → 경우 나누기 또는 항 상쇄 이유 → 결과 식 → 극한·특수 경우 확인 → 한 줄 해석(교수님 표현 인용). 기호 정의(λ, hᵢ, πₖ, c 등)를 먼저 쓰고, 어떤 손실 척도(λ/2 vs λ)인지 명시.
- **계산형**(Q2·Q10·Q15·Q18·Q24·Q29): 식 → 숫자 대입 → 중간값 → 답(단위·소수 둘째 자리) → 상식 점검(PPV는 π가 작으면 급락, 라쏘는 문턱 안이면 0).
- **서술형**(Q5·Q7·Q13·Q17·Q21·Q23·Q28): 결론 한 문장 → 이유 2~3개(번호) → 수업의 예(Credit·남아공·V23·Default) → 교수님의 결론 문장("무조건 CV", "percentile이 무조건 좋음") → 한계·주의.
- **비교형**(Q8·Q11·Q13·Q39·Q41): 표(기준 열: 가정 / 목표 / 식 / 장단점 / 언제 쓰나) → 교수님의 실무 평가 한 줄.
- **실습 해석형**(Q9·Q12, 6-4 실습): 출력에서 ① 방법 고정 ② λ 격자·곡선 ③ 표준화 ④ 재적합 ⑤ 반복·seed ⑥ 손실/벌점 기본값 순으로 점검 → 의심되는 점 → 재실행 지시 → 재해석 → AI 사용 리포트 문장.
