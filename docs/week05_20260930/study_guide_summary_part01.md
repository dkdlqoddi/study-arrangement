### 2. 핵심 개념 정리

진행 순서대로 2.1~2.9. 괄호는 전체판 슬라이드 번호.

#### 2.1 판별분석의 출발점 — likelihood 유추, p(Y|X) ⇕ p(X|Y) (S22–S25, 칠판 18:37–18:47)

목표는 하나: Bayes 분류기 1(p(Y=1|x) ≥ ½), 0-1 손실을 최소화. 로지스틱은 이 확률을 e^{xβ}/(1+e^{xβ})로 직접 모델링; 판별분석은 x, y의 자리를 뒤바꿔 도달한다 — "그래서 Bayes 정리를 활용한다고 표현" [녹음1 01:08–02:35][칠판 18:37].

likelihood 유추: θ가 주어졌을 때 y의 분포 = probability; y가 관찰된 뒤 θ의 함수 = likelihood; 둘을 오가는 사고가 Bayes식. 데이터·파라미터에 제한 없이 x, y를 오가니 Bayesian이라 부르는 관습 [노트 p.6][녹음1 02:53–04:18][칠판 18:38 "data → p(Y|θ) ⇕ p(θ|Y), likelihood/parameters"].

두 갈래: y=1일 때 x의 분포와 y=0일 때 x의 분포를 정하면 p(Y=1|x)가 완벽히 결정 → Discriminant Analysis; 직접 모델링 → Logistic Regression. "머신러닝의 두 가지 큰 갈래" [녹음1 06:23–07:10].

모델링할 것: f₁(x) = p(x|Y=1), f₀(x) = p(x|Y=0), 그리고 π₁·π₀. π는 "데이터에서 Y가 1인 비율을 그냥 갖다 쓰면 됨(plug-in)" — 크게 이슈가 아니고, 제일 중요한 파트는 밀도 f_k [노트 p.6][녹음1 08:11–08:48]. X가 성별 같은 이산 변수여도 틀은 같다 — "기술적인 거에 스스로를 가두면 메시지를 놓친다" [노트 p.6].

Bayes 규칙 유도(칠판 18:47): p(Y=1|x) = p(x|Y=1)π₁ / [p(x|Y=1)π₁ + p(x|Y=0)π₀] ≥ ½ ⇔ π₁p(x|Y=1) ≥ π₀p(x|Y=0) ⇔ p(x|Y=1)/p(x|Y=0) ≥ π₀/π₁. 사전확률이 같으면 밀도 높이 비교 f₁(x) ≥ f₀(x); 다르면(S25 π₂=.7) 큰 쪽이 유리해 경계 이동 [슬라이드 S24–S25][교재 p.138–139 (4.10)].

칠판에 X|Y=1 ~ N(μ₁,σ²), X|Y=0 ~ N(μ₀,σ²)를 상자로 써 두고 2.2로 넘어감 [칠판 18:47].

#### 2.2 LDA p=1 — 정규밀도 대입과 항 상쇄, 판별점수, 모수 추정 (S27–S30)

설정: x = BMI, k = CVD 유무. 두 그룹의 분산을 편의상 같다고 둔다 — "꼭 요구되는 조건은 아니지만, 계산을 지우려고" [노트 p.7][녹음1 09:27–10:46, 13:33].

유도(노트 "수식 놓침" 부분, 녹음1 12:53–16:25): π₁f₁(x) ≥ π₀f₀(x)에 f_k = (1/√(2πσ²))e^{−(x−μ_k)²/2σ²}를 넣고로그: log π_k − ½log(2πσ²) − (x−μ_k)²/(2σ²). −½log(2πσ²)는 양변에 같아 지움("귀찮으니까"), 전개한 x²/(2σ²) 도 양변에 같아 지움 → 남는 것 δ_k(x) = xμ_k/σ² − μ_k²/(2σ²) + log π_k, x의 1차식 = Linear DA [슬라이드 S27–S28][교재 p.140 (4.13)]. K=2, π 같으면 경계 (μ₁+μ₂)/2 [교재 (4.14)].

"튀어나온 게 아니다": 판별점수는 새 원리가 아니라 "0-1 손실 → ½ 규칙"이라는 대원칙에 정규분포를 넣어 계산한 결과 [노트 p.8][녹음1 16:30–17:20].

그림(S29): 새 사람의 BMI가 2.2면 "녹색(클래스 1)에서는 이런 x가 나오기 어렵고 핑크에서는 빈번하니 핑크로" — 밀도 높이 비교의 자동화 규칙. 정확히 가운데(확률 ½)는 현실에 없다, 동전 던져도 됨 [노트 p.8][녹음1 17:44–20:18].

QDA 예고: σ²이 다르면 log σ²·x² 항이 안 지워져 x²이 살아남아 2차식 경계 → QDA. "σ²은 경계의 복잡도를 조절하는 역할" [노트 p.8][녹음1 20:31–22:35].

교수님 평가: "practical에서 LDA·QDA는 거의 안 쓴다. 이걸 기반으로 만든 naive Bayes는 아주 많이 쓴다. LDA·QDA는 다른 걸 설명하기 위한 밑밥. 기억 안 나면 GPT한테 물어보면 요새 충분" [노트 p.8][녹음1 22:47–23:53].

모수 추정(S30): π̂_k = n_k/n, μ̂_k = 클래스 k의 x 평균, σ̂² = Σ_kΣ_i(xᵢ−μ̂_k)²/(n−K) — "평균의 개수만큼 빼 준 자유도 보정", n 크면 불필요 [노트 p.8][녹음1 24:03–25:16][교재 p.141 (4.15)].

산뜻한 formula: 덧셈·뺄셈으로 모수가 구해져 수십억 건도 편함. 로지스틱은 "20억 개 들어가면 기도해도 안 돌아간다" — 큰 행렬의 역행렬은 n³ 비용(샘플 10배 → 1000배). "큰 행렬을 빠르게 inverse하는 알고리즘을 만들면 세상이 바뀐다". 프로젝트 초반에 전체 자료를 돌리는 건 바보 — 더티하고 빠른 방법으로 윤곽부터. 딥러닝은 역행렬(Newton–Raphson) 없이 1차 미분(경사법)만 쓰는 동네 [노트 p.8][녹음1 25:20–28:30].

#### 2.3 p>1 — 왜 다변량 정규인가, GEE와 mixed effect (S31, M04, 칠판 19:22)

p>1이면 X = (X₁,…,X_p)의 결합분포가 필요. 정규분포의 벡터 버전 multivariate Gaussian — "못 들어보면 안 되는 내용" [녹음1 29:10–30:27].

다른 다변량 분포의 한계: multivariate Poisson·Bernoulli·binomial은 존재하지만 표현력이 부족 — 예: multivariate Poisson의 상관은 "음수밖에 허락이 안 된다든가, 제약이 너무 심하다". 모델링 tool로서 가치가 작다(80·90년대 이론) [노트 p.8][녹음1 31:09–31:50].

두 탈출구: ① 분포를 버리고 "어떤 equation = 0"을 푼다 → GEE; ② 조건부분포(랜덤효과)로 상관을 간접 모델링 → mixed/random effect model(multilevel, spatial 포함; 종단자료·repeated measure에서 "패키지만 돌리던" 그것) [노트 p.8–9][녹음1 31:58–33:17][칠판 19:22 "Σ S(β̂)=0, G. estimating eq."].

우도 vs 추정방정식: 우도 접근은 분포를 가정하지만 잔차(Y−Ŷ)로 모형 가정을 다각도로 점검할 길이 열림; GEE는 분포 가정이 없어도 결과가 옳다는 보장이 있지만 모형 Y=Xβ+ε 자체는 맞아야 하고 점검할 길이 없다. "훈련받은 배경에 따라 선호가 갈린다 — 한쪽만 기계적으로 보지 마라" [노트 p.1][녹음1 36:37–40:48].

"정규분포 아니면 어떡하냐 — 괜찮다, 대충 잘 된다. 해 보고 안 되면 그때 가서" [녹음1 36:01].

#### 2.4 보충 덱 「Multivariate Gaussian」 — 밀도식, Σ, 기하, 성질 (M06–M17, 칠판 19:22)

왜 보나: 새 방법이 작동하는지 이론적으로 손으로 보일 수 있는 몇 안 되는 분포. 보건통계를 할 사람은 "1+1=2처럼 완벽히 숙지", 아니면 개념만 [녹음1 34:24–35:52].

평균벡터·공분산행렬: μ = E(X)(성분마다 기댓값), Σ = E[(X−μ)(X−μ)ᵀ]. 임의의 상수벡터 z에 대해 Var(zᵀX) = zᵀΣz ≥ 0 → 양반정치(positive semi-definite); 역행렬이 있으면 양정치. "covariance matrix는 아무 행렬이나 들어오는 게 아니다"; "평생 Σ만 연구하는 분도 있다" [노트 p.2][녹음1 41:31–44:23][슬라이드 M07].

밀도식: (x−μ)²/σ² → (x−μ)ᵀΣ⁻¹(x−μ)(Mahalanobis 거리²), σ → |Σ|^{1/2}(일반화 분산 = 부피) 로 "바꿔치기": f(x) = (2π)^{−p/2}|Σ|^{−1/2} exp(−½(x−μ)ᵀΣ⁻¹(x−μ)) [노트 p.2–3][녹음1 44:30–45:14][M08–M09][교재 p.142 (4.18)].

모수 개수: Σ는 대칭이라 아래삼각은 불필요 → 대각 p + 위삼각 (p−1)+(p−2)+…+1 = p(p+1)/2, p²으로 증가. "다변량 정규의 문제는 Σ 추정에서 발생" — 40년째 연구 중("학계에는 한량이 있어야") [노트 p.2][녹음1 46:29–48:42][칠판 19:22][M09 "이 슬라이드는 중요"].

대각 Σ = 독립: 역행렬은 대각 원소의 역수, 밀도가 f(x₁)f(x₂)로 곱 분해 = 독립의 정의. "상관 0 ⇒ 독립은 정규 분포에서만; 다른 분포에서 그렇게 생각하면 틀린 것" [노트 p.3][녹음1 50:10–52:07][M11]. 이 곱 분해가 naive Bayes의 식 [추가].

기하: 등고선 = 밀도가 같은 x의 집합 = (x−μ)ᵀΣ⁻¹(x−μ) = c² 인 타원, 3차원 종을 "칼로 자른 단면". 중심은 μ, 장축·단축 방향은 Σ의 고유벡터 eᵢ, 반축 길이 c√λᵢ. 예 Σ=[[2,1],[1,2]]: λ=3,1; e₁=(1,1)/√2(장축 45°), e₂=(−1,1)/√2; 길이비 √3 [노트 p.3][녹음1 52:15–56:41][M12–M14].

네 성질: ① 선형결합 aᵀx는 정규 — 외우세요 ② 부분벡터도 정규 — 외우세요 ③ 공분산 0 ⇔ 독립(가우스에서만) ④ 조건부분포도 정규. E(Ax) = Aμ, Cov(Ax) = AΣAᵀ. "나머지는 읽어 보라" [노트 p.4][녹음1 56:54–58:27] [M16–M17].

결론: 판별분석에 필요한 건 밀도식 하나. 공통 Σ이면 xᵀΣ⁻¹x가 상쇄되어 x의 1차식(LDA), Σ_k가 다르면 2차 (QDA) — "1차원과 달라지는 게 아무것도 없다. 기분 나쁘죠? naive Bayes만 잘 알아 두라" [노트 p.2][녹음1 58:33–60:51]. δ_k(x) = xᵀΣ⁻¹μ_k − ½μ_kᵀΣ⁻¹μ_k + log π_k [S31][교재 p.142 (4.19)].

#### 2.5 "가장 힘든 파트는 Σ" → naive Bayes → Laplace 평활 (S31 후반·S42, 녹음2)

1차원에서 p차원으로 가면 클래스마다 p차원 μ_k와 p×p Σ_k가 필요할 뿐 계산 내용은 같다; 분모는 공통이라 분자만 비교 [녹음2 00:00–03:05].

질문: 가장 힘든 파트는? → Σ. μ는 p개(평균 내면 끝)지만 Σ는 p²에 비례. 변수 20개면 400에 비례하는 unknown [노트 p.9][녹음2 08:18–09:25].

유전체 자료: gene expression 5천~4만 차원, 샘플은 2~300개(2010년 무렵, 칩 1장 100만 원). 4만×4만 Σ는 불가능. 로지스틱 쪽은 LASSO·regularized regression으로 돌파(Stanford 그룹, 2010–12). 판별분석을 고집한다면? — "무대뽀 정신" [노트 p.9][녹음2 09:28–11:21].

단순화의 사다리: 모든 클래스에 공통 Σ → 그래도 5000×5000 → 특정 구조 가정 → 가장 무대뽀로 대각선만 살리고 비대각을 0으로 = naive Bayes. "왜 naive인지 이해하겠나?" 정규에서 상관 0 = 독립 → 밀도가 변수별 곱 → 모수가 p개로, Σ⁻¹는 성분별 역수. "제일 어려운 부분을 없다고 가정하는 나쁜 방식"이지만 "Σ를 올바르게 구하려는 노력보다 결과가 좋다는 게 증명" [노트 p.9][녹음2 12:11–17:45][슬라이드 S42][교재 p.149].

연구 태도: "가정하면 틀리지 않나 하며 가만있을 바에는 가정하고 풀어 본 다음 보는 것도 중요한 연구 방식"[녹음2 16:50–17:36].

혼합형 변수: 연속은 적당한 분포, 이산은 클래스 안에서 범주 빈도를 count해서 곱. 큰 역행렬이 없어 10억 건도 빈도만 세면 됨 — "quick and dirty의 선도주자", 공학 쪽에서 가장 먼저 쓰는 방법 [노트 p.9][녹음2 17:54–19:21].

Laplace 평활: 훈련자료에 없던 범주(1,2만 있고 3 없음)가 테스트에 나오면 확률 0 → 곱 전체 0. 분자·분모에 α 를 더해 (빈도+α)/(n+α·범주수)로 0을 피함. R e1071::naiveBayes(laplace=) — " ?naiveBayes 읽어 보라"

[노트 p.9][녹음2 19:26–24:16]. 폴더 NaiveBayes.txt 주석과 R 도움말의 기본값은 0이며 laplace=1 권장 [추가].

#### 2.6 K=3 땅따먹기, Fisher의 붓꽃, 확률로의 변환 (S32–S35)

K=3이면 δ₁=δ₂, δ₂=δ₃, δ₁=δ₃ 세 직선이 평면을 정확히 3등분; 새 점은 δ_k 최대 영역의 색으로. "분류 문제의 많은 것은 설명변수 공간을 땅따먹기하듯 자르는 것" [노트 p.9][녹음2 03:14–04:07][S32][교재 p.143 Fig 4.6].

Fisher: R. A. Fisher(ANOVA·randomization·p-value·sufficiency·likelihood, 현대통계학의 아버지, 우생학자이기도)가 판별분석을 개발. 붓꽃 4변수·3종·종당 50개, LDA는 150개 중 3개만 오분류. 두 종만 남기면 로지스틱이 편하지만, 판별분석은 종별로 4차원 정규를 적합해 δ를 비교. "컴퓨터로는 한 줄( lda() ) — 뭐가 돌아가는지를 지금까지 설명" [노트 p.9][녹음2 04:16–07:26][S33–S34].

확률 변환(S35): P̂(Y=k|x) = e^{δ̂_k}/Σe^{δ̂_ℓ} — softmax 형태; 이 확률이 있어야 임계값을 바꿀 수 있다 [추가].

#### 2.7 이진 분류기 성능 — 정확도의 함정, 오류 비용, 임계값 (S36, 노트 p.10, 녹음2 33:10–46:21)

"사실 굉장히 중요하다, 요새" [녹음2 33:26][노트 "중요함"]. 로지스틱·LDA·QDA 중 누구의 분류가 좋은지 말해 줘야 한다.

혼동행렬: 10,000명, 오분류 23+252 = 2.75%. 그러나 이는 적합에 쓴 자료의 훈련 오류 — "모형 평가를 이렇게 해서는 안 된다"; 테스트 자료는 적합에 쓰이면 안 됨 [노트 p.10][녹음2 34:49–36:06][교재 p.144–145].

정확도의 함정: 97.75%가 만족스러운가? default는 333명(3.33%)뿐 — "무조건 파산 안 함"이라는 최악의 분류기도 96.67%. "불균형 자료에서 정확도가 높다는 말에 현혹되지 말아라" [노트 p.10][녹음2 37:44–40:20].

#### 2.8 민감도·특이도, ROC, AUC, 임계값 선택 (S37–S39, 노트 p.11, 녹음3)

의료 문맥: 암 환자를 아니라고 하면 비용은 생명, 아닌데 암이라 하면 추가 검사 비용. 분야(community)마다 어느 오류를 우선할지 합의가 있다 — "무대포로 적용하지 말고 문맥에 따라" [노트 p.10–11][녹음3 13:27–14:57].

정의: 민감도 = P(ŷ=1|y=1) = 1−FNR(환자를 환자라고), 특이도 = P(ŷ=0|y=0) = 1−FPR(정상을 정상이라고). 정확도를 "1을 1로, 0을 0으로"로 세분한 것 [노트 p.11][녹음3 15:03–16:46][교재 p.147–149 Table 4.7].

시소: 임계값이 매우 높으면 아무도 양성 아님 → (민감도, 특이도) = (0, 1); 매우 낮으면 (1, 0). 둘을 동시에 올릴 수 없다 [노트 p.11][녹음3 16:46–18:39].

ROC: x = 1−특이도, y = 민감도. 모든 분류기가 (0,0)과 (1,1)을 지나고, (0,1)은 "신의 분류기(oracle)". 2차 대전 때 만들어진 이름 — "receiver가 왜 나오냐 따지지 마라" [노트 p.11][녹음3 18:46–21:59][S39].

원숭이 선: 무작위 추측(월드컵 맞추는 낙지)은 대각선 — 두 클래스의 점수 분포가 exact하게 같으면 임계값을 옮길 때 한쪽 면적이 커지는 만큼 다른 쪽도 올라가 기울기 1. 대각선 아래가 나오면 "원숭이보다 못할 수 없다" — 라벨을 뒤집으면 거울 대칭으로 올라오니 코딩·라벨 실수를 의심 [노트 p.11][녹음3 22:02–24:58].

교차하는 ROC와 AUC: 현실에서는 두 곡선이 교차한다. 등수를 주려면 1차원 숫자가 필요 — 고등학교 때 영어

·수학 점수를 (1,1) 방향으로 사영한 "평균"처럼("(−1,3)으로는 반에서 제일"은 농담). AUC = 곡선 아래 면적, oracle 1, 원숭이 0.5 → 0.5 ≤ AUC ≤ 1, 1에 가까울수록 좋다. "AUC도 limitation이 매우 크다 — 다음 때" [노트 p.11][녹음3 25:05–29:30][교재 p.147: Default LDA AUC 0.95].

임계값 선택: ROC 위의 점 하나하나가 임계값. 실무에서는 ① (0,1)에서 원을 그려 처음 만나는 점, ② 민감도 +특이도 최대 = 기울기 1 직선의 y절편 최대점 = Youden의 J index — 계산이 쉬워 많은 패키지의 "best threshold" 기본값 [노트 p.11][녹음3 31:01–34:00]. "오늘은 여기까지" [녹음3 34:02].
