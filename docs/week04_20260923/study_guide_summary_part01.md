### 2. 핵심 개념 정리

진행 순서대로 2.1~2.9. 괄호는 전체판 슬라이드 번호.

#### 2.1 로지스틱 회귀 모형과 링크 함수 (S04–S10)

분류: 순서 없는 집합 𝒞의 값을 갖는 Y를 예측하는 함수 C(X) ∈ 𝒞. 종종 분류 자체보다 각 범주의 확률이 더 가치 있다(보험 사기 확률) [슬라이드 S04][교재 p.127].

선형회귀가 안 되는 이유: 0/1 반응에 선형회귀를 쓰면 확률이 [0,1]을 벗어나고(S07 왼쪽 그림, 잔액 작을 때 음수), 3범주 이상을 1,2,3으로 코딩하면 순서와 등간격을 강요한다 [교재 p.129–131]. 이진이면 선형회귀 분류가 LDA와 같다는 사실은 알아 둘 것(S06, 교재 p.130).

로지스틱 함수 p(X) = e^{β₀+β₁X}/(1+e^{β₀+β₁X}): "분모가 분자보다 크니까 무조건 0과 1 사이" [녹음1 00:46]. 1−p를 구해 비를 취하면 e^{β₀+β₁X}만 남고 로그를 취하면 logit log[p/(1−p)] = β₀+β₁X — "역함수 못 구해도 상관없다, 할 일 없을 때 유도해 보라" [녹음1 01:09–01:27]. 이것이 링크 함수이고 링크의 선택이 계수 해석을 결정한다 [녹음1 01:33].

β₁ 해석: X 한 단위 증가 → log odds가 β₁ 증가, odds에 e^{β₁}배. p(X)의 변화량은 현재 X에 따라 다르며, 부호만 방향을 결정 [교재 p.132–133].

"β₀, β₁을 데이터로부터 구한다 = 학습한다 = 러닝 = estimation, 다 같은 말" [녹음1 01:46].

#### 2.2 0-1 손실 → 우도 → −log 우도 → 경사법 (S11, 칠판 18:40–18:51)

원래 목표는 0-1 손실 (1/n)Σ1(yᵢ ≠ 1(p(yᵢ=1|xᵢ) ≥ ½)) = Loss(β₀,β₁) [칠판 18:40]. 그러나 "Data 1이 되면 점프하는 순간이 된다. gradient는 최소한 한 번은 미분되어야 함" — 계단함수라 경사법 불가 [노트 p.6][녹음1 05:44–06:22].

대리(surrogate) 손실: "zero one loss는 수리적으로 까다롭기 때문에 다른 loss function들을 가짜 loss function 또는 대리 loss function이라고 부르면서 만들기 시작" [노트 p.6]. 통계 쪽 사람은 자료가 생성되는 분포를 떠올린다 — binary면 베르누이 pʸ(1−p)¹⁻ʸ(n번이면 이항분포), count면 포아송, 연속이면 가우시안 [녹음1 06:58–08:38, 15:36].

우도: 분포에 자료를 넣고 모수의 함수로 본 것. p 자리에 로지스틱 식을 넣으면 β₀, β₁의 함수 [녹음1 08:38–09:30]. 교재 (4.5): ℓ(β₀,β₁) = ∏{yᵢ=1}p(xᵢ)∏(1−p(xᵢ)) [교재 p.133]. 로그와 마이너스: "로그는 제일 큰 놈… 등수를 유지해 주는 성질" → log 우도의 최대점 = 우도의 최대점; 손실은 최소화이므로 마이너스. "statistics에서 negative log likelihood가 computer science의 loss function을 취함" [노트 p.6][녹음1 09:36–10:49]. 칠판: Loss(β₀,β₁) = (−log like) = −Σᵢ{yᵢ log pᵢ + (1−yᵢ)log(1−pᵢ)} [칠판 18:46].

손실의 직관: y=1이면 −log p → p→1이어야 작아짐, y=0이면 −log(1−p) → p→0. "Y=1인 데이터는 확률이 최대로, Y=0인 데이터는 확률이 최소가 되도록 β가 움직인다. 이 loss는 합리적" [노트 p.7][녹음1 12:37–14:22][칠판 18:51 상자].

경사법: β^{(t+1)} = β^{(t)} − η∇Loss(β^{(t)}). 초기치에서 가장 빠르게 감소하는 방향으로 조금씩 이동·반복 [노트 p.6][칠판 18:51]. 볼록이므로 MLE로 수렴 [추가]. "미분이 안 되는 함수를 제외하고는 거의 모든 최적화 문제에 쓸 수 있다. 집 가서 연습해 보세요" [녹음1 16:29–16:43].

교재 연결: 최대우도는 비선형 최소제곱보다 통계적 성질이 좋고, 선형회귀의 최소제곱은 최대우도의 특수한 경우 [교재 p.133].

#### 2.3 표준오차·z·p-value와 Newton–Raphson (S11·S14, 칠판 19:09)

"Standard error 같은 것은 −log likelihood를 두 번 미분해서 구함. 각 파라미터로 두 번 미분하면 Fisher (information). 역행렬의 대각선 성분들이 각 parameter의 (분산)" [노트 p.7][녹음1 17:32–18:34]. 칠판: F = [∂²(−loglik)/∂β₀∂β₀, ∂²(−loglik)/∂β₀∂β₁; …], F⁻¹ = 추정치의 공분산 [칠판 19:09]. 수렴점에서 F⁻¹의 대각에 루트 → 표준오차 [녹음1 21:12].

Newton–Raphson: 학습률 η 대신 "두 번 미분의 inverse를 앞에 곱해 주는 것. 뉴턴이 컴퓨터도 없던 시기에 개발". glm 내부는 정확히는 Fisher scoring, 매 iteration마다 표준오차가 자동으로 나옴 [노트 p.7][녹음1 19:50–21:04]. 경사법을 썼다면 수렴 후 마지막에 두 번 미분 행렬을 넣으면 되고, numerical derivative 함수가 있어 "glm 패키지 짜는 거 어렵지 않다" [녹음1 21:20–22:34].

z와 p-value(질문으로 확인): z = coefficient/standard error; 귀무가설 하에서 z ~ N(0,1); p = 2(1 − Φ(|z|)), 양쪽 꼬리 [노트 p.7][녹음1 22:38–24:30][교재 p.134]. 노트의 "Std error를 coefficient로 나누면"은 녹음에서 "coefficient를 standard error로 나누면"으로 확인됨 [추가].

다변수: "multivariable logistic regression이라 함. multivariable과 multivariate는 다른 단어, 혼동하지 마라" [녹음1 33:09–33:27]. β가 3차원 벡터가 될 뿐 "본질적으로 다르지 않음" — 손실·갱신·Fisher 정보 모두 동일 [노트 p.8][녹음1 33:36–34:51].

#### 2.4 예측, odds ratio, confounding (S12–S15)

예측: 잔액 $1000 → p̂ = 0.006 → default 아님; $2000 → 0.586 > 0.5 → default로 예측, "추가 대출 안 해 준다" [노트 p.8][녹음1 27:31–28:08][교재 p.134].

student 변수: 계수 0.4049 → e^{0.4049} = odds ratio. "학생 그룹의 odds가 비학생의 60% 높다"(정확히는 1.50배 [추가]). odds = p/(1−p), OR = odds₂/odds₁. 직관: "죽을 확률/살 확률 = 한 명 살 때마다 몇 명 죽는가" — 한 명 살 때 3명 죽는 그룹과 5명 죽는 그룹 중 어디가 위험한가 [노트 p.8][녹음1 29:04–32:13]. 학생 0.0431 vs 비학생 0.0292 [교재 p.135].

Confounding(S14–S15): student만 넣으면 +0.4049, balance·income과 함께 넣으면 −0.6468(여전히 유의). "학생은 보통 balance가 커서 파산 확률이 올라가지만, 같은 잔액에서는 학생이 더 낮다" [노트 p.9][녹음1 35:08–38:17]. 교재: student와 balance가 상관 → 잔액 정보가 없으면 학생이 더 위험, 같은 잔액이면 덜 위험. 이 현상이 confounding [교재 p.136]. 교수님 질문: "저자들의 설명에 틀린 말 찾아보세요" — 답은 녹음에서 확인되지 않음 [녹음1 38:27].

[추가] balance는 노출(student)과 결과(default) 모두와 연관된 교란변수. 다중 회귀는 교란 보정 효과를 준다.

#### 2.5 남아공 심장병 자료 — 유병률 vs 환자 비율, 코호트 vs 환자-대조군 (S16–S18)

160 case, 302 control; 지역 유병률 5.1%인데 자료의 환자 비율 160/462 = 0.346. "디자인에 따라 다른 것인데 뭘까요? → case control design" [노트 p.9][녹음1 40:12–41:30].

"역학·보건통계가 다른 분야와 다른 것: 현실적인 여건에 따라 데이터를 뽑는 스킬이 굉장히 발달". 백신은 SCCS. 흡연→폐암을 RCT로 하면 "감옥 간다" — 윤리 문제로 관찰연구 [노트 p.9][녹음1 41:33–44:20].

코호트: 암이 없는 흡연자·비흡연자를 모아 10년 이상 추적. "2주 보면 0분의 0". 돈이 엄청 든다(모자보건 코호트의 선물 예). 우리나라 코호트 사례 다수 [노트 p.9][녹음1 44:24–48:49].

환자-대조군: "앉아 있으면 환자가 온다 → 담배 핀 적 있는지 물어본다". 코호트의 시간·비용을 줄이는 현명한 설계지만 논리를 뒤집는 것. 뒤집기를 허용하는 특별한 measure가 odds ratio — "case-control 자료로 로지스틱 회귀를 하면 코호트에서 얻은 것과 같다는 것이 증명됨. 일반 regression은 안 되고 로지스틱만 된다. 70·80 년대 역학·보건통계의 역사적으로 가장 중요한 결론 중 하나" [노트 p.10][녹음1 49:45–53:14].

slope는 같고 intercept는 완전히 다르다 — 병원은 환자를 증폭해 보는 샘플링 [노트 p.10][녹음1 54:33–55:03].

iid와 p* vs P: CS의 ML은 iid(독립·동일분포) 가정. 환자-대조군 자료도 사람끼리 독립이고 iid지만 목표 모집단 P가 아닌 환자가 증폭된 p*에서 나온 것. p*로 학습해 P의 관계를 복원할 수 있느냐가 문제이며, 로지스틱 회귀만 된다. 랜덤포레스트·부스팅은 보존 안 됨. "로그오즈 모델링 때문인지 로그우도 학습 때문인지? 모델 때문"[노트 p.11][녹음1 55:14–59:48].

R 출력(S18): tobacco, ldl, famhist, age가 유의한 양의 위험요인; obesity 음수지만 비유의 [슬라이드][추가]. 이 자료는 ESL(저자들의 "두 번째 책")의 예제이며 ISLR 1판에는 없다 [추가].

#### 2.6 선택지표 S로 증명하는 환자-대조군 로지스틱 회귀 (S19–S20, 칠판 19:47–19:59)

모집단: p(y=1|x) = e^{β₀+β₁x}/(1+e^{β₀+β₁x}), p(y=0|x) = 1/(1+e^{β₀+β₁x}). S = 1 selection indicator(1이면 분석 집단에 포함) 도입이 "매우 중요"하고 "굉장히 일반적인 접근 — 설계에 따라 S가 1이 되는 조건만 달라짐" [노트 p.11][녹음2 01:28–02:23].

p(y=1|x,S=1) = p(y=1,x,S=1)/p(x,S=1) = p(S=1|y=1,x)p(y=1|x) / [p(S=1|y=0,x)p(y=0|x) + p(S=1|y=1,x)p(y=1|x)] [칠판 19:47].

환자-대조군의 가정: "환자일 때는 다 뽑고 control일 때는 일부만. X를 활용하느냐? 전혀 없다(남성이면 더 뽑고… 그러면 case-control이라 안 부름)" → p(S=1|y,x) = p(S=1|y) [녹음2 04:04–04:52][칠판 19:49 동그라미].

분자·분모를 p(S=1|y=0)p(y=0|x)로 나누면 분모의 로지스틱 분모가 지워지고 c = p(S=1|y=1)/p(S=1|y=0)가 e^{β₀+β₁x} 앞에 남는다. c·e^{β₀+β₁x} = e^{(β₀+log c)+β₁x} → 절편만 β₀ = β₀ + log c로 shift, slope 불변* [녹음2 04:56–08:28][칠판 19:59].

결론: "intercept는 믿지 말고 slope는 원래 값과 같다. OR·유의성·z·p-value는 전혀 문제없다. Intercept는 절대 쓰면 안 되고 확률값을 쓸 수 없다 → 0.5 룰도 닫힌다" [노트 p.11][녹음2 08:28–09:57].

절편 보정식(S19): β̂₀* = β̂₀ + log[π/(1−π)] − log[π̃/(1−π̃)], π 유병률, π̃ 표본 환자비율. "유병률을 알면 case-control의 intercept를 복원시킬 수도 있다" [녹음2 16:33–17:06]. 남아공 자료 보정량 ≈ −2.32 [추가].

대조군 수(S20): 환자는 전부, 대조군은 약 5배까지 분산 감소, 그 이상은 수확 체감 [슬라이드].

Matched design: 산모 흡연 vs 저체중 — 흡연군에 젊은 산모가 많아 저체중이 덜 나오는 착시. 연령 32살끼리 짝 맞추면 "연령의 가치가 0"이지만 그것이 안 중요하다는 뜻이 아니다. "이런 자료에 머신러닝 쓰고 변수중요도 보면 다 틀림. 역학 디자인은 새로운 population 이야기 — 원래 목적 집단에 어디까지 recover할 수 있는지 반드시 따져야" [노트 p.11][녹음2 10:26–14:44].

왜 로지스틱만 되나: "1+exp라는 특수한 꼴 때문" → 역학에서 binary면 로지스틱을 돌리는 관습(계량경제는 probit) [녹음2 15:43–16:30]. 병원 자료에서 선택이 y에만 의존한다는 가정이 성립할지는 의문(강남검진센터 예) [녹음2 18:33–19:40].

#### 2.7 다항 로지스틱 — baseline category logit (S21, 칠판 20:48–20:59)

S21의 glmnet : "Stanford 그룹 패키지는 빠르고 안정적. small sample에 변수가 많을 땐 엄청난데 샘플이 많고 변수가 적으면 쥐약" [녹음3 00:00–00:46].

모형: π_j(x) = P(Y=j|x), log[π_j(x)/π_J(x)] = α_j + β_j x — 마지막 범주 J를 기준으로 비에 모델, 범주마다 절편·기울기 다름. 임의의 두 범주 a, b의 비는 두 기준 logit의 차로 얻는다 [노트 p.13][칠판 20:50][녹음3 02:24–04:04].

유도: π_j = π_J e^{α_j+β_j x}; j=J이면 e^{α_J+β_J x} = 1 → α_J = β_J = 0(계수 수를 줄이기 위해 고정) [칠판 20:51]. Σ_j π_j = 1 = π_J Σ_j e^{α_j+β_j x} → π_J = 1/Σ_j e^{α_j+β_j x}, π_j = e^{α_j+β_j x}/Σ_ℓ e^{α_ℓ+β_ℓ x}(softmax) — "각 클래스에 비례하는 확률. 이렇게 나왔구나 하는 모델의 근거를 알아 두라" [노트 p.13][칠판 20:54][녹음3 07:52–09:44]. S21의 "K−1개 선형함수만 필요"가 이것 [추가].

#### 2.8 판별분석의 출발점 — Bayes 정리로 뒤집기, 최고 밀도 분류 (S22–S25, 칠판 21:07–21:22)

"LDA·QDA는 나도 실제 분석에서 거의 안 쓴다. 그런데 naive Bayes는 엄청 많이 쓴다. 예비분석은 quick and dirty — 정교한 모델 말고 원시적이고 빠른 걸로 먼저. 가정은 망나니인데 성능이 좋다. 책의 LDA·QDA는 naive Bayes를 이해하기 위한 순서" [노트 p.14][녹음3 16:21–18:10].

목표는 같다: Bayes classifier 1(p(Y=1|x) ≥ ½). 로지스틱은 p(y|x)를 직접 모델링(logit 선형). 다른 길: x와 y의 자리를 바꿔 p(x|y)를 모델링 [노트 p.14][녹음3 18:15–19:18].

결합분포의 두 분해 p(x,y) = p(y|x)p(x) = p(x|y)p(y) [칠판 21:13]. p(y=1|x) = p(x|y=1)p(y=1)/[p(x|y=0)p(y=0)+p(x|y=1)p(y=1)] = f₁(x)π₁/[f₀(x)π₀ + f₁(x)π₁] [칠판 21:07] = 교재 (4.10) Pr(Y=k|X=x) = π_k f_k(x)/Σ_ℓ π_ℓ f_ℓ(x) — π_k 사전확률, f_k 클래스별 밀도 [교재 p.139][슬라이드 S24].

무엇을 모델링하나: π는 "자료의 1인 비율, 0인 비율을 넣으면 된다"; 모델링이 필요한 것은 f₁, f₀. 정규분포를 가정하면 LDA·QDA, 조금 틀면 naive Bayes [노트 p.14][녹음3 21:03–21:57].

장단점(트레이드오프): 로지스틱의 큰 장점 = X쪽을 모델링하지 않아도 됨(X 분포가 뭐든 inference는 올바름). 단점 = "X가 나올 데가 없어" 자료를 생성할 수 없다(모의실험 어려움). 판별분석 = x·y의 joint를 가져 (x,y)를 생성할 수 있는 모델, 생성형 모델의 뿌리; 단점 = X 분포가 맞아야 함 [노트 p.14–15][녹음3 22:24–26:10].

가우시안이면 decision boundary가 직선(LDA) 또는 2차곡선(QDA) [노트 p.15][녹음3 27:02–27:32].

최고 밀도 분류(S25): p(y=1|x) ≥ ½ ⇔ f₁π₁ ≥ f₀π₀ ⇔ f₁(x)/f₀(x) ≥ π₀/π₁ [칠판 21:15]. 사전확률이 반반이면 f₁(x) ≥ f₀(x): "질병군의 X 분포에서 이 x의 높이(intensity)와 비질병군의 높이를 비교해 높은 쪽으로" [노트 p.15][녹음3 29:37–31:25]. 사전확률이 다르면(π₂=0.7) 큰 쪽이 유리해 경계가 이동 [슬라이드 S25]. K클래스는 분모에 f₂π₂… 추가 [칠판 21:22].

[추가] 환자-대조군 자료에서 π̂_k를 표본 비율로 쓰면 사전확률이 왜곡된다 — 외부 유병률을 써야 함(2.6과 연결).

#### 2.9 왜 판별분석인가 — complete separation (S26)

교재의 세 이유: 클래스가 잘 분리되면 로지스틱 추정이 놀랍도록 불안정, n 작고 X 정규이면 LDA가 안정, K>2 에서 인기·저차원 시각화 [슬라이드 S26][교재 p.138].

Complete separation: "로지스틱 회귀가 답을 안 주고 발산하면서 컴퓨터가 멈추는 경우" — x가 어떤 값보다 작으면 다 0, 크면 다 1. 확률을 0·1로 만들려면 β₁이 −∞·+∞로 → "likelihood가 박살남", 돌다가 멈추고 값을 내뱉음. 증상: "신뢰구간이 678만부터 374만". 특정 변수 하나가 아니라 어떤 linear combination에서도 생기며, rare outcome에서는 큰 자료에도 꽤 자주 [노트 p.16][녹음3 31:33–34:27].

"Discrimination analysis는 이런 일이 생기는 일이 0" — y=1 자료만으로 X 분포를, y=0 자료만으로 X 분포를 피팅해 공식에 넣으면 끝 [노트 p.16][녹음3 34:29–35:21]. X 분포가 정규가 맞으면 로지스틱보다 더 정확하다는 사람도 있다(교수님은 선호하지 않는 말) [녹음3 35:21–35:36].

다항 확장: 분모에 f₂(x)π₂만 추가하면 되어 "베르누이→다항보다 더 쉽다". 단점은 각 클래스에서 X 분포가 맞아야 한다는 것이고, 그 자리를 naive Bayes가 대신 [노트 p.16][녹음3 35:43–36:50].
