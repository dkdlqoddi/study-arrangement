#### 5-3. 집에서 해 보라고 한 연습

로지스틱 함수에서 logit(링크 함수) 유도해 보기 (녹음1 01:27).

미분이 되는 함수라면 어떤 최적화 문제에도 쓸 수 있으니 "집에 가서 몇 번 연습해 보라" (녹음1 16:43).

#### 6-3. 서술형

Q23. (15점) 0-1 손실에서 출발하여 로지스틱 회귀의 손실함수가 −log 우도가 되는 과정을 설명하고, 통계학의 최대우도 추정과 컴퓨터과학의 손실 최소화가 왜 동치인지 쓰라. [노트 p.6–7·판서 18:40–18:51]

① 분류의 진짜 목표는 오분류율, 즉 0-1 손실 (1/n)Σ1(yᵢ ≠ 1(p(yᵢ=1|xᵢ) ≥ ½))을 최소화하는 β를 찾는 것이다. 그러나 지시함수는 β에 대해 계단형이어서 기울기가 0 아니면 정의되지 않아 경사법을 쓸 수 없다("Gradient는 최소한 한 번은 미분되어야 함"). ② 그래서 미분 가능한 대리 손실을 만든다. 통계학자는 Y의 생성 분포를 떠올린다. Y ∈ {0,1}은 베르누이 분포 pʸ(1−p)¹⁻ʸ를 따르고, 전체 자료의 확률 ∏ pᵢ^{yᵢ}(1−pᵢ)^{1−yᵢ}를 β의 함수로 본 것이 우도이다. 이를 최대화하는 것이 최대우도법이다. ③ 로그는 단조증가 함수라 "등수를 유지"하므로 우도의 최대점과 log 우도의 최대점이 같다. 부호를 바꾸면 −log 우도 = −Σ[yᵢ log pᵢ + (1−yᵢ)log(1−pᵢ)]가 되고, 이를 최소화하는 것이 손실 최소화이다. 따라서 max 우도 ⇔ min(−log 우도)로 두 관점이 동치이다. ④ 직관: y=1인 관측의 손실 −log p는 p → 1일 때, y=0의 −log(1−p)는 p → 0일 때 작아지므로, 손실을 줄이는 β는 정답 라벨에 확률을 몰아준다. 손실은 볼록이므로 경사법 β^{(t+1)} = β^{(t)} − η∇Loss로 전역 최소(MLE)에 도달하며, 실제 소프트웨어는 2차 미분을 이용한 Newton–Raphson으로 빠르게 수렴시키고 그 과정에서 표준오차를 얻는다.

Q24. (15점) 환자-대조군(case-control) 자료에 로지스틱 회귀를 적용해도 되는 이유를 선택지표 S를 도입해 수식으로 증명하고, 추정 결과 중 믿을 수 있는 것과 없는 것을 구분하라. [판서 19:47–19:59·노트 p.10–11·S19]

① 모집단 모형: p(y=1|x) = e^{β₀+β₁x}/(1+e^{β₀+β₁x}), p(y=0|x) = 1/(1+e^{β₀+β₁x}). 표본에 뽑혔음을 S=1로 표시하면 환자-대조군 자료에서 추정되는 것은 p(y=1|x, S=1)이다. ② p(y=1|x,S=1) = p(y=1,x,S=1)/p(x,S=1) = p(S=1|y=1,x)p(y=1|x) / [p(S=1|y=0,x)p(y=0|x) + p(S=1|y=1,x)p(y=1|x)]. ③ 환자-대조군 설계의 가정: 선택이 y에만 의존, p(S=1|y,x) = p(S=1|y). 분자·분모를 p(S=1|y=0)p(y=0|x)로 나누면 c = p(S=1|y=1)/p(S=1|y=0)에 대해 p(y=1|x,S=1) = c·e^{β₀+β₁x}/(1 + c·e^{β₀+β₁x}). c·e^{β₀+β₁x} = e^{(β₀+log c)+β₁x}이므로 결과는 절편만 β₀* = β₀ + log c로 바뀐 로지스틱 모형이다. 기울기 β₁은 그대로이다. ④ 따라서 기울기(= log OR), odds ratio, 그 표준오차·p-value는 코호트 자료에서 얻은 것처럼 해석해도 된다. 반면 절편은 모집단의 β₀가 아니므로 절대 쓰면 안 되고, 절편이 들어가는 예측확률도 쓸 수 없다. 유병률 π와 표본 환자비율 π̃을 알면 β̂₀* = β̂₀ + log[π/(1−π)] − log[π̃/(1−π̃)]로 복원할 수 있다. ⑤ 이것이 가능한 이유는 logit 링크가 곱셈 상수를 덧셈 상수(절편)로 흡수하기 때문이며, 일반 회귀나 다른 링크에서는 성립하지 않는다("일반적으로 regression이 안 되는데 logistic regression만 된다"). 선택이 x에도 의존하면(성별·교육수준 등) 이 결론은 깨질 수 있다.

Q25. (10점) Baseline category logit model을 정의하고, 이로부터 π_j(x)의 softmax 표현을 유도한 뒤, 이 모형의 손실함수와 분류 규칙을 쓰라. [판서 20:48–20:59·노트 p.13]

① π_j(x) = P(Y=j|x), j = 1,…,J. 마지막 범주 J를 기준으로 log[π_j(x)/π_J(x)] = α_j + β_j x (j = 1,…,J−1; α_J = β_J = 0). 범주마다 절편·기울기가 다르며, 임의의 두 범주 a, b의 log odds는 두 기준 logit의 차로 얻는다. ② 지수화: π_j(x) = π_J(x)e^{α_j+β_j x}. 합이 1: Σ_j π_j(x) = π_J(x)Σ_j e^{α_j+β_j x} = 1 ⇒ π_J(x) = 1/Σ_j e^{α_j+β_j x} ⇒ π_j(x) = e^{α_j+β_j x}/Σ_ℓ e^{α_ℓ+β_ℓ x} (각 범주에 e^{α_j+β_j x}에 비례하는 확률). ③ 손실: 다항분포 우도 ∏_j p_j^{y_j}(y는 one-hot) → −log lik = −Σ_j y_j log p_j, 모든 (α_j, β_j)의 함수이며 경사법으로 최소화. ④ 분류: 모든 j에 대해 π̂_j(x)를 계산해 argmax_j P(Y=j|x)인 범주로 배정. 이 Bayes 분류기가 0-1 손실을 최소화한다.

Q26. (10점) 로지스틱 회귀(판별적 접근)와 판별분석(생성적 접근)이 Bayes 분류기 1(p(Y=1|x) ≥ ½)에 도달하는 두 경로를 결합분포의 분해로 설명하고, 각 접근의 장단점을 쓰라. [판서 21:07–21:13·노트 p.14–15·S23]

① p(x,y) = p(y|x)p(x) = p(x|y)p(y). 로지스틱은 첫 분해의 p(y|x)를 logit 선형모형으로 직접 모델링하고 p(x)는 묻지 않는다(판별적, 조건부 우도). 판별분석은 둘째 분해를 써서 클래스별 X 밀도 f_k(x) = p(x|y=k)와 사전확률 π_k = p(y=k)를 모델링한 뒤 Bayes 정리로 뒤집는다: p(y=1|x) = f₁(x)π₁/[f₀(x)π₀ + f₁(x)π₁] (생성적, 완전 우도). ② 생성적 접근의 장점: y를 뽑고 f_y(x)에서 x를 뽑으면 (x,y)를 생성할 수 있어 모의실험·검증이 쉽다. 클래스가 잘 분리되거나 n이 작아도 안정적이고(complete separation 없음), K클래스 확장이 분모에 항만 더하면 되어 쉽다. 단점: X의 분포 가정(정규 등)이 맞아야 한다. ③ 판별적 접근의 장점: X 분포에 대한 가정이 없어 설명변수에 대한 접근 없이 모델링이 가능하다. 단점: 자료를 생성하려면 X를 외부에서 가져와야 하고, 완전 분리 시 추정이 불안정하다. ④ f_k를 정규로 두면 LDA(공통 Σ)·QDA(클래스별 Σ_k), 변수 간 조건부 독립을 두면 naive Bayes가 된다. 2클래스 LDA의 log odds는 x에 선형이라 로지스틱과 같은 형태이며 차이는 추정법뿐이다.

Q27. (10점) 코호트 설계와 환자-대조군 설계를 흡연-폐암 예로 비교하고, 역학 자료에 머신러닝을 적용할 때 주의할 점을 교수님의 논지에 따라 서술하라. [노트 p.9–11]

① RCT는 흡연을 무작위 배정해야 하므로 윤리적으로 불가능 → 관찰연구. 코호트: 암이 없는 흡연자·비흡연자를 모아 장기간(암은 10년 이상) 추적해 발병률을 비교. 시간적 선후가 분명하지만 비용·시간이 크다(임신 코호트예: 출산 후 머리둘레 등 측정, 방문마다 선물). 환자-대조군: 앉아 있으면 오는 폐암 환자와 비환자에게 과거 흡연 여부를 묻는다. 빠르고 싸지만 결과→노출로 논리를 뒤집는 것이라 일반적으로 회귀계수가 보존되지 않는다. 예외가 odds ratio이고, 그래서 로지스틱 회귀의 기울기는 코호트처럼 해석 가능하다(절편 제외). ② 주의점: 컴퓨터과학의 ML은 자료가 목표 모집단 분포에서 iid로 나왔다고 가정하지만, 역학 설계(환자-대조군, matched design 등)는 의도적으로 다른 분포 p*에서 자료를 뽑는다. 알고리즘은 기계적으로 돌아가지만, 그 결과를 원래 목적 모집단으로 얼마나 복원할 수 있는지 스스로 물어야 한다. 예: matched design에서 짝지은 변수(연령)는 효과가 사라져 변수중요도가 틀리게 나온다. 역학에서 이진 자료에 로지스틱을 돌리는 관습은 이런 설계 호환성 (OR 복원)에서 비롯됐다.

Q28. (10점) "Classify to the highest density"(S25) 슬라이드의 두 그림을 설명하고, 사전확률이 다를 때 결정경계가 왜 이동하는지 수식으로 보여라. [판서 21:15–21:22·S25]

① 왼쪽(π₁ = π₂ = 0.5): 두 클래스의 밀도 f₁, f₂가 교차하는 점이 경계. 새 점 x는 밀도가 더 높은 클래스(f₁(x) ≥ f₀(x) ⇔ p(x|y=1) ≥ p(x|y=0))로 분류한다. ② 오른쪽(π₁ = 0.3, π₂ = 0.7): 비교 대상이 π_k f_k(x)이므로 분홍(π₂ = 0.7)이 유리해져 경계가 왼쪽으로 이동한다. ③ 수식: p(Y=1|x) = f₁π₁/(f₀π₀ + f₁π₁) ≥ ½ ⇔ f₁π₁ ≥ f₀π₀ ⇔ f₁(x)/f₀(x) ≥ π₀/π₁. 사전확률이 같으면 임계비가 1이지만, π₁이 커지면 임계비 π₀/π₁이 작아져 더 넓은 x 영역이 클래스 1로 분류된다. K클래스에서는 분모에 f₂π₂ 등이 더해지고 규칙은 argmax_k π_k f_k(x).

Q29. (10점) 로지스틱 회귀 계수표(Coefficient, Std. Error, Z, P-value)의 각 열이 어떻게 계산되는지 Newton–Raphson과 Fisher 정보행렬을 이용해 설명하라. [노트 p.7·판서 19:09·교재 p.134]

① Coefficient: −log 우도를 최소화하는 MLE. 경사법으로도 되지만 glm은 Newton–Raphson β^{(t+1)} = β^{(t)} − F⁻¹∇Loss(2차 미분 역행렬을 기울기 앞에 곱함)로 몇 번 만에 수렴. ② Std. Error: 수렴점에서 −log 우도의 2차 미분 행렬 F(Fisher 정보)를 구하면 F⁻¹이 β̂의 근사 공분산행렬이고, 대각원소의 제곱근이 각 계수의 SE. 수치미분 함수가 있어 손으로 미분하지 않아도 된다. ③ Z = β̂/SE(선형회귀의 t 역할). ④ P-value = 2(1−Φ(|z|)) (표준정규 양쪽 꼬리). 절댓값이 큰 z, 작은 p는 H₀: β = 0에 반하는 증거. 절편은 보통 관심 대상이 아니다.

Q30. (10점) LDA·QDA·naive Bayes가 공유하는 공식과 각각의 가정, 그리고 LDA와 QDA 사이의 편향-분산 트레이드오프를 설명하라. [S40–S42·교재 p.149–150]

① 공통: Pr(Y=k|X=x) = π_k f_k(x)/Σ_ℓ π_ℓ f_ℓ(x)에 f_k(x)의 가정만 다르게 넣는다. LDA: 가우스, 공통 Σ → δ_k(x) 가 x에 선형. QDA: 가우스, 클래스별 Σ_k → 이차항이 살아남아 이차 경계. Naive Bayes: f_k(x) = ∏j f(x_j)(클래스 내 변수 조건부 독립; 가우스이면 Σ_k 대각) → p가 커도 가능, 혼합형 변수 가능. ② 트레이드오프: 공분산행렬 하나에 p(p+1)/2개 모수, QDA는 K배. LDA는 Kp개 선형계수만 추정하므로 분산이 작지만 공통 Σ 가정이 틀리면 편향이 크다. 관측이 적으면 LDA, 자료가 매우 크거나 공통 공분산 가정이 명백히 틀리면 QDA(Fig 4.9).
