### 6. 셀프 체크리스트

아래 항목을 보지 않고 말로 설명할 수 있으면 체크한다. 설명이 막히면 섹션 2의 해당 번호로 돌아간다.

**통계학 vs 기계학습 (2.1~2.2)**

- [ ] 통계학과 ML의 2000년 이전 차이 다섯 가지(관심·데이터 크기·복잡도·추론 도구·해석력)를 표로 그릴 수 있다.

- [ ] 통계학이 농업 데이터에서, ML이 대량 데이터에서 출발했다는 점이 왜 "불확실성 vs 예측 정확도"차이로 이어지는지 설명할 수 있다.

- [ ] intercept/bias, coefficient/weight, predictor/feature, response/label 대응을 안다.

- [ ] "ML은 AI의 하위분야, statistical learning은 통계학의 하위분야, 둘은 교집합이 크다"를 그림으로 그릴 수 있다.

- [ ] Breiman, Efron, Shmueli 세 논문의 제목과 핵심 주장을 한 줄씩 말할 수 있다.

- [ ] 보건학에서 ML을 그대로 가져다 쓰면 안 되는 이유(tailoring, 공정성, 프라이버시)를 예와 함께 말할 수 있다.

**학습의 유형 (2.3)**

- [ ] Supervised / unsupervised / reinforcement를 "무엇이 있고 무엇이 없는가"로 구분할 수 있다.

- [ ] Regression과 classification을 Y의 유형으로 구분하고 보건학 예를 하나씩 든다.

- [ ] Unsupervised learning의 평가가 왜 어려운지 말할 수 있다.

- [ ] 강화학습의 보상 설계가 왜 위험할 수 있는지 예를 들 수 있다.

**f 추정과 손실함수 (2.4~2.6)**

- [ ] Y = f(X) + ε의 각 기호와 ε의 두 가지 가정을 말할 수 있다.

- [ ] Prediction과 inference의 차이를 direct mailing / housing 예로 설명할 수 있다.

- [ ] "라이터 예"로 예측 변수와 개입 변수가 다름을 설명할 수 있다.

- [ ] 제곱오차 손실 아래 최적 예측자가 E[Y|X=x]임을 백지에 유도할 수 있다(교차항이 0이 되는 이유 포함).

- [ ] Irreducible error와 reducible error를 구분한다.

- [ ] 제곱 손실이 표준이 된 이유와 OLS와의 연결을 말할 수 있다.

- [ ] Nearest neighbor averaging의 식 f̂(x) = Ave(Y|X∈N(x))을 쓰고 hyperparameter가 무엇인지 말할 수 있다.

- [ ] 이미지·텍스트를 벡터화하는 전통 방식과 그 한계(이웃 정보 손실)를 설명할 수 있다.

**모수·비모수, 차원의 저주, trade-off (2.7~2.9)**

- [ ] 모수적 방법의 2단계와 장단점, 비모수적 방법의 장단점을 말할 수 있다.

- [ ] "표준편차가 작아도 틀린 모형이면 나쁜 답"이 무슨 뜻인지 설명할 수 있다.

- [ ] 차원의 저주를 "10% 이웃이 local이 아니다"와 "10차원에서 80%"로 설명할 수 있다.

- [ ] d(X,0) ≈ √p, d(X,Y) ≈ √(2p), angle ≈ 90°를 근거와 함께 유도할 수 있다.


- [ ] 유연한 모형을 항상 쓰지 않는 두 가지 이유를 말할 수 있다.

- [ ] Lasso → Least squares → GAM/Trees → Bagging/Boosting/SVM의 유연성 순서를 그릴 수 있다.

**시험 전 마무리**

- [ ] 섹션 5의 서술형 6문을 답안 안 보고 각 10분 안에 쓴다.

- [ ] Chap2 Part II(Assessing model accuracy: MSE, training vs test, bias-variance)가 2차시 범위이므로이어서 정리한다.

- [ ] Efron(2020)과 Shmueli(2010) 논문의 초록을 한 번씩 읽어본다.

### 7. 셀프 체크리스트

보지 않고 말로 설명할 수 있으면 체크한다. 괄호는 해당 슬라이드(P1 = Chap2 Part I, P2 = Part II)와 강의노트·교재 쪽수이며, 막히면 2절의 해당 소절로 돌아간다.

**f 추정과 parametric / non-parametric (2.1~2.2)**

- [ ] Y = f(X) + ε에서 f와 ε의 뜻, reducible/irreducible error를 말할 수 있다 (P1 슬4, 8~11; 교재 p.16~19)
- [ ] 회귀함수 f(x) = E(Y|X=x)가 제곱오차 기준 최적 예측자인 이유를 안다 (P1 슬7; 노트 p.18, 22)
- [ ] 예측과 추론의 목적 차이를 f̂을 black box로 둘 수 있는지로 설명할 수 있다 (P1 슬12~16; 교재 p.17~20)
- [ ] Parametric 2단계(함수형 가정 → 모수 추정)와 그 위험을 안다 (P1 슬20~21; 노트 p.19~20)
- [ ] "선형모형 = 직선"이 오개념인 이유와 변환 항·교호항의 해석 문제를 설명할 수 있다 (P1 슬20; 노트 p.19)
- [ ] ML 관점에서 회귀는 L(y,f(x)) = (y−f(x))²의 평균을 최소화하는 문제임을 안다 (노트 p.19, 30)
- [ ] Non-parametric의 장단점과 "데이터가 많으면 non-parametric"의 근거를 안다 (P1 슬23~24; 노트 p.21)
- [ ] Taylor 전개로 매끄러운 f가 다항식(선형모형)으로 근사된다는 교수님 설명을 재현할 수 있다 (노트 p.21)

**KNN과 차원의 저주 (2.3)**

- [ ] KNN 회귀 f̂(x) = Ave(Y|X∈N(x))와 k=1 / k=n일 때의 모양을 안다 (P1 슬25; 노트 p.22~23)
- [ ] k가 hyperparameter이며 "기분으로" 정하지 않고 test MSE로 정한다는 것을 안다 (노트 p.23, 32)
- [ ] 단위 입방체에서 r 비율을 잡는 변 길이 r^(1/p)를 계산할 수 있다: 0.316, 0.46, 0.8, 0.977 (P1 슬26~27; 노트 p.24)
- [ ] 고차원에서 d(X,0) ≈ √p, d(X,Y) ≈ √(2p), 각 ≈ 90°를 LLN으로 설명할 수 있다 (P1 슬28; 노트 p.25)
- [ ] 차원의 저주가 KNN만의 문제가 아니라 거의 모든 non-parametric의 문제임을 안다 (노트 p.23)
- [ ] LLN과 CLT가 무엇인지 말할 수 있다 (노트 p.25 "알아두세요")

**예측 정확도와 해석력 (2.4)**

- [ ] 유연한 방법을 항상 쓰지 않는 두 이유(해석력, 단순 모형이 더 정확할 수 있음)를 안다 (P1 슬29~30; 교재 p.25~26)
- [ ] βⱼ의 해석을 정확히 말할 수 있다 (P1 슬29)
- [ ] 그림 2.7의 방법 순서(Lasso → OLS → GAM·Trees → Bagging·Boosting → SVM)를 안다 (P1 슬31; 교재 p.25)
- [ ] 표본 수가 허용 복잡도를 제한한다는 교수님 강조("매우 중요")를 기억한다 (노트 p.28)
- [ ] Explainable AI·LIME이 왜 "우하단" 모형에 필요한지 안다 (노트 p.27~28)

**모형 정확도 평가 (2.5)**

- [ ] Stat(βⱼ, s.e., CI)과 ML(Ŷ = xβ̂)의 관심 차이를 안다 (노트 p.29)
- [ ] "문헌에서 가장 먼저 loss function을 보라"는 이유를 안다 (노트 p.30; 녹음2)
- [ ] training MSE / test MSE의 정의와 식을 쓸 수 있다 (P2 슬3~4; 교재 p.29~30)
- [ ] Generalization과 generalizability의 차이를 예와 함께 설명할 수 있다 (노트 p.30)
- [ ] training MSE가 0이 되는 interpolation과 overfitting("에러까지 적합")을 설명할 수 있다 (P2 슬5~6; 노트 p.32)
- [ ] 그림 2.9~2.11 세 예에서 최적 유연성이 다른 이유를 안다 (P2 슬6~8; 교재 p.33)
- [ ] 실제로는 test MSE를 교차검증으로 추정한다는 것을 안다 (교재 p.33)

**Bias-variance trade-off (2.6)**

- [ ] Bias와 variance를 정의하고 유연성에 따른 변화를 말할 수 있다 (P2 슬10~11; 교재 p.34~35)
- [ ] 기대 test MSE = Bias² + Var + Var(ε)을 직접 유도할 수 있다 (P2 슬12; 노트 p.36 "꼭 해 보라")
- [ ] U자가 bias·variance 변화 속도의 차이에서 생기는 이유를 안다 (P2 슬13; 노트 p.34, 36)

**분류 (2.7)**

- [ ] 분류의 error rate와 0-1 loss, 그 수학적 단점(미분 불가)을 안다 (P2 슬14; 노트 p.37)
- [ ] Bayes classifier(P ≥ 1/2 → 1)를 0-1 risk로부터 유도할 수 있다 (P2 슬15; 노트 p.38)
- [ ] Bayes error rate = 분류판 irreducible error임을 안다 (P2 슬15; 교재 p.38~39)
- [ ] 확률을 추정하는 방법(로지스틱)과 경계만 찾는 방법(SVM)의 구분을 안다 (노트 p.38)
- [ ] KNN 분류의 확률 추정식과 K에 따른 bias·variance 변화를 안다 (P2 슬17~20; 교재 p.39~40)
- [ ] 근본적인 그림(훈련오차 단조 감소, 시험오차 U자)을 그리고 각 구간을 설명할 수 있다 (P2 슬21~22; 교재 p.40~42)
- [ ] Double descent와 interpolation threshold를 한두 문장으로 말할 수 있다 (P2 슬23; 노트 p.32, 44)

### 7. 셀프 체크리스트 (괄호 = 해당 슬라이드)

로지스틱 회귀의 기초 - ☐ 분류에 선형회귀를 쓰면 생기는 두 문제를 말할 수 있다 (S06·S08) - ☐ 로지스틱 함수와 logit(링크 함수)을 쓰고, 서로 유도할 수 있다 (S09) - ☐ β₁의 해석(log odds 변화, odds에 e^{β₁}배)을 말할 수 있다 (S09·S13) - ☐ odds, odds ratio를 정의하고 더미변수 계수에서 OR을 계산할 수 있다 (S13) - ☐ 잔액 $1000, $2000의 default 확률을 계산하고 0.5 기준으로 분류할 수 있다 (S12)

손실함수와 추정 - ☐ 0-1 손실을 식으로 쓰고, 직접 최소화하기 어려운 이유를 말할 수 있다 (S11, 판서 18:40) - ☐ 베르누이 우도 → −log 우도 = cross-entropy를 유도할 수 있다 (S11, 판서 18:46) - ☐ MLE와 손실 최소화가 동치인 이유("로그는 등수를 유지")를 말할 수 있다 (S11) - ☐ y=1 / y=0 관측에서 손실이 p를 어느 방향으로 미는지 안다 (S11, 판서 18:51) - ☐ 경사법 갱신식 β^{(t+1)} = β^{(t)} − η∇Loss를 쓸 수 있다 (S11) - ☐ Newton–Raphson


이 무엇이고 glm이 왜 그것을 쓰는지 안다 (S11·S14, 판서 19:09) - ☐ 표준오차 = √diag(F⁻¹), z = β̂/SE, p = 2(1−Φ(|z|))을 설명할 수 있다 (S11·S14)

다변수·교란 - ☐ 다중 로지스틱 모형식을 쓰고 설명변수가 늘어도 본질이 같음을 말할 수 있다 (S14) - ☐ student 계수가 +에서 −로 바뀐 이유를 confounding으로 설명할 수 있다 (S14–S15) - ☐ "잔액 정보가 없으면 학생이 더 위험, 같은 잔액이면 덜 위험"을 설명할 수 있다 (S15)

역학 설계와 로지스틱 회귀 - ☐ 남아공 자료의 환자비율 0.35 vs 유병률 0.051의 차이를 설계로 설명할 수 있다 (S16·S19) - ☐ RCT가 불가능한 이유, 코호트·환자-대조군의 자료 수집 방식과 장단점을 말할 수 있다 (S16) - ☐ 선택지표 S를 도입해 p(y=1|x,S=1)을 유도하고 환자-대조군 가정을 쓸 수 있다 (S19, 판서 19:47–19:49) - ☐ 결과가 "절편만 log c만큼 이동한 로지스틱"임을 보일 수 있다 (S19, 판서 19:59) - ☐ 환자-대조군에서 믿을 것(기울기

·OR·p)과 못 믿을 것(절편·예측확률)을 구분할 수 있다 (S19) - ☐ 절편 보정식 β̂₀ = β̂ + log[π/(1−π)] − log[π̃/(1−π̃)]을 쓸 수 있다 (S19) - ☐ 대조군 5:1 이상에서 수확 체감이 생기는 이유를 말할 수 있다 (S20) - ☐ iid 가정과 "p vs p" 논의, matched design의 필요성과 부작용을 설명할 수 있다 (S19)

다항 로지스틱 - ☐ baseline category logit model을 쓰고 softmax 형태를 유도할 수 있다 (S21, 판서 20:48–20:54)

- ☐ 기준 범주의 (α_J, β_J) = (0, 0)이고 K−1개 선형함수만 필요함을 안다 (S21) - ☐ 다항분포 −log 우도 = −Σ y_j log p_j를 쓸 수 있다 (S21, 판서 20:59) - ☐ argmax 분류가 0-1 손실을 최소화함을 설명할 수 있다 (S21)

판별분석의 출발점 - ☐ 판별적(P(Y|X)) vs 생성적(P(X|Y)P(Y)) 접근을 p(x,y)의 두 분해로 설명할 수 있다 (S23, 판서 21:07–21:13) - ☐ 판별분석용 Bayes 정리와 π_k, f_k(x)의 뜻을 쓸 수 있다 (S24) - ☐ p(Y=1|x) ≥ ½ ⇔ f₁(x)/f₀(x) ≥ π₀/π₁을 유도할 수 있다 (S25, 판서 21:15–21:22) - ☐ 사전확률이 다르면 결정경계가 이동하는 방향을 설명할 수 있다 (S25) - ☐ 생성모델의 장단점(자료 생성 가능 vs X 분포 가정 필요)을 말할 수 있다 (S23) - ☐ complete separation의 정의·증상과 LDA에는 없는 이유를 말할 수 있다 (S26) - ☐ 로지스틱 대신 LDA를 쓰는 세 이유를 말할 수 있다 (S26) - ☐ naive Bayes를 예비분석에 먼저 돌려 보라는 조언과 그 이유를 안다 (S22·S42)

다음 차시 대비(이번 차시 미진행 추정) - ☐ LDA(p=1) 판별점수 δ_k(x)와 결정경계 (μ₁+μ₂)/2를 유도할 수 있다 (S27–S28) - ☐ LDA 모수 추정식(π̂_k, μ̂_k, σ̂²)을 쓸 수 있다 (S30) - ☐ p>1 LDA 판별함수가 선형인 이유와 Mahalanobis 거리의 뜻을 안다 (S31) - ☐ 혼동행렬에서 민감도·특이도·FPR·FNR을 계산할 수 있다 (S36–S37) - ☐ 임계값 변화의 트레이드오프와 ROC·AUC의 의미를 설명할 수 있다 (S38–S39) - ☐ LDA·QDA·naive Bayes의 f_k 가정 차이와 편향-분산 트레이드오프를 설명할 수 있다 (S40–S42) - ☐ 로지스틱 vs LDA(같은 형태, 다른 추정법)와 KNN의 장단점을 말할 수 있다 (S43–S45)

### 7. 셀프 체크리스트 (괄호 = 해당 슬라이드)

**판별분석의 출발점**

- [ ] probability와 likelihood의 차이를 θ·y의 역할로 설명할 수 있다 (S23, 판서 18:38)

- [ ] p(Y|X) ⇕ p(X|Y) 뒤집기가 판별분석의 핵심임을 말할 수 있다 (S23)

- [ ] 판별분석에 필요한 f₁, f₀, π와 "π는 표본 비율로 끝"을 안다 (S24)

- [ ] p(Y=1|x) ≥ ½ ⇔ π₁f₁ ≥ π₀f₀ ⇔ f₁/f₀ ≥ π₀/π₁을 유도할 수 있다 (S25, 판서 18:47)

- [ ] 로지스틱 대신 LDA를 쓰는 세 이유를 말할 수 있다 (S26)

**LDA p=1**

- [ ] 정규밀도를 대입해 로그를 취하고 지워지는 항(−½log 2πσ², x²/2σ²)을 짚을 수 있다 (S27)

- [ ] δ_k(x) = xμ_k/σ² − μ_k²/2σ² + log π_k를 쓰고 결정경계 (μ₁+μ₂)/2를 보일 수 있다 (S28)

- [ ] "판별점수는 튀어나온 게 아니라 대원칙(0-1 손실·Bayes 분류기)에서 온다"를 설명할 수 있다 (S28)

- [ ] 밀도 높이 비교 그림(녹색 vs 핑크)으로 분류 규칙을 설명할 수 있다 (S29)

- [ ] π̂_k, μ̂_k, σ̂²(n−K) 추정식을 쓰고 자유도 보정 이유를 안다 (S30)

- [ ] 분산이 다르면 x²이 살아남아 QDA가 되는 이유를 안다 (S30·S41)

- [ ] LDA가 "산뜻한 formula"인 이유와 로지스틱의 역행렬 비용(n³)을 말할 수 있다 (S30)

**다변량 정규분포**

- [ ] 다변량 포아송·이항 대신 다변량 정규를 쓰는 이유와 GEE·mixed-effect의 등장 배경을 말할 수 있다 (S31, M04)

- [ ] 우도 접근과 추정방정식 접근의 장단점을 비교할 수 있다 (M04, 판서 19:22)

- [ ] μ = E(X), Σ = E[(X−μ)(X−μ)ᵀ]를 쓰고 zᵀΣz ≥ 0(양반정치)을 설명할 수 있다 (M07)

- [ ] (x−μ)²/σ² → 이차형식, σ → |Σ|^{1/2}의 대응과 p차원 밀도식을 쓸 수 있다 (M08–M09)

- [ ] Σ의 모수 개수 p(p+1)/2를 유도할 수 있다 (M09, 판서 19:22)

- [ ] 대각 Σ이면 밀도가 곱으로 분해되어 독립임을 보이고 "가우스에서만"을 안다 (M11)

- [ ] 등고선 = 타원, 중심 μ, 축 = 고유벡터, 길이 = c√λ를 설명할 수 있다 (M12–M13)

- [ ] Σ=[[2,1],[1,2]]의 고유값·고유벡터를 구해 장축·단축을 말할 수 있다 (M14)

- [ ] "외우세요" 두 성질(선형결합·부분벡터)과 나머지 두 성질을 안다 (M16)

- [ ] E(Ax) = Aμ, Cov(Ax) = AΣAᵀ를 쓸 수 있다 (M17)

- [ ] 표준화 Σ^{−1/2}(X−μ) ~ N(0,I)와 카이제곱 타원체의 뜻을 안다 (M18–M19, 읽기)

- [ ] 조건부 평균이 회귀직선이고 분산이 (1−ρ²)배로 줄어듦을 안다 (M23–M24, 읽기)

- [ ] √, logit, Fisher z, log 변환의 용도를 안다 (M26, 읽기)

**LDA p>1과 naive Bayes**

- [ ] p>1 판별함수 δ_k(x) = xᵀΣ⁻¹μ_k − ½μ_kᵀΣ⁻¹μ_k + log π_k가 선형인 이유를 안다 (S31)

- [ ] "가장 어려운 파트는 Σ"와 유전체 자료 예(p 5천~4만, n 수백)를 말할 수 있다 (S31)

- [ ] 비대각 = 0 → 독립 → 곱 분해 → naive Bayes의 흐름을 설명할 수 있다 (S31·S42)

- [ ] 이산 변수의 count 처리와 Laplace 평활식을 쓸 수 있다 (S42)

- [ ] naiveBayes(default ~ ., data=Default) 의 추정 모수와 laplace 인자의 뜻을 안다 (S42)

- [ ] K=3 "땅따먹기"(세 직선, 3등분)를 설명할 수 있다 (S32)

- [ ] 붓꽃 자료(4변수·3종·50개·오분류 3)와 Fisher에 대해 말할 수 있다 (S33)

- [ ] K−1차원 판별 플롯의 이유를 안다 (S34)

- [ ] δ̂_k → softmax → 확률 변환식을 쓸 수 있다 (S35)

**이진 분류기 성능**


- [ ] 혼동행렬에서 오류율·정확도·민감도·특이도·FPR·FNR을 계산할 수 있다 (S36–S37)

- [ ] 훈련 오류와 테스트 오류를 구분하고 왜 전자가 지표가 아닌지 말할 수 있다 (S36)

- [ ] "항상 No" 분류기의 정확도(96.67%)로 불균형 자료의 함정을 설명할 수 있다 (S36)

- [ ] 두 오류의 비용 비대칭(은행·암 진단)을 예로 들 수 있다 (S36)

- [ ] "자유도는 ½뿐" — 임계값 c를 바꾸는 것의 의미와 대가를 설명할 수 있다 (S37–S38)

- [ ] 임계값 극단값에서 (민감도, 특이도)와 ROC의 (0,0)·(1,1)을 연결할 수 있다 (S38–S39)

- [ ] ROC의 축, 원숭이 선(0.5), (0,1) oracle, 0.5 ≤ AUC ≤ 1을 설명할 수 있다 (S39)

- [ ] Youden 지수·(0,1) 최근접점과 "분야마다 중시하는 오류가 다르다"를 말할 수 있다 (S39)

- [ ] LDA·QDA·naive Bayes의 f_k 가정 차이를 한 틀로 설명할 수 있다 (S40)

**비교와 선택(다음 차시 범위 대비)**

- [ ] QDA 판별함수와 모수 개수(Kp(p+1)/2), 편향-분산 관점의 LDA/QDA 선택을 설명할 수 있다 (S41)

- [ ] 로지스틱 vs LDA(같은 형태, 다른 추정법; 판별적 vs 생성적)를 설명할 수 있다 (S43)

- [ ] KNN의 장단점과 S45 요약(언제 무엇을 쓰나)을 말할 수 있다 (S44–S45)

- [ ] 교수님의 실무 평가("naive Bayes만 잘 알아 두라")와 교재 요약을 함께 정리할 수 있다 (S45)

- [ ] 내 조 번호·조원·조장을 알고 중간보고서(A4 1–2쪽: 제목·데이터셋·목적·이유)를 준비하고 있다
