### 7. 셀프 체크리스트 (괄호 = 해당 슬라이드)

**1장 · 교차검증(V01–V23)**

- [ ] bootstrap(불확실성)과 CV(예측 성능)의 용도를 한 문장으로 구분할 수 있다 (V01)

- [ ] 훈련오차가 검정오차를 과소추정하는 이유와 "아직도 많이 틀린다"는 분할 평가 원칙을 말할 수 있다 (V03)

- [ ] 검증셋 접근의 절차와 분할 비율에 "법칙이 없다"는 뜻을 안다 (V04–V05)

- [ ] hp² 추가 여부를 계수 검정(통계학)과 검증 오차 비교(머신러닝)로 판단하는 두 관점을 구분한다 (V06, V20)

- [ ] seed마다 달라지는 곡선에서 "위치는 믿고 값은 조심"을 설명할 수 있다 (V07, V15, V17)

- [ ] 검증셋 접근의 두 단점과 k-fold가 이를 줄이는 방식, K의 관례(10 → 5·3)를 안다 (V08–V09)

- [ ] CV_(K) 식을 쓰고 n_k가 약분되어 (1/n)Σ(yᵢ − ŷᵢ(−k))²가 됨을 보일 수 있다 (V10–V11, 판서 18:49)

- [ ] LOOCV의 장단점(seed 무관, n번 적합)과 (1 − hᵢ) 공식, 그 공식이 Gaussian 선형회귀에서만 성립함을 안다 (V12–V14)

- [ ] K의 편향–분산을 교재 방향으로 쓰고, 강의 표현("LOOCV는 variance가 없다")과의 차이를 설명할 수 있다 (V14–V15)

- [ ] 분류 CV의 Err_k, ŜE가 타당하지 않은 이유, one-SE rule의 절차·근거를 설명할 수 있다 (V18)

- [ ] 1–4차 로지스틱의 검정오류(0.201/0.197/0.160/0.162, Bayes 0.133)와 CV가 4차를 고른 것이 좋은 선택인 이유를 안다 (V19–V22)

- [ ] 훈련–검정 곡선 간격의 뜻과 KNN 가로축 1/K의 "order 주의"를 설명할 수 있다 (V22)

- [ ] 5000×50 예에서 틀린 CV, 올바른 CV(40/10), 최종 재적합, nested CV를 서술할 수 있다 (V23)

- [ ] Ambroise & McLachlan(selection bias)의 요지와 Nature의 심사 거부 공표를 말할 수 있다 (V23)

**2장 · 모형 선택(M01–M23)**

- [ ] 6장의 세 방법군과 대표 기법, 교수님이 2번(shrinkage)을 가장 중요하게 꼽은 것을 안다 (M02, M05)

- [ ] 최소제곱의 대안이 필요한 두 이유(p > n의 분산, 해석)와 feature·variable·model selection의 관계를 안다 (M03–M04)

- [ ] best subset의 2ᵖ(곱의 법칙)과, 같은 크기 비교와 크기가 다른 비교에서 다른 기준을 쓰는 이유를 안다 (M07–M09)

- [ ] forward·backward의 모형 수 1 + p(p+1)/2, "앞 변수 fix" 단점, backward의 n > p 요구를 안다 (M10–M13)

- [ ] R²·RSS로 크기가 다른 모형을 고르면 안 되는 이유와 predictive R²에 대한 교수님 입장을 말할 수 있다 (M14)

- [ ] 검정오차 추정의 간접(보정)·직접(CV) 접근과 각각의 장점을 말할 수 있다 (M15, M21)

- [ ] AIC·BIC 식, 각 항의 이름, d의 의미(로지스틱 d = 3 → 벌점 6)를 쓸 수 있다 (M18–M19, 판서 20:25)

- [ ] AIC가 U자가 되는 이유와 BIC가 더 단순한 모형을 고르는 이유(log n > 2, log n = 10 예)를 설명할 수 있다 (M18–M19)

- [ ] AIC(참 모형 없음·KL)와 BIC(참 모형 있음·일치성)의 철학, 하이브리드 불가능, 임상의 일치 요구 비판을 서술할 수 있다 (M05)

- [ ] Credit 결과(BIC 4, Cp·AIC 6, adjusted R² 7, 검증·CV 6, one-SE rule 3)를 기억한다 (M17, M22–M23)

- [ ] Cp–AIC "동치"의 조건(공통 σ²)과 "엄밀하게는 같지 않다", adjusted R²의 식과 방향을 안다 (M18, M20)

- [ ] 고차원에서 σ̂² = 0이 되는 문제와 CV가 universal한 이유를 설명할 수 있다 (M21)

- [ ] y 모형과 log y 모형의 AIC 비교에서 Jacobian 2Σlog yᵢ를 보정하고, 10만 vs 500만의 신호를 알아챌 수 있다 (M21)

- [ ] LOOCV ≈ AIC(Stone)이고 CV는 AIC의 성격이라는 연결을 말할 수 있다 (M22)

**3장 · 수강생 발표**

- [ ] 같은 seed인데 10-fold CV 값이 코드마다 다를 수 있는 이유와, 후보 모형이 하나의 fold 배정을 공유해야 하는 이유를 안다 (3장)


**4장 · 축소 방법(M24–M39)**

- [ ] 계수를 가두면 분산↓·편향↑이고 MSE가 줄 수 있는 이유("세상에 공짜가 없다")를 설명할 수 있다 (M25, M30)

- [ ] 직사각형·원·마름모·십자가·elastic net 영역과 해당 방법을 짝지을 수 있다 (M25, 판서 21:07)

- [ ] ridge의 제약형·벌점형을 쓰고 Lagrangian으로 연결하며, C와 λ의 방향과 닫힌 해를 안다 (M26, M34, 판서 21:11)

- [ ] λ = 0과 λ → ∞의 극한, solution path 읽는 법을 안다 (M26–M28)

- [ ] λ 선택 절차(격자 → CV → 최소 → 전체 재적합)와 "경계값이 최적이면 의심"을 말할 수 있다 (M27, M37)

- [ ] 표준화가 필요한 이유(척도 등변이 아님)를 안다 (M29 — 이번 차시 미진행, 교재)

- [ ] lasso의 ℓ1 벌점, 정확히 0, sparse, 이름(올가미), 장점(만 개 변수도 초 단위)·단점(아래로 긴 자료)을 말할 수 있다 (M31–M33)

- [ ] 마름모 꼭짓점 기하와 soft-thresholding으로 lasso만 정확히 0이 되는 이유를 설명할 수 있다 (M34–M35 — 이번 차시 미진행, 교재)

- [ ] ridge와 lasso가 각각 유리한 상황과 "CV로 정한다"는 결론을 안다 (M36 — 이번 차시 미진행, 교재)

**5장 · 차원축소(M40–M53, 이번 차시 미진행)**

- [ ] Z_m = Σφ_mjX_j로 회귀하고 β_j = Σθ_mφ_mj로 제약된다는 차원축소의 뜻을 안다 (M42–M43)

- [ ] PCR(비지도)과 PLS(지도)의 차이와 성분 수 M을 CV로 고르는 것을 안다 (M44–M52)


## 8차시 (2026-10-21) — AIC·BIC 유도(KL 발산·Laplace 근사) · 능형회귀·라쏘 심화(해 경로·표준화·sparse·oracle·soft thresholding) · elastic net·bridge·fused lasso · LLM으로 능형·라쏘 돌릴 때 시험 주의 (Ch7 자료 배포)

### 7. 셀프 체크리스트 (괄호 = 해당 슬라이드)

**1장 · 모형 선택 복습(M01–M23)**

- [ ] 6장의 세 방법군과 공지된 시험 범위("lasso와 ridge까지")가 어디까지인지 말할 수 있다 (M02, M05, 노트 p.1)

- [ ] 최소제곱의 대안이 필요한 두 이유(예측 정확도·해석)를 p > n과 연결해 설명할 수 있다 (M03–M04)

- [ ] best subset(2ᵖ)과 forward·backward(1 + p(p+1)/2)의 모형 수와 backward의 n > p 요구를 안다 (M07–M13)

- [ ] RSS·R²로 크기가 다른 모형을 고르면 항상 완전모형이 뽑히는 이유를 안다 (M14)

- [ ] Cp·AIC·BIC 식을 쓰고, Cp와 AIC가 비례하는 조건을 안다 (M18–M19)

- [ ] BIC의 벌점 log n이 n ≥ 8에서 2보다 커서 더 작은 모형을 고르는 이유와 Credit 결과(BIC 4, Cp 6, adjusted R² 7)를 안다 (M17, M19)

- [ ] adjusted R² ≈ (RSS/n)(1 + d/n)을 유도하고 모수당 벌점 ≈ 1, "AIC BIC로 충분히 족하다"를 설명할 수 있다 (M20, 판서 18:44)

- [ ] p ≫ n에서 σ̂² ≃ 0이 되어 Cp·AIC·BIC가 무너지고 CV가 "주된 현재 흐름"인 이유를 설명할 수 있다 (M21, 판서

18:44)

- [ ] one-standard-error rule의 절차·근거와 lambda.1se의 관계를 안다 (M23)

**2장 · AIC·BIC 유도(AB01–AB18)**

- [ ] AIC가 추정하는 것(η, 기대 KL)과 BIC가 근사하는 것(주변가능도, 사후 모형확률)을 한 문장씩 말할 수 있다 (AB02, AB05, AB13)

- [ ] KL 발산의 정의, 첫 항이 상쇄되는 이유, KL이 거리가 아닌 이유를 설명할 수 있다 (AB03, 판서 18:59)

- [ ] 정규·감마처럼 분포족이 다른 모형도 AIC로 비교할 수 있는 이유와 척도 주의(야코비안)를 안다 (AB03, AB10, 판서 18:59)

- [ ] ℓ(θ̂)가 낙관적인 이유("y를 두 번 쓴다")와 편향 b의 정의를 쓸 수 있다 (AB05)

- [ ] J·I의 정의와 정보 항등식 I = J가 "2p가 나오는 곳"인 이유를 안다 (AB06)

- [ ] 두 2차 전개의 이차형식이 부호가 반대라 b ≈ tr(J⁻¹I)가 되는 흐름을 말로 설명할 수 있다 (AB07–AB11)

- [ ] 2차에서 멈추는 이유(3차 이상 O(1/√n))를 차수로 설명할 수 있다 (AB03, AB09)

- [ ] TIC·AICc의 식과 쓰는 상황(오지정, n/p < 40)을 안다 (AB10)

- [ ] "AIC는 상대적 기준"(garbage 비유)의 뜻을 설명할 수 있다 (AB10)

- [ ] Laplace 근사에서 ∣nĴ∣ = nᵖ∣Ĵ∣ → p·log n이 나오는 과정을 쓸 수 있다 (AB13–AB15)

- [ ] AIC(효율성, 과대선택 확률 0.157, LOOCV 동등)와 BIC(일치성)를 비교하고 log BF₁₂ ≈ −½(BIC₁ − BIC₂)를 계산할 수 있다 (AB16–AB17)

**3장 · 능형회귀·라쏘(M24–M39) — 시험의 중심**

- [ ] 축소가 "문제를 변환시키는 방식"(제약 → 동치인 벌점)임을 두 단계로 설명할 수 있다 (M24–M25)

- [ ] 능형·라쏘의 제약형과 벌점형을 쓰고 라그랑지안으로 연결할 수 있다 (M26, M34, 판서 19:24·19:33)

- [ ] S와 λ의 방향(S↑ ⟺ λ↓)과 λ = 0, λ → ∞의 극한을 안다 (M26–M27)

- [ ] RSS 등고선이 타원인 이유와 "처음 닿는 점이 해"를 그림으로 설명할 수 있다 (M26, M35, 판서 19:33)

- [ ] 마름모 꼭짓점 때문에 라쏘만 계수를 정확히 0으로 만드는 이유를 그림과 확률로 설명할 수 있다 (M26, M35, M39)

- [ ] λ가 조절모수이고 β와 함께 최소화하면 항상 λ = 0이 되므로 CV로 고른다는 논리를 안다 (M26–M27, 판서 19:24)

- [ ] 능형 해 경로가 0을 "터치하지 않는다"는 것과 라쏘 경로(0에 닿아 머묾)의 차이를 안다 (M28, M33)


- [ ] (Y − Xβ)ᵀ(Y − Xβ) + λβᵀβ를 미분해 β̂ᴿ = (XᵀX + λI)⁻¹XᵀY를 유도할 수 있다 (M28–M29, 판서 19:54)

- [ ] 1차원 능형 β̂ = y/(1 + λ)의 기댓값·분산·MSE와 최적 λ = σ²/β²를 구할 수 있다 (M29, 판서 20:13)

- [ ] 척도 동변성의 정의와 능형에서 깨지는 이유(실효 벌점 λ/c²)를 설명할 수 있다 (M29, 노트 p.12 손글씨)

- [ ] 표준화 식을 쓰고, glmnet(기본 표준화)과 scikit-learn(StandardScaler 필요)의 차이, 범주형의 가변수 처리를 안다 (M29)

- [ ] Fig 6.5의 편향–분산 U자와 n = 50, p = 45에서 OLS가 null 모형과 비슷한 이유를 안다 (M30)

- [ ] 라쏘 = ℓ1 벌점(노트의 "l2"는 오류)과 변수 선택·sparse 모형을 설명할 수 있다 (M31–M32)

- [ ] 1차원 라쏘 해 sgn(y)(∣y∣ − λ/2)₊를 경우를 나눠 유도하고 숫자로 계산할 수 있다 (M34, 판서 20:47)

- [ ] sparse/dense의 정의, 각각 유리한 방법, 모를 때 "둘 다 돌리고 CV"를 말할 수 있다 (M31, M36, 판서 20:20)

- [ ] oracle property의 뜻과 표준 라쏘가 늘 갖지는 않는다는 단서를 안다 (M31)

- [ ] elastic net의 동기(상관된 묶음)·식·α의 뜻과 조절모수 2개의 비용(10,000 격자)을 안다 (M31–M32, 판서 20:25)

- [ ] λ 선택 절차(넓은 격자 → CV → 곡선 → 최솟값 → 전체 자료 재적합)를 쓸 수 있다 (M37)

- [ ] CV와 AIC/BIC로 λ를 고를 때의 장단점(계산 시간, σ², 범용성)을 비교할 수 있다 (M37)

- [ ] M38(작은 λ 쪽이 평평)과 M39(U자, 신호 변수 둘만 남음)의 CV 그림을 읽을 수 있다 (M38–M39)

- [ ] bridge 벌점(q < 1)의 모양, 선택이 강해지는 이유, 비볼록이라 잘 안 쓰는 이유를 안다 (M39, 판서 20:34·20:37)

**4장 · 차원축소(M40–M53, 범위 밖일 가능성 높음)**

- [ ] PCR(비지도)과 PLS(지도)의 차이, β_j = Σθ_mφ_mj 제약, 성분 수 M을 CV로 고르는 것을 안다 (M42–M52)

**5장 · 다른 벌점 함수(OP01–OP20, 범위 밖일 수 있음)**

- [ ] 라쏘의 두 한계(최대 n개, 묶음에서 하나만)와 elastic net 벌점 두 부분의 역할을 짝지을 수 있다 (OP03–OP04)

- [ ] elastic net 영역(꼭짓점·볼록한 변)과 grouping effect 부등식의 뜻을 안다 (OP05–OP06)

- [ ] OP05 슬라이드·칠판·glmnet·scikit-learn의 α 표기 차이를 안다 (OP05, 판서 20:25)

- [ ] generalized lasso의 식, D = I이면 표준 라쏘, 1-d fused lasso의 D(1차 차분)를 쓸 수 있다 (OP08–OP09, 판서 20:54)

- [ ] fused lasso가 이웃 차이에 라쏘를 걸어 점프·군집을 찾는 원리를 설명할 수 있다 (OP10–OP12, 판서 20:56–21:01)

- [ ] 서울 결핵 군집 탐지(식 (6))와 부호 제약 LUR(C-Ridge 등)의 요지를 말할 수 있다 (OP13–OP20)
