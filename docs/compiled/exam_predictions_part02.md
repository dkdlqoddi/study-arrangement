### 4. 분류기 성능 평가 (5~6차시)

**Q27 [A·유도] AUC = c-통계량 P(S_D > S_D̄)임을 증명하라. 세로 띠의 높이·너비, 전확률 법칙이 쓰이는 단계, 그리고 "AUC는 rank에만 의존"이 따라오는 이유를 쓰라. ("고등학교 구분구적법이면 된다")**
- 답안 핵심: ① c = P(S_D > S_D̄) + ½P(S_D = S_D̄)(동점 ½은 이산 점수의 technical한 약속); 표본에서는 concordant pair 비율(예 13/16 = 0.8125) = Mann–Whitney U/(n₁n₀). ② ROC = 임계값 s를 훑으며 (FPR, TPR) = (P(S_D̄ > s), P(S_D > s)). ③ 아래 면적을 세로 띠로 자르면 높이 = TPR(s) = P(S_D > s), 너비 = dFPR = f_D̄(s)ds("D가 아니라 D bar — 확대해서 보세요"). ④ AUC = ∫ P(S_D > s) f_D̄(s) ds = ∫ P(S_D > s | S_D̄ = s) f_D̄(s) ds(두 점수 독립) = P(S_D > S_D̄)(전확률 법칙 — 한쪽을 s로 고정하고 모두 더함). ⑤ 확률은 부등호만 쓰므로 점수에 단조변환(+5, ×2)을 해도 불변 → rank-based measure → 보정에 눈먼 한계로 이어짐.
- 근거: 6차시 §2.2–2.3(판서 18:51, 녹음1 05:45–17:08) · 모범답안: 예상문제 모음 4부 Q31, 3부(6차시) Q3–Q6·Q17–Q19.
- 프롬프트: Q27.

**Q28 [A·서술] discrimination과 calibration의 차이, AUC의 네 가지 한계(교수님이 "3번이 굉장히 중요"), 그리고 보고할 지표 세트를 쓰라.**
- 답안 핵심: ① 판별 = 환자·비환자 점수가 얼마나 분리되나(AUC); 보정 = 점수 0.2인 사람들의 실제 발병률이 0.2인가 — 모든 확률에 0.5를 더하면 AUC는 그대로지만 보정은 깨짐; 확인은 10등분 보정 플롯(y ≈ x), Brier score. ② 한계: (1) 보정에 눈멂 (2) 임상에서 안 쓰는 임계값까지 전 구간 평균(부분 AUC) (3) **증분이 작다** — odds ratio가 큰 변수를 넣어도 순위가 안 바뀌면 ΔAUC ≈ 0.01 → AUC 증분으로 변수 중요도 평가는 위험 (4) 오류 비용·유병률 무시. ③ 학습 손실(cross-entropy)과 평가지표(AUC)의 불일치 = "철학적 issue" → 실용: 민감도·특이도·PPV·NPV·F1·보정을 세트로 보고(TRIPOD), 유병률 낮은 문맥에서 PPV·F1이 낮은 것은 설명.
- 근거: 6차시 §2.4–2.5·§2.7(녹음1 16:46–25:59, 39:46–46:58) · 모범답안: 예상문제 모음 4부 Q32, 3부(6차시) Q7·Q9·Q20·Q22.
- 프롬프트: Q28.

**Q29 [A·계산] 민감도 0.99·특이도 0.98인 검사의 PPV를 Bayes 정리로 전개하고 유병률 10%, 1%, 1/1000, 10만 명당 10건에서 계산하라. 왜 민감도·특이도는 유병률과 무관한데 PPV·NPV는 아닌가?**
- 답안 핵심: ① PPV = P(Y=1|Ŷ=1) = Se·π / [Se·π + (1 − Sp)(1 − π)]; NPV = Sp(1 − π)/[Sp(1 − π) + (1 − Se)π]. ② π = 0.1 → 0.846; 0.01 → 0.333; 0.001 → 0.047; 0.0001 → 0.0049("20~30%가 채 안 된다"). ③ 민감도·특이도는 실제 상태를 조건으로 한 검사(기기)의 성질이라 π와 무관; PPV·NPV는 판정을 조건으로 한 환자 입장의 확률이라 π에 좌우. ④ "의료기기 팔 때는 민감도·특이도, 환자에게는 PPV·NPV"; "다른 병원도 가 봐야 한다"는 지혜 = 낮은 PPV의 직감.
- 근거: 6차시 §2.6(판서 19:03–19:08, 녹음1 26:05–31:30) · 모범답안: 예상문제 모음 4부 Q33, 3부(6차시) Q8·Q21.
- 프롬프트: Q29.

**Q30 [B·계산·서술] 정확도의 함정(Default 자료 LDA 혼동행렬), 임계값과 오류 비용, ROC 곡선 그리는 법, 임계값을 0.5 → 0.2로 낮출 때의 변화를 쓰라.**
- 답안 핵심: ① 전체 오류 2.75%(23 + 252)/10000이지만 "항상 No"도 3.33% → 정확도만으로는 판단 불가(불균형). ② 민감도 81/333 = 24.3%, 특이도 9644/9667 = 99.8% — 환자(default) 대부분을 놓침. ③ 오류 비용이 다르면(놓친 환자 vs 거짓 경보) 임계값을 바꿈: 0.2로 낮추면 놓친 비율 75.7% → 41.4%, 대신 FP 증가·전체 오류 3.73%. ④ ROC: 임계값을 0→1로 훑으며 (1 − 특이도, 민감도)를 찍음, 좌상단이 좋음, 교차하면 AUC로 비교(Default 0.95); 점수는 확률일 필요도 임계값이 ½일 필요도 없음; x축을 특이도로 그린 그림도 있음. ⑤ Youden 지수 = Se + Sp − 1.
- 근거: 5차시 §2.7–2.8, 6차시 §2.1, 교재 p.144–149 · 모범답안: 예상문제 모음 3부(5차시) Q26–Q28·Q33, 3부(6차시) Q1·Q15–Q16.
- 프롬프트: Q30.

**Q31 [B·비교] 로지스틱 회귀는 무슨 손실로 학습하고 문헌은 무엇으로 평가하는가? 그 불일치에 대한 교수님의 입장과 TRIPOD/PROBAST의 역할을 쓰라.**
- 답안 핵심: ① 목표는 0-1 손실이지만 미분 불가 → 베르누이 −log 우도(cross-entropy)로 학습; 평가는 AUC(순위) 등 — 학습 손실 ≠ 평가지표. ② 교수님: 철학적 issue지만 실용적으로 지표 세트를 함께 보고하고 문맥을 설명. ③ TRIPOD = 예측모형 보고 지침, PROBAST = 예측모형 연구의 편향 위험 평가 도구(4차시 발표).
- 근거: 6차시 §2.7, 4차시 §2.11 · 모범답안: 예상문제 모음 3부(6차시) Q22.
- 프롬프트: Q31.

### 5. 분류 모형 — 로지스틱·판별분석·naive Bayes (3~5차시)

**Q32 [B·유도·서술] 로지스틱 회귀에서 0-1 손실 → 우도 → −log 우도(cross-entropy) → 경사법/Newton–Raphson으로 이어지는 흐름을 쓰고, odds ratio 해석과 confounding 예(student 계수 +0.40 → −0.65)를 설명하라.**
- 답안 핵심: ① p(X) = e^{β₀+β₁X}/(1 + e^{β₀+β₁X}), logit = β₀ + β₁X; OR = e^{β₁}(X 1 증가 → odds e^{β₁}배). ② 0-1 손실은 계단함수라 미분 불가 → 대리(surrogate) 손실: 베르누이 우도 Π pᵢ^{yᵢ}(1 − pᵢ)^{1−yᵢ} → −ℓ = −Σ[yᵢ log pᵢ + (1 − yᵢ)log(1 − pᵢ)] = cross-entropy, β에 볼록, 닫힌 해 없음. ③ 경사법 β ← β − η∇(−ℓ), η = learning rate("art"); Newton–Raphson β ← β − [∇²ℓ]⁻¹∇ℓ(IRLS). SE = 정보행렬 역행렬 대각의 제곱근 → z = β̂/SE. ④ confounding: student 단독 +0.4049이지만 balance를 넣으면 −0.6468 — 학생은 balance가 높아서 default가 많아 보였을 뿐, 같은 balance에서는 덜 default. ⑤ 다범주는 다항(multinomial) 우도 → softmax; "통계의 우도에 로그 취하고 마이너스 붙여 loss로 보고 gradient로 최소화 — 신경망도 같다".
- 근거: 3차시 §2.9, 4차시 §2.1–2.4(판서 18:46·18:51·19:09), 교재 p.132–136 · 모범답안: 예상문제 모음 2부(4차시) Q1–Q3·Q12–Q15.
- 프롬프트: Q32.

**Q33 [A·유도] 환자-대조군 자료에 로지스틱 회귀를 적합하면 무엇을 믿을 수 있고 무엇을 믿으면 안 되는가? 선택지표 S로 증명하라. ("70·80년대 역학·보건통계의 역사적으로 가장 중요한 결론 중 하나")**
- 답안 핵심: ① S = 1(분석에 포함) 도입; 환자-대조군의 핵심 가정 P(S=1|y, x) = P(S=1|y) — 선택이 y에만 의존하고 x에는 의존하지 않음. ② P(y=1|x, S=1) = P(S=1|y=1)p(y=1|x) / [P(S=1|y=0)p(y=0|x) + P(S=1|y=1)p(y=1|x)]; 분자·분모를 P(S=1|y=0)p(y=0|x)로 나누면 c·e^{β₀+β₁x}/(1 + c·e^{β₀+β₁x}), c = P(S=1|y=1)/P(S=1|y=0) → e^{(β₀ + log c) + β₁x}: **절편만 log c만큼 이동, 기울기 불변**. ③ 믿을 것: 기울기 = log OR, z·p-value; 믿으면 안 되는 것: 절편·예측확률(½ 규칙 닫힘). ④ 유병률 π를 알면 절편 복원 β̂₀* = β̂₀ + log[π/(1 − π)] − log[π̃/(1 − π̃)](남아공 자료: 환자 비율 0.346, 유병률 0.051 → ≈ −2.32). ⑤ "1 + exp라는 특수한 꼴" 때문에 로지스틱만 가능(일반 회귀·랜덤포레스트·부스팅은 보존 안 됨); 코호트는 시간·비용, 환자-대조군은 논리를 뒤집는 설계; 대조군은 환자의 약 5배까지 이득.
- 근거: 4차시 §2.5–2.6(판서 19:47–19:59, 녹음1 49:45–59:48, 녹음2 01:28–09:57) · 모범답안: 예상문제 모음 2부(4차시) Q4·Q5·Q16.
- 프롬프트: Q33.

**Q34 [A·유도] 2클래스·p = 1·공통분산에서 Bayes 분류기(사후확률 ≥ ½)로부터 LDA 판별점수 δₖ(x)를 유도하라. 어떤 항이 왜 사라지며 분산이 다르면 무엇이 달라지는가? 모수 추정식과 "왜 로지스틱 대신 판별분석인가"(complete separation)도 쓰라.**
- 답안 핵심: ① Bayes 정리: P(Y=k|x) = πₖfₖ(x)/Σₗπₗfₗ(x); ½ 규칙 ⟺ π₁f₁(x) ≥ π₀f₀(x) ⟺ f₁/f₀ ≥ π₀/π₁(사전확률 같으면 밀도 높이 비교). ② fₖ = N(μₖ, σ²) 대입 후 로그: log πₖ − ½log(2πσ²) − (x − μₖ)²/(2σ²); 양변 공통인 −½log(2πσ²)와 x²/(2σ²)이 지워짐 → δₖ(x) = x·μₖ/σ² − μₖ²/(2σ²) + log πₖ(x의 1차식 = Linear). 경계: π 같으면 (μ₁ + μ₂)/2. ③ 분산이 다르면 log σₖ²·x²/σₖ² 항이 남아 2차식 → QDA("σ²은 경계의 복잡도를 조절"). ④ 추정: π̂ₖ = nₖ/n, μ̂ₖ = 클래스 평균, σ̂² = ΣₖΣᵢ(xᵢ − μ̂ₖ)²/(n − K)(평균 개수만큼 자유도 보정). 덧셈·뺄셈만으로 구해져 수십억 건도 가능(로지스틱은 역행렬 n³). ⑤ complete separation: x의 어떤 경계로 y가 완전히 갈리면 로지스틱 우도가 β → ±∞로 "박살" — 계수·신뢰구간이 터무니없이 커짐(rare outcome에서 흔함); 판별분석은 y별로 X 분포를 따로 적합하므로 이런 일이 없음. ⑥ 로지스틱 = p(y|x) 직접(X 분포 불필요, 생성 불가) vs 판별분석 = p(x|y)·p(y)(생성형, X 분포가 맞아야). 교수님: "LDA·QDA는 실무에서 거의 안 쓰고 naive Bayes를 이해하기 위한 순서".
- 근거: 4차시 §2.8–2.9(판서 21:07–21:22), 5차시 §2.1–2.2(판서 18:37–18:47, 녹음1 09:27–28:30), 교재 식 (4.10)·(4.13)–(4.15) · 모범답안: 예상문제 모음 3부(5차시) Q18–Q20·Q31·Q35.
- 프롬프트: Q34.

**Q35 [B·유도·서술] 다변량 정규분포의 밀도식·Σ의 성질·모수 개수·등고선, 교수님이 "외우라"고 한 두 성질, p > 1 LDA 판별함수와 QDA의 차이를 쓰라.**
- 답안 핵심: ① f(x) = (2π)^{−p/2}|Σ|^{−1/2} exp(−½(x − μ)ᵀΣ⁻¹(x − μ)); (x − μ)ᵀΣ⁻¹(x − μ)는 Mahalanobis 거리²(1변량의 (x − μ)²/σ²), |Σ|^{1/2}은 일반화 분산(σ 대응). ② Σ = E[(X − μ)(X − μ)ᵀ], 임의의 z에 Var(zᵀX) = zᵀΣz ≥ 0 → 양반정치; 모수 p(p + 1)/2(p²으로 증가 — "가장 힘든 파트는 Σ"). ③ 대각 Σ ⇒ 밀도가 곱으로 분해 = 독립("상관 0 ⇒ 독립은 정규에서만"). ④ 등고선 = 타원: 중심 μ, 축 방향 = Σ의 고유벡터, 반축 길이 c√λᵢ; Σ = [[2,1],[1,2]] → λ = 3, 1, 장축 (1,1)/√2, 길이비 √3. ⑤ 외울 것: 선형결합 aᵀX는 정규, 부분벡터도 정규; E(AX) = Aμ, Cov(AX) = AΣAᵀ; 조건부분포도 정규. ⑥ δₖ(x) = xᵀΣ⁻¹μₖ − ½μₖᵀΣ⁻¹μₖ + log πₖ(공통 Σ → xᵀΣ⁻¹x 상쇄 → 선형); Σₖ가 다르면 QDA(2차). GEE·mixed model은 다변량 분포 대신 추정방정식·조건부분포로 상관을 다루는 두 탈출구.
- 근거: 5차시 §2.3–2.4(칠판 19:22, 녹음1 29:10–60:51), 교재 식 (4.18)–(4.19) · 모범답안: 예상문제 모음 3부(5차시) Q21–Q24·Q34.
- 프롬프트: Q35.

**Q36 [B·서술] naive Bayes의 가정과 식, 왜 "naive"이며 왜 Σ 문제를 피하는지, 혼합형 변수 처리와 Laplace 평활, 교수님의 실무 평가를 쓰라.**
- 답안 핵심: ① 클래스 안에서 변수들이 조건부 독립: fₖ(x) = Πⱼ fₖⱼ(xⱼ) — Σ의 비대각을 0으로 두는 "무대뽀" 가정이라 naive; 모수가 p(p + 1)/2에서 p로. ② 그래도 "Σ를 올바르게 구하려는 노력보다 결과가 좋다는 게 증명"; 고차원(유전체 4만 차원·표본 수백)에서 판별분석을 쓰려면 이 길뿐. ③ 연속 변수는 적당한 분포(정규·커널), 이산 변수는 클래스별 범주 빈도 → 곱; 역행렬이 없어 10억 건도 빈도만 세면 됨 — "quick and dirty의 선도주자", 예비분석에 먼저 돌려 보라. ④ 훈련에 없던 범주가 테스트에 나오면 확률 0 → 곱 전체 0 → Laplace 평활 (빈도 + α)/(n + α·범주수), e1071::naiveBayes(laplace = 1) 권장(기본 0). ⑤ 로지스틱과 LDA는 각각 조건부·완전 우도를 최대화(교재 용어).
- 근거: 5차시 §2.5(녹음2 08:18–24:16), 6차시 §2.8, 교재 p.149 · 모범답안: 예상문제 모음 3부(5차시) Q29·Q32, 2부(4차시) Q11.
- 프롬프트: Q36.

### 6. 기초 — 통계적 학습·편향–분산·선형회귀 (1~3차시)

**Q37 [A·유도] 기대 검정 MSE의 편향–분산 분해를 유도하라. 어떤 가정이 필요하고 교차항은 왜 사라지는가? ("연습 삼아서라도 유도를 해 보세요. 꼭 필요하다고 생각합니다")**
- 답안 핵심: ① 설정: y₀ = f(x₀) + ε, E(ε) = 0, Var(ε) = σ², ε은 훈련자료로 만든 f̂과 독립(x₀는 훈련에 쓰지 않은 점). ② m = E[f̂(x₀)]로 두고 y₀ − f̂ = ε + (f − m) + (m − f̂)로 쪼개 제곱: E(y₀ − f̂)² = σ² + (f − m)² + E(m − f̂)² = Var(ε) + Bias² + Var(f̂). ③ 교차항: E[ε(f − f̂)] = 0(독립·평균 0), (f − m)E(m − f̂) = 0(m의 정의), E[ε(m − f̂)] = 0. ④ 기댓값은 "같은 분포에서 훈련셋을 반복 추출해 x₀에서 평가"한 평균; 모든 x₀에서 평균하면 교재 Fig 2.12의 곡선. ⑤ 해석: 유연할수록 편향↓·분산↑ → U자("U shape이 universal"), 필요한 변수가 다 들어온 뒤에는 분산만 늘어남; σ²는 환원 불가능한 하한. ⑥ 1차시의 "최적 예측자 E[Y|X]" 유도와 같은 완전제곱 + 교차항 소거 기법.
- 근거: 2차시 §2.6(노트 p.36, 녹음3 11:17–13:54), 3차시 §2.1, 교재 식 (2.7) · 모범답안: 예상문제 모음 1부(2차시) 서술형.
- 프롬프트: Q37.

**Q38 [C·서술] Y = f(X) + ε에서 f를 왜 추정하는가(prediction vs inference)? 환원·비환원 오차를 쓰고 제곱오차 아래 최적 예측자가 E[Y|X]임을 보여라.**
- 답안 핵심: ① 예측(f̂은 블랙박스여도 됨, 새 X의 Y) vs 추론(어떤 변수가 어떻게 영향 — 형태를 알아야). 예측에 강한 변수 ≠ 개입 효과가 있는 변수(라이터 소지와 폐암). ② E(Y − Ŷ)² = [f(X) − f̂(X)]²(reducible) + Var(ε)(irreducible). ③ (Y − g(x))² = (Y − E[Y|x] + E[Y|x] − g(x))² → 조건부 기댓값에서 교차항 0 → E[(Y − E[Y|x])²|x] + (E[Y|x] − g(x))² → g*(x) = E[Y|X = x]("예측을 잘하려면 조건부 평균만 잘 추정하면 된다"). ④ 실제로는 X = x인 자료가 없어 이웃 평균(KNN)·커널로 완화 — 이웃 크기는 tuning parameter. ⑤ 통계학 = β에 관심(β̂, s.e., CI), 기계학습 = Ŷ에 관심("Two cultures").
- 근거: 1차시 §2.1·§2.4–2.6, 2차시 §2.1 · 모범답안: 예상문제 모음 1부(1·2차시).
- 프롬프트: Q38.

**Q39 [C·비교] parametric vs non-parametric, KNN 회귀와 차원의 저주, 유연성–해석력 trade-off를 설명하라.**
- 답안 핵심: ① 모수적: f의 형태를 가정(선형) → 계수 추정으로 축소; 적은 자료·해석 쉬움, 형태가 틀리면 나쁨. 비모수적: 형태 가정 없음(spline, KNN); 넓은 f를 맞추지만 많은 자료 필요. ② KNN 회귀 f̂(x₀) = (1/K)Σ_{N₀} yᵢ; K 작을수록 유연(훈련오차↓, 분산↑). ③ 차원의 저주: p ≤ 4·N 큼이면 잘 되지만 고차원에서는 이웃이 멀어짐 — 10차원에서 자료의 10%를 잡으려면 각 좌표의 80%를 덮음; 독립 N(0,1) 성분이면 d(X, 0) ≈ √p, d(X, Y) ≈ √(2p), 각 ≈ 90° → "가깝다"가 의미를 잃음. ④ 유연할수록 해석력↓(subset/lasso → OLS → GAM/trees → bagging/boosting/SVM); 예측만 목적이어도 단순한 모형이 과적합을 피해 더 정확할 때가 많음; "표본 수에 따라 허용되는 복잡도가 제한 — 희귀 질환일수록 단순한 모형".
- 근거: 1차시 §2.7–2.9, 2차시 §2.2–2.4 · 모범답안: 예상문제 모음 1부.
- 프롬프트: Q39.

**Q40 [C·서술] 훈련 MSE vs 검정 MSE, 과적합의 뜻, Bayes 분류기와 Bayes 오류율, KNN 분류, double descent를 한 줄씩 설명하라.**
- 답안 핵심: ① 훈련 MSE는 유연성에 단조 감소(변수를 늘리면 0까지 = 내삽), 검정 MSE는 U자; 훈련 MSE 작고 검정 MSE 크면 과적합 = "에러(ε)까지 적합". 모형 선택 = 적합에 쓰지 않은 자료의 오차를 최소화하는 모형. ② Bayes 분류기 ŷ = argmaxⱼ P(Y=j|X=x)(이진이면 ½ 규칙) — 0-1 손실의 조건부 risk를 각 x에서 최소화; 어떤 분류기도 이보다 낮은 오류 불가; "베이지안과는 상관없다". Bayes 오류율 1 − E[maxⱼ P(Y=j|X)] = 분류의 비환원 오차(모의자료 0.1304). ③ KNN 분류: 이웃 비율로 P(Y=j|x) 추정 후 다수결("민주적"); K = 1 훈련오류 0, K = 100 거의 직선. ④ double descent(Belkin 2019): 보간 문턱을 넘은 과모수 영역에서 검정오차가 다시 내려감 — "2019년에 깨짐", 한 줄 수준 대비. ⑤ Generalization(같은 분포) vs generalizability(다른 분포: 2026 → 2027, 한국 → 미국)는 교수님 고유 구분.
- 근거: 2차시 §2.5·§2.7, 3차시 §2.1–2.2, 교재 식 (2.10)–(2.12) · 모범답안: 예상문제 모음 1부(2·3차시).
- 프롬프트: Q40.

**Q41 [C·비교] 선형회귀를 보는 두 관점(true model vs projection), likelihood와 MLE = OLS, Fisher 정보, 경사하강 → 신경망("One idea, many models")을 설명하라.**
- 답안 핵심: ① True model view: E(Y|X) = xᵀβ가 실제 생성 메커니즘, β는 참값 — 통계학(검정·CI); projection view: β* = argmin E(Y − Xᵀb)² 최선의 선형 근사 — 기계학습(예측). "참 관계가 선형이라고 믿는 일은 드물다"(교재 각주). ② L(β) = Π(2πσ²)^{−1/2}exp{−(yᵢ − xᵢᵀβ)²/2σ²}; log → const − RSS/(2σ²) → MLE = OLS; 로그가능도의 곡률(−2계 미분) = Fisher 정보 = XᵀX/σ² → Var(β̂) = σ²(XᵀX)⁻¹ → s.e.·CI·검정은 모두 우도에서. ③ ML은 분포 대신 손실(제곱오차)을 최소화; "통계의 −log 우도 = ML의 loss"; hinge loss처럼 분포에 대응하지 않는 손실도 있음. ④ 경사하강 β ← β − η∇RSS, ∇RSS = −2Xᵀ(y − Xβ); 같은 손실에 비선형 층을 쌓으면 신경망; 로지스틱 → cross-entropy → softmax도 같은 틀. ⑤ Ch.3 나머지(추론·변수선택·R²·KNN 비교)는 "이미 끝난 것"으로 교재 자습.
- 근거: 3차시 §2.3–2.6(판서 19:26·20:08), §2.9 · 모범답안: 예상문제 모음 1부·2부(3차시).
- 프롬프트: Q41.

**Q42 [B·서술] "문헌을 볼 때 가장 먼저 확인할 것은 loss function"이라는 말의 뜻을 설명하고, 0-1 손실·제곱오차·cross-entropy·hinge가 각각 어떤 문제의 정의인지 쓰라.**
- 답안 핵심: ① 손실함수는 "연구자가 문제 자체를 정의하는 것" — 어떤 오차를 줄이려 하는지가 곧 방법의 목표; 같은 자료도 손실이 다르면 다른 모형이 최선. ② 제곱오차(연속, 미분 쉬움, OLS와 연결) → 최적 예측자 E[Y|X]; 0-1 손실(분류의 표준이지만 미분 불가, "무조건 써야 하는 건 아님") → Bayes 분류기; cross-entropy = 베르누이/다항 −log 우도(0-1의 대리); hinge(SVM, 분포에 대응 없음, 확률 해석 없음 — 확률 경로 vs 경계 경로의 "역사의 분기점"). ③ 손실을 "갈아 끼우면" 같은 최소화 틀(경사법)로 풀린다 — 전형적 supervised learning.
- 근거: 1차시 §2.6, 2차시 §2.5·§2.7(노트 p.30·p.37), 3차시 §2.9.
- 프롬프트: Q42.

### 8. 유형별 답안 틀

- **유도형**(Q1–Q3·Q14–Q16·Q22·Q27·Q33–Q34·Q37): 설정과 가정 → 식 세우기 → 미분/전개 → 경우 나누기 또는 항 상쇄 이유 → 결과 식 → 극한·특수 경우 확인 → 한 줄 해석(교수님 표현 인용). 기호 정의(λ, hᵢ, πₖ, c 등)를 먼저 쓰고, 어떤 손실 척도(λ/2 vs λ)인지 명시.
- **계산형**(Q2·Q10·Q15·Q18·Q24·Q29): 식 → 숫자 대입 → 중간값 → 답(단위·소수 둘째 자리) → 상식 점검(PPV는 π가 작으면 급락, 라쏘는 문턱 안이면 0).
- **서술형**(Q5·Q7·Q13·Q17·Q21·Q23·Q28): 결론 한 문장 → 이유 2~3개(번호) → 수업의 예(Credit·남아공·V23·Default) → 교수님의 결론 문장("무조건 CV", "percentile이 무조건 좋음") → 한계·주의.
- **비교형**(Q8·Q11·Q13·Q39·Q41): 표(기준 열: 가정 / 목표 / 식 / 장단점 / 언제 쓰나) → 교수님의 실무 평가 한 줄.
- **실습 해석형**(Q9·Q12, 6-4 실습): 출력에서 ① 방법 고정 ② λ 격자·곡선 ③ 표준화 ④ 재적합 ⑤ 반복·seed ⑥ 손실/벌점 기본값 순으로 점검 → 의심되는 점 → 재실행 지시 → 재해석 → AI 사용 리포트 문장.
