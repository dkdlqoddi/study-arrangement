#### 5-1. 강의 1 (이진 분류기 성능, 녹음1) — 반복·강조한 개념

"C-statistic은 AUC와 완전히 똑같다" (06:11, 15:43, 16:04). Mann–Whitney U까지 "3개가 다 똑같은 거예요"(16:34). 증명은 고등학교 구분구적법 수준이며 "폭은 D가 아니라 D bar — 확대해서 보세요"(12:34–12:44). [B07–B10, 칠판 18:51]

"C statistic은 rank에만 의존합니다 — 일단 rank에만 의존한다는 것만 기억하도록" (10:54–11:36). 모든 점수에 5를 더하거나 2를 곱해도 안 바뀐다. 이것이 장점이자 단점. [B07]

"AUC가 높으면 classifier가 다 좋을 거라고 생각하고 있어요. 그런데 그건 아니다" (18:14). AUC는 두 그룹을 잘 분리하는지만 말하지 확률값이 진짜 위험인지는 말하지 않는다 → discrimination measure(17:36). 그것을 말해 주는 것은 calibration measure(19:31): 점수 0.2인 사람들을 모으면 실제 발생률이 0.2이기를 바란다; 0~1을 10등분해 y≈x를 확인(21:48–22:10); Brier score(20:01, 45:08). [B12–B14]

**"연구자들이 AUC에 목을 매달고 있는데 … 무비판적으로 무조건 AUC를 보는 게 좋은 접근은 아닐 수 있다"**

(20:05–20:25); "결론적으로 AUC는 rank based measure"(20:36). [B12]

AUC의 한계 가운데 "저 개인적으로는 3번이 굉장히 중요하다" (24:00): odds ratio가 커서 중요해 보이는 변수를 넣어도 등수가 안 바뀌면 AUC는 0.01 정도밖에 안 움직인다; AUC를 얼마나 올렸나로 변수 중요도를 평가하는 것은 매우 위험(24:46–25:06). 부분 AUC는 관심 임계값 범위(예: 150~200)에서 따로 계산(23:21–23:54). 비용 차이는 AUC가 반영하지 못한다(25:34). [B15]

민감도·특이도는 유병률에 의존하지 않지만 PPV·NPV는 유병률에 심각하게 의존(27:18–27:33). 의료기기를 팔 때·비교할 때는 민감도·특이도(진단 성능), 환자에게 필요한 것은 PPV·NPV(28:13–29:11). "sens 0.99, spec 0.98 에 유병률 0.0000…을 직접 넣어 보세요 — PPV가 20~30%가 채 안 된다"(30:58); "다른 병원도 가봐야 해"가 PPV의 직감(노트 p.29). [B15, 칠판 19:03–19:08]

학습 손실과 평가지표의 불일치 = "철학적 issue" (40:18–42:29): 0–1 loss를 목표로 했지만 binomial/cross-entropy(negative log-likelihood)로 학습하고, 평가는 AUC로 한다. AUC로 평가할 거면 AUC를 최대화하도록 학습하는 게 논리적이지만, 그러면 calibration이 안 된 모델이 나올 수 있다(44:22). 실용주의: 하나의 지표만 optimize하지 말고 여러 지표를 다 보고(43:06); TRIPOD+AI는 subgroup별 성능 저하를 살피라고 권고(45:00). [B17, 칠판 19:20]

유병률이 낮으면 PPV·F1이 낮게 나오니 너무 실망하지 말고 문맥을 설명하며 set of index를 함께 보고(46:05). [B19]

naive Bayes는 큰 자료에서 가장 빠른 "dirty"한 출발점; 범주형·연속형이 섞여 있어도 상관없고 Laplace smoothing을 쓴다(46:58–48:13). [S40–S42]

일화: 개표방송의 95% 신뢰구간 — 250곳 중 20곳 틀리는 게 당연하지만 "틀리면 안 되는 문제들"이 많다 (36:38); 학생 질문 "99%로 높이면?" → "0석부터 300석"(38:30). [B17]

#### 5-2. 논문발표·강의 2 (부트스트랩, 녹음2) — 반복·강조한 개념

논문발표 도입: "LLM이 이겼다 — 뭘 갖고, 무슨 measure로? C 인덱스가 높았다는 거야?"(00:16) — 분류기 평가지표의 문제의식을 LLM 평가로 확장. JAMA 2025 LLM 평가 리뷰를 직접 읽어 보기를 추천(00:49). 발표 뒤 코멘트: fairness 등은 이후 수업에서 다룸, 2024년 논문이라 최근 것은 각자 업데이트(34:31); 보건 분야 AI 활용은 임상보다 더디니 미리 준비(33:45). [4장]

"Bootstrap = statistical inference의 최강 도구, Cross-validation = tuning parameter·model selection의 최강 도구. 기본 원리를 익히고 문맥별 modification을 이해하라"(34:56). [T01]

Bootstrap은 통계적 추론의 최후의 보루, Efron(스탠퍼드)이 개발(35:59); 어원은 신발끈 — 자기 데이터로 자기를 끌어올림(36:27). 만병통치는 아니지만 문제의 99%에 적용 가능; 가장 중요한 용도는 standard error·신뢰구간(uncertainty assessment)(37:10). 계산량이 크다 — 공짜가 아니며 환경·건강에 미치는 영향도 고민할 시점 (38:05). [T01–T02]

"모든 것의 끝판왕은 distribution" — F를 알면 반복 생성으로 모든 불확실성을 계산할 수 있지만 실제로는 F 를 모른다(41:55); F를 모르면? → F̂을 대신 넣는다 = bootstrap(42:23). [T02, 칠판 20:17·20:20]

경험분포함수 = 각 관측치에 1/n을 주는 계단함수; 샘플이 적당히 많으면 원래 분포에 무조건 가까이 간다 — "역사상 가장 중요한 이론 중 하나"(Glivenko–Cantelli, 44:46). nF̂ₙ(x) ~ Binomial은 고등학생도 하는 문제, sup 은 maximum이라 생각하면 된다(49:42). 같은 샘플 크기로 복원추출해야 uncertainty가 생긴다(47:18). [T03–T04]

B = 1000은 "그때 당시 큰 숫자"가 굳은 것(52:05). median의 신뢰구간처럼 공식이 burden인 통계량에 bootstrap을 쓰며, 상상할 수 있는 거의 모든 통계량에 적용(53:40–55:16). 공짜가 아니다 — 회귀 한 번에 하루면 bootstrap은 1000일; 이론적 연구도 여전히 의미 있다, "너무 한량스럽게 바라보지 마세요"(56:22). [T05–T06]

bias 부분은 중요하지 않다; 제일 중요한 건 confidence interval(59:21). normal bootstrap interval = θ̂ ± 2·se_boot(θ̂은 원자료 추정치, 59:28) vs percentile interval(1000개 정렬해 앞 25번째·뒤 25번째) — "개인적으로 훨씬 더 즐겨 쓰고 추천", "무조건 좋다, 항상 보고한다고 생각하라"(60:29, 63:10). ±2se에는 정규(대칭) 가정이 있고 percentile은 비대칭을 반영(61:18). [T07–T10]

회귀·상관계수의 신뢰구간: 실무적으로 제일 중요한 것은 resampling unit 설정 — (xᵢ, yᵢ) 쌍이 하나의 unit, 컴퓨터에서는 index만 뽑는다(64:22). 3000번이면 25·25가 아니라 가운데 95%가 되도록 자르라 — "이 정도의 유연함은 있기를"(66:03). 코드는 GPT·Claude로(66:19). [T11–T14, 칠판 없음]

#### 5-3. 강의 3 (부트스트랩 마무리·교차검증, 녹음3) — 반복·강조한 개념

부트스트랩 표본으로 학습하고 전체 자료로 평가하면 training set이 평가셋에 다시 들어간다(01:15). 한 번 뽑을 때 안 뽑힐 확률 1−1/n, n번이면 (1−1/n)ⁿ → 1/e ≈ 0.37: 63%가 뽑히고 37%는 안 뽑힌다(02:10–03:23, 칠판 21:04). 안 뽑힌 37%로 평가하는 것이 OOB(out-of-bag) — "OOB라는 단어가 생각보다 많이 등장", random forest가 많이 씀(04:31). [T15–T16]

예측오차는 OOB냐 CV냐? "무조건 cross validation"(06:03). 정리: statistic의 uncertainty(s.e.·CI)는 bootstrap, prediction error의 evaluation은 cross validation — "거의 모든 문제에 적절한 답안"(06:12). [T17–T18]

대원칙: "평가할 때 사용한 데이터셋은 모형의 학습에 절대 사용돼서는 안 된다"(06:50). training error(적합에 쓴 자료로 평가) vs test error(적합에 안 쓴 자료로 평가)(06:33). LLM도 같다 — 학습되지 않은 데이터를 넣어 보라(07:21). 나중에 Nature·PNAS·JNCI의 실패 논문 사례를 보여 주겠다고 예고. [V03]

분할 비율에 정답 숫자는 없다 — 자료 크기에 따라 9:1~5:5(08:31). 분할 전에 random shuffling 한 번(시간순·남녀 순 입력 대비, 09:43). [V04–V05]

CV의 목적 = model selection(= tuning)(10:30). "R²는 절대 쓰면 안 되는 1번 measure. R²로 모델을 고르는 것은 금기"(10:46). AIC·BIC·CV·test error는 다 연결되어 있다(11:32). [V06]

seed마다 다른 곡선: 오차값의 변동은 크지만 best model(2차)은 robust(13:32). 반반 나눠 swapping → "validation을 교차했다고 해서 cross validation"(15:37). [V07–V08]

k-fold: (k−1)/k로 학습, k번 반복; 전통적으로 10, 요즘은 5·3-fold까지(17:03–17:25). LOOCV = n-fold: randomness가 없다(장점), 시간이 엄청 걸린다(단점)(18:14). 2-fold와 LOOCV 사이의 bias–variance trade-off; "유명한 사람이 10이 좋았다" → 10으로 굳음(19:07). [V09–V13]

LOOCV 항등식: hᵢ = hat matrix 대각, 1−hᵢ로 나눠 한 번 피팅으로 LOOCV와 정확히 같은 값(20:43); 증명은 "지금은 Claude·GPT가 잘 해 준다"(20:15). binary·count 자료에서는 근사식 = AIC = "LOOCV를 그냥 빨리 한 것"(Stone, 22:08). [V14]

왜 10-fold인가: seed를 바꿔도 test error가 안정적이고 같은 모델을 골라 준다 — "실제 prediction error라고 써도 문제없다"는 주장까지 있지만 "저는 많이 동의하진 않습니다만"(23:03–23:38). [V15–V16]

#### 5-1. 강의 1 (교차검증, 녹음1) — 반복·강조한 개념

**"bootstrap은 통계적 불확실성을 평가하는 방식, cross validation은 모형의 예측 성능을 평가하는 방식 — 그**

게 가장 중요한 메시지" (00:22–01:13). [V01]

분할 평가 원칙: "너무나 당연해 보이는 데이터셋 split에서 모형을 평가 … 아직도 많은 [문헌]에서 틀리고 … 여러분들께서는 그러지는 않으시길 바랍니다"(01:25–01:47); 적합에 쓴 자료로 다시 평가하면 "너무 성능이 좋은 것처럼 나온다"(02:17). 분할 비율은 "8대2, 7대3, 5대5 … 법칙이 있는 건 아니다"(02:59–03:15). [V03–V05]

통계학 vs 머신러닝의 모형 선택: 통계학은 제곱항 계수가 0인지 검정, 머신러닝은 검정을 꺼리고 검증셋 예측 오차가 작은 쪽을 고른다 — "computer science 스타일의 모델 선택"(03:52–05:35). 로지스틱 제곱항도 "이 차이가 정말 없는 게 아니냐 이런 거 가설검정은 잘 안 따지고 … 머신러닝 커뮤니티 스타일"(34:41–34:50). [V06, V20]

가장 많이 반복된 메시지 — CV는 선택(위치)에는 믿을 만하고 평가(값)에는 조심: seed가 달라도 "어디서 최적 값을 갖냐는 … 꽤 달라지지는 않는데 예측오차 값 자체는 상당히 변동"(06:11–06:51); "주의해야 될 것은" 10-fold가 stable하다는 것이지 "숨겨놓은 데이터로 평가했을 때 나오는 prediction error를 보여준다는 뜻은 아닙니다. 이해되나요?"(24:01–24:17); CV 오차가 "19 정도가 나왔다 그럼 … 예측성능이 19인 거냐 그렇게는 설명을 안 해 … 어디서 최소값을 갖는가만 중요하게 판단"(24:53–25:23); 세 모의자료에서 "best model을 골라주는 건 큰 차이는 없다. 그러나 커브 자체가 일치하지 않는다 … 조금 기억을 해서 조금 더 조심하면"(27:13–27:28); 간격은 있지만 "reliable한 result"(39:15–39:19). [V07, V15, V17, V22]

K와 교수님 실무: "예전에는 10이었는데 … 요새는 5나 3까지"(07:56–08:01); 몇십만 건 이상에서는 LOOCV를 거의 안 하고 5-fold·10-fold, 더 크면 3-fold, LOOCV는 관측 수백 개일 때만(13:17–13:45). [V09, V12]

CV_(K) 식: "약간 괴팍하게 써서 그러는데 … n_k가 지워지기 때문에 … 모든 관측치에 대해서 예측값과 실제값의 차이의 제곱의 총합을 sample size로 나눈 것", "다만 위에 있는 값은 감춰졌을 때만 구하는 거예요"(10:09–10:53). n이 K의 배수가 아니면(247개) 50·50·50·50·47로 나누면 되고 "별로 영향도 없는 고민"(08:58–09:16). [V10–V11, 칠판 18:49]

LOOCV: "여러분이 좀 알아둬야 될 것은 … 데이터를 어떻게 shuffle하더라도 … 똑같습니다", "누구라도 다 똑같은 결과"(13:49–14:18); 샘플 1억 개면 적합 1억 번(12:53). 한 번 적합으로 LOOCV를 얻는 공식은 70·80년대 "가장 중요한 연구"였지만 "Gaussian outcome에 대한 선형회귀 모형에서만 존재"(20:51–21:39) → 일반적으로는 "K는 5-fold, 10-fold가 recommend"(21:45–21:51). [V12–V14]

주의 — 강의 표현과 교재가 반대인 곳(K의 편향–분산, 22:05–22:51). 강의: "K가 엄청 커지면 LOOCV가 되는데 그때 variance가 있나요? variance가 없잖아요 … bias가 굉장히 큰 값이 됩니다. 왜냐하면 training 데이터의 overlap이 너무 커요", "K를 2로 낮추면 … 어떻게 나누냐에 따라 결과가 굉장히 변동성이 크죠. 그렇지만 training 데이터는 완전히 overlap이 없는 … 에러들은 완전히 독립입니다. 그렇기 때문에 bias는 굉장히 없어요"(노트 p.8 V14 메모도 같은 표현). 교재(ISLR p.183–184)는 반대 방향이다: LOOCV는 훈련셋이 n−1개라 편향

**이 거의 없고, n개 적합이 거의 같은 자료로 훈련되어 출력이 고도로 상관되므로 분산이 크다. K = 2는 자료의**

절반만으로 학습하므로 검정오차를 과대추정하는 편향이 크다. 두 설명이 일치하는 점: ⓐ LOOCV의 약점은 훈련 자료의 overlap, ⓑ K = 2는 분할에 따라 크게 흔들린다, ⓒ K는 bias–variance trade-off를 조절하는 값이며 현실에서는 5 또는 10으로 고정(22:54–23:23: 안쪽에서 K를 튜닝하고 바깥에서 CV를 한 번 더 하자는 아이디어도 있었지만 계산이 버거움). 안전한 답안 요령: 교재 방향으로 쓴다 — "K↑(LOOCV 쪽): 편향↓·분산↑(훈련셋 overlap → 적합 간 상관)·계산↑ / K↓(2 쪽): 편향↑(학습 자료가 적음)·분할에 따른 변동↑ → K = 5 또는 10". 강의의 "LOOCV는 variance가 없다"를 쓰고 싶으면 "분할(seed)에 따른 무작위성이 없다는 뜻"이라고 함께 밝힌다(자세한 대조는 1장 V14–V15 주황 박스 ③④). [V14–V15]


fold별 오류의 표준오차: "이 에러들은 기본적으로 서로 correlation이 있는 quantity … 독립은 아니기 때문에 … 추천하지는 않습니다"(29:14–29:41) — V18 "Why not?"의 답. 그래도 "유용하게 쓰일 때"가 one-SE rule(29:48). [V18]

one-SE rule: CV 곡선은 하나만 보므로 "내 생각보다 복잡한 모형을 고를 수 있는 가능성"(30:52–31:03) → 최솟값 위아래 1 SE 안의 모델은 "prediction performance가 거의 같다고 봐야"(31:37–31:42) → "연구자가 조금 더 단순한 모델을 선호할 때가 많거든요. 해석도 … 계산도 더 간단"(31:53–31:56) → "one standard error bound 내에서 고를 수 있는 제일 단순한 모델"(32:10); 이때 SE는 "실제 올바른 공식은 아니지만 그냥 proxy로"(32:58–33:01). [V18]

훈련오류 곡선의 간격 = 편향: 파랑(훈련)이 갈색(검정)보다 아래인 "이것만큼이 … prediction error에 대한 bias", 이유는 "prediction error가 제일 작게끔 모형을 training시키잖아요"(36:02–36:17); "중요한 거는" 단순한 모형은 이 bias가 크지 않고, 모델 복잡도가 클 때 극단적으로 증폭(36:50–37:44); KNN 가로축 1/K는 "1이니까 … 가장 복잡한 모델, 0.01이면 K가 100이니까 … 단순한 모델 … order가 바뀌어 있는 것을 주의하세요"(37:52–38:12); 충분히 복잡하면 training error를 거의 0으로(38:26). **V23 — 고차원 자료와 올바른 CV: "중요한 메시지는 샘플에 비해서 predictor가 굉장히 큰 문제 … High**

Dimensional Data, 고차원 자료"(40:26–40:35), 보건·의료에 자주 나오는 세팅(39:51). 틀린 방식: 전체 50명으로 상위 변수를 선별한 뒤 CV — "이 방식은 모두 다 틀린 방식이다 … 나중에 평가할 데이터셋이 활용되고 있는가의 여부가 제일 중요"(44:57–45:16), "information leakage … 무조건 reject"(46:21–46:24). 올바른 방식: "1 단계를 하기 전부터 데이터를 분리 … 이 모든 step이 cross validation 안쪽에 있어야 돼요"(47:32–47:50) — 5-fold면 10명을 떼고 40명으로 선별·적합, 10명으로 평가, 5번 반복(48:04–49:15). 최종 모델은 "모든 데이터를 다 써서 … 최종적으로 한 번 더 피팅", 이 철학은 "ridge하고 lasso를 얘기할 때 … 여러 번 반복할 거예요"(49:51–50:07). nested CV는 "거의 모든 이론가들"이 추천하지만 실무에서 버거움(52:20–53:17). "이런 방식이 좋다고 전 얘기한 적이 없습니다" — 상관 높은 변수를 뽑는 방식은 "평가받아야 하는 대상"(53:35–53:54). [V23]

여담: 자가보고 키(169.9 vs 170)와 measurement error — "bias가 있는 데이터는 샘플 사이즈가 커지면 bias가 강화"(17:19–17:34); 심야 TV 전화 설문은 selection bias, "치우쳐진 집단을 100만 조사하시면 60명을 랜덤하게 조사하시는 것보다 결과가 좋지 않습니다"(20:15). [V12 묶음, 해당 슬라이드 없음]
