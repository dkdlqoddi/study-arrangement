### 1. 질문 유형별 템플릿 (P1~P9)

대괄호 [ ]만 바꿔 보낸다. 모두 P0 뒤에 보내는 것을 전제로 짧게 만들었다.

- **P1 개념 설명** — 「[개념]을 수업 자료 기준으로 설명해 줘: 정의 → 왜 필요한가 → 식 → 수업에서 든 예 → 교수님이 강조한 한 문장 → 출처.」
- **P2 비교** — 「[A]와 [B]를 가정 / 목표 / 식 / 장단점 / 언제 쓰나 5행 표로 비교하고, 교수님의 실무 평가를 한 줄 덧붙여 줘.」
- **P3 단계별 유도** — 「[결과]를 수업 자료의 흐름대로 단계별로 유도해 줘. 각 단계에서 쓰는 가정과 사라지는 항의 이유를 밝히고, 마지막에 극한·특수 경우로 검산해 줘.」
- **P4 계산** — 「다음을 계산해 줘: [식과 숫자]. 식 → 대입 → 중간값 → 답(소수 둘째 자리) 순서로 쓰고, 답이 상식적인지 한 줄로 점검해 줘.」
- **P5 내 답안 검증** — 「아래 내 답안을 자료와 대조해 틀린 곳·빠진 곳·더 정확한 표현을 짚고, 고친 답안을 다시 써 줘. 추측으로 보충한 부분은 [일반]으로 표시해. [답안]」
- **P6 코드 요청(능형·라쏘)** — 3절의 프롬프트를 그대로 사용.
- **P7 AI 출력 검토(감사)** — 「아래 코드와 출력을 검토해 줘: ① 방법(라쏘/능형)이 명시·고정됐나 ② λ 격자 범위와 CV 곡선 모양(최솟값이 격자 끝인가) ③ 설명변수 표준화 ④ 고른 λ로 전체 자료 재적합 ⑤ 반복마다 같은 모형·같은 fold인가 ⑥ 기본 벌점(LogisticRegression의 C)·alpha 의미(scikit-learn vs glmnet). 문제가 있으면 고친 코드와 재실행 결과를 줘. [코드·출력]」
- **P8 답안 다듬기** — 「다음 핵심을 빠짐없이 넣어 [N]점짜리 서술형 답안을 [M]줄로 써 줘. 각 문장 끝에 근거 출처를 괄호로 달아. 핵심: [예상 질문 문서의 답안 핵심을 붙여 넣기]」
- **P9 AI 사용 리포트 생성** — 「이 대화에서 내가 쓴 프롬프트 중 핵심 2~3개를 원문 그대로 뽑고, 내가 확인·수정한 설정(방법 고정, λ 격자·CV 곡선, 표준화, 재적합, seed)과 최종 결과를 4절 템플릿에 채워 줘. 내가 직접 판단한 부분은 비워 둬.」

### 2. 예상 질문별 한 줄 프롬프트 (Q1~Q42)

**축소법 (A급)**
- **Q1** → 8차시 §2.12 · 「1차원 라쏘 (y − β)² + λ|β|의 최소해를 β > 0, β < 0, 그 사이 세 경우로 나눠 유도하고 soft thresholding 식으로 정리해 줘. λ = 4에서 y = −1.5, 5의 해를 계산하고 능형 해 y/(1 + λ)와 비교해 줘. 판서(20:46) 표현을 인용해.」
- **Q2** → 8차시 §2.8 · 「(y − β)² + λβ²의 해 β̂ = y/(1 + λ)의 기댓값·편향·분산·MSE를 구하고, MSE를 최소화하는 λ*를 유도해 줘. β = 2, σ² = 1일 때 λ*와 MSE 값, 그리고 왜 실제로는 CV로 λ를 고르는지 교수님 표현으로.」
- **Q3** → 8차시 §2.6 · 「(Y − Xβ)ᵀ(Y − Xβ) + λβᵀβ를 미분해 능형 닫힌 해를 유도하고, λ = 0과 λ → ∞의 극한, p > n에서도 해가 유일한 이유(고윳값)를 설명해 줘. 절편 처리도.」
- **Q4** → 7차시 §2.11–2.13, 8차시 §2.5 · 「능형·라쏘의 제약 형태와 벌점 형태를 쓰고 라그랑지안으로 연결해 줘(s와 λ의 방향, 극단값). p = 2에서 RSS 등고선과 원·마름모 그림으로 왜 라쏘만 계수를 정확히 0으로 만드는지 설명하고, 십자가·elastic net 모양도 한 줄씩.」
- **Q5** → 7차시 §2.11 · 「계수에 제약을 걸면 왜 예측이 좋아질 수 있는지 편향–분산으로 설명해 줘. 교수님의 '세상에 공짜가 없다' 맥락과 교재 Fig 6.5의 U자, n = 50·p = 45 예를 포함해.」

### 3. 실습형(코드) 프롬프트 세트 — P6

시험 문제가 "자료를 주고 라쏘/능형을 적합해 보고하라"는 형태라면 아래를 쓴다. 괄호의 열 이름·파일명만 바꾼다. 교수님 점검 항목이 모두 들어 있다.

**P6-1 라쏘/능형 + CV (Python scikit-learn)**

```
반응 y(연속), 설명변수 X(열: [x1, …, xp])인 자료 [파일명/데이터프레임]가 있어. Python scikit-learn으로 다음을 해 줘.
1) 설명변수 표준화(StandardScaler)를 파이프라인 안에 넣고,
2) 방법은 [라쏘 Lasso / 능형 Ridge]로 고정해 적합하되,
3) λ(alpha) 격자는 np.logspace(-4, 3, 100), KFold(10, shuffle=True, random_state=1)로 10-fold CV를 해서 고르고,
4) λ별 평균 CV MSE 곡선을 그려(로그 x축) 최솟값이 격자의 양 끝이 아닌지 확인해 줘. 끝이면 범위를 넓혀 다시 돌려.
5) 고른 λ로 전체 학습 자료에 재적합한 뒤 계수 표(0이 아닌 변수 수 포함)와 검정 자료 MSE를 보고해 줘.
6) 마지막 줄에 "확인: 방법 고정 / 격자 범위 / 최솟값 위치(격자 안) / 표준화 / 재적합 / seed"를 체크 표시로 적어 줘. 코드 전체를 보여 줘.
```

**P6-2 R glmnet 판**

```
R의 glmnet으로 [라쏘(alpha = 1) / 능형(alpha = 0)]을 적합해 줘. cv.glmnet(x, y, alpha = …, nfolds = 10, lambda = 10^seq(3, -4, length = 100))로 λ를 고르고 plot(cvfit)을 그려 최솟값이 격자 끝이 아닌지 확인해. lambda.min과 lambda.1se를 둘 다 보고하고, coef(cvfit, s = "lambda.min")로 계수를 보여 줘(standardize = TRUE 기본이라 원래 단위로 돌아온다는 점을 적어 줘). set.seed(1).
```

**P6-3 반복 시뮬레이션(sparse vs dense, 100회)**

```
n = 100, p = 50, σ² = 9로 (a) sparse(5개 계수만 3, 나머지 0) (b) dense(50개 계수 모두 0.5) 자료를 seed 1~100으로 100번 만들어 OLS·능형·라쏘의 검정 MSE 평균(표준오차)을 표로 줘. 조건: 매 반복 같은 방법(라쏘는 끝까지 라쏘)·같은 λ 선택 절차(10-fold CV, 넓은 로그 격자)·표준화·재적합을 쓰고, 라쏘가 남긴 변수 수 평균도 보고해. 반복문 안에서 모형이 바뀌지 않는다는 것을 코드로 보여 줘.
```

**P6-4 이진 반응(로지스틱 라쏘)**

```
반응이 0/1인 자료야. scikit-learn LogisticRegression의 기본값(C = 1, ℓ2 벌점)을 쓰지 말고, (1) 벌점 없는 로지스틱(penalty=None) (2) 라쏘 로지스틱(penalty='l1', solver='saga')을 StandardScaler 파이프라인으로 적합해 줘. (2)의 C는 np.logspace(-3, 2, 50) 격자에서 10-fold CV(log-loss)로 고르고, C = 1/λ임을 명시해 선택 λ, CV 곡선(격자 끝 여부), 0이 아닌 계수 수를 보고해. R이면 glmnet(family = "binomial", alpha = 1)과 cv.glmnet.
```

**P6-5 출력을 받은 뒤 반드시 보내는 검토 프롬프트** — P7과 같음. 추가로 "선택된 λ가 격자 끝이면 10배 넓혀 다시 돌리고 두 결과를 나란히 보여 줘".

**자주 틀리는 설정 표**

| 함정 | 확인 | 근거 |
|---|---|---|
| scikit-learn `alpha` = λ(벌점 크기), glmnet `alpha` = 라쏘·능형 섞는 비율 | 어느 패키지의 alpha인지 적기 | 8차시 6-4 Q3·Q37 |
| `RidgeCV()` 기본 격자 (0.1, 1, 10) → 격자 끝 선택, 경고 없음 | `alphas=np.logspace(…)` 직접 지정 | 실습 Q34 |
| scikit-learn은 표준화 안 함 | `make_pipeline(StandardScaler(), …)`, CV도 파이프라인째 | 실습 Q35 |
| `LogisticRegression()` 기본 = C 1의 ℓ2 벌점 | `penalty=None` 또는 명시 | 실습 Q37 |
| glmnet `coef(cvfit)` 기본 s = "lambda.1se" | lambda.min이면 s 명시 | 6부 Q27 |
| 반복 시뮬레이션에서 LLM이 방법을 바꿈 | 반복문 안 모형 정의를 고정, seed 기록 | 녹음2 15:52 |
| CV 값으로 "예측오차 = 19"라고 보고 | 위치(최솟값)만 믿고 값은 hold-out으로 | 7차시 §2.3 |
