Q18. LDA(p=1)의 판별점수 δ_k(x)를 쓰라. [S28]

δ_k(x) = x·μ_k/σ² − μ_k²/(2σ²) + log π_k.

Q19. K=2, π₁=π₂=0.5, μ₁=−1.5, μ₂=1.5, σ²=1일 때 Bayes 결정경계는? [S29]

x = (μ₁+μ₂)/2 = 0.

Q20. 합동분산 σ̂²의 분모가 n−K인 이유를 한 문장으로. [S30·녹음1 24:57]


K개의 클래스 평균을 추정하느라 자유도를 K개 잃었기 때문("평균의 개수만큼 빼 준 자유도 보정").

Q21. p차원 다변량 정규 밀도함수를 쓰라. [M09]

f(x) = (2π)^{−p/2}|Σ|^{−1/2} exp(−½(x−μ)ᵀΣ⁻¹(x−μ)).

Q22. (x−μ)ᵀΣ⁻¹(x−μ)의 이름과, 1변량에서의 대응물. [M08]

(제곱) Mahalanobis 거리; (x−μ)²/σ².

Q23. 교수님이 "외우라"고 한 다변량 정규분포의 두 성질. [노트 p.4]

Q25. Fisher의 붓꽃 자료의 변수 수·클래스 수·클래스당 표본 수와 LDA 훈련 오분류 개수. [S33]

#### 6-3. 서술형

Q31. (15점) 2클래스, p=1, 공통분산 가정에서 Bayes 분류기(사후확률 ≥ ½)로부터 LDA의 판별점수 δ_k(x)를 유도하고, 어떤 항이 왜 사라지는지, 분산이 다르면 무엇이 달라지는지 설명하라. [노트 p.7–8·녹음1 11:46–17:20·판서 18:47]

① p(Y=1|x) = π₁f₁(x)/[π₁f₁(x)+π₀f₀(x)] ≥ ½ ⇔ π₁f₁(x) ≥ π₀f₀(x) (분모를 넘기고 ½을 지움; 판서 18:47). ② f_k(x) = (1/√(2πσ²)) exp(−(x−μ_k)²/(2σ²))를 대입하고 양변에 로그: log π_k − ½log(2πσ²) − (x−μ_k)²/(2σ²). ③ −½log(2πσ²)는 공통분산이므로 양변에 동일해 지워진다. (x−μ_k)² = x² − 2μ_kx + μ_k²를 전개하면 −x²/(2σ²)도 양변에 동일해 지워진다("서로 날아가고"). ④ 남는 것은 δ_k(x) = xμ_k/σ² − μ_k²/(2σ²) + log π_k — x의 1차식이므로 Linear DA. δ₁(x) ≥ δ₀(x)이면 1로 배정하며, 이것은 ①의 규칙과 동치다. π₁=π₀이면 경계는 (μ₁+μ₀)/2. ⑤ 분산이 다르면(σ₁² ≠ σ₀²) log σ_k² 항과 x²/(2σ_k²) 항이 살아남아 경계가 x의 2차식이 된다(QDA). σ²의 역할은 경계의 복잡도를 조절하는 것이다. ⑥ 핵심 메시지: 판별점수는 새로운 원리가 아니라 "0-1 손실을 최소화하는 Bayes 분류기"라는 대원칙에 정규분포를 대입했을 때 나오는 계산 결과다.

Q32. (15점) p>1 LDA에서 공분산행렬 Σ의 추정이 왜 어려운지 모수 개수로 설명하고, 고차원(p≫n) 자료에서 판별분석을 고집할 때 취할 수 있는 단순화와 그 결과(naive Bayes)를 수식과 함께 서술하라. 이산 변수가 섞여 있을 때의 처리와 Laplace 평활도 포함하라. [노트 p.9·판서 19:22·녹음2 07:45–24:16]

① Σ는 p×p 대칭행렬이므로 서로 다른 모수가 p(p+1)/2개(대각 p + 위삼각 p(p−1)/2). p에 대해 제곱으로 증가하므로(p=20이면 210, p=5000이면 약 1,250만) n이 수백인 유전체 자료에서는 추정이 불가능하다. μ_k는 p개뿐


이라 평균을 내면 끝이지만 Σ가 병목이다. ② 1단계 단순화: 모든 클래스에 공통 Σ(LDA). 그래도 p(p+1)/2개가 남는다. ③ 2단계(가장 무대뽀) 단순화: 비대각을 0으로 — 클래스 안에서 변수들이 독립. 다변량 정규에서 상관 0 ⇔ 독립이므로 밀도가 곱으로 분해된다: f_k(x) = ∏{j=1}^{p} f(x_j), 가우스이면 δ_k(x) = −½Σ_j (x_j−μ_{kj})²/σ_{kj}² + log π_k. 모수는 변수당 평균·분산뿐(p개 수준)이고 Σ⁻¹가 성분별 역수로 바뀌어 역행렬 계산이 없다 → 10억 건도 빈도·평균만 세면 되므로 매우 빠르다. 이것이 naive Bayes이며, "제일 어려운 부분을 없다고 가정하는 나쁜 방식"이지만 Σ를 제대로 추정하려는 노력보다 성능이 좋다는 것이 이론적으로 증명되었다. ④ 혼합형 변수: 독립 가정 덕에 연속 변수는 정규밀도, 이산 변수는 클래스 안에서 범주 빈도(확률질량함수)로 f_{kj}를 추정해 곱하면 된다. ⑤ Laplace 평활: 훈련자료에 없던 범주가 테스트에 나오면 f_{kj} = 0이 되어 곱 전체가 0이 된다. 범주 확률을 (빈도 + α)/(n_k + α·범주 수)로 추정해 0을 피한다(R e1071::naiveBayes(laplace=α) , 교수님은

"고민 안 하려면 기본값/1을 쓰라").

Q33. (15점) Default 자료의 LDA 혼동행렬(예측 No/Yes × 실제 No 9667/Yes 333; 오분류 23+252)을 이용해 (a) 전체 오류율과 정확도, (b) "항상 No" 분류기의 정확도, (c) 민감도·특이도, (d) 정확도만으로 성능을 판단하면 안 되는 이유, (e) 모형을 바꾸지 않고 default자 오분류를 줄이는 방법과 그 대가, (f) ROC·AUC가 무엇인지 서술하라. [S36–S39·노트 p.10–11·녹음2 33:10–46:21·녹음3]

(a) 오류율 (23+252)/10000 = 2.75%, 정확도 97.75%. 단, 이는 훈련 오류이며 성능 지표로는 테스트 오류를 써야한다. (b) 항상 No: 9667/10000 = 96.67%. 제일 나쁜 분류기도 majority class만큼은 맞춘다. (c) 민감도 = 81/333 = 24.3%(= 1 − FNR 75.7%), 특이도 = 9644/9667 = 99.8%(= 1 − FPR 0.2%). (d) 자료가 불균형(default 3.33%)이면 한쪽으로 몰아도 정확도가 높게 나오므로, 실제 양성 안에서의 오류와 실제 음성 안에서의 오류를 분리해서 봐야 한다. 또 두 오류의 비용이 비대칭(파산자를 놓치면 원금 손실, 건전 고객을 거절하면 이자 기회비용)이므로 문맥에 맞는 지표가 필요하다. (e) 0-1 손실(정확도)은 임계값 ½을 쓴다. 우리에게 있는 유일한 자유도인 임계값 c를 낮추면(예: 0.2) default자 중 놓치는 비율이 75.7% → 41.4%로 줄지만, 비default자 오분류가 늘어 전체 오류율은 2.75% → 3.73%로 약간 오른다(교재 Table 4.5). 민감도와 특이도는 시소 관계. (f) c를 바꿔 가며 (1−특이도, 민감도)를 찍어 이은 곡선이 ROC. 모든 ROC는 (0,0)과 (1,1)을 지나며, 대각선은 우연 수준("원숭이 선"), (0,1)은 완벽 분류기. 곡선 아래 면적 AUC는 0.5~1이며 1에 가까울수록 좋다(Default LDA 0.95). 실무 임계 값은 Youden 지수나 (0,1) 최근접점으로 고르되, 분야의 합의와 오류 비용을 따라야 한다.

Q34. (10점) 다변량 정규분포 N_p(μ, Σ)의 등밀도선이 타원인 이유를 설명하고, 타원의 중심·축 방향·축 길이를 각각 무엇이 정하는지 쓰라. Σ = [[2,1],[1,2]]로 예를 들라. [M13–M14·노트 p.3·녹음1 52:15–56:41]

① 밀도 f(x) ∝ exp(−½(x−μ)ᵀΣ⁻¹(x−μ))이므로 밀도가 같다 ⇔ 이차형식 (x−μ)ᵀΣ⁻¹(x−μ) = c²("안의 것만 똑같으면 높이가 똑같다"). 3차원 종 모양을 수평으로 "칼로 자른 단면"이 등고선. ② Σ = EΛEᵀ(스펙트럼 분해)를 넣으면 Σᵢ (eᵢᵀ(x−μ))²/λᵢ = c² — 회전좌표에서의 타원 표준식. 따라서 중심은 μ, 축 방향은 Σ의 고유벡터 eᵢ, 반축 길이는 c√λᵢ(큰 고유값 방향이 장축). ③ 예: |Σ−λI| = (2−λ)²−1 = 0 ⇒ λ₁ = 3, λ₂ = 1; e₁ = (1,1)/√2(장축, 45°), e₂ = (−1,1)/√2(단축). 길이비 √3 : 1 ≈ 1.73. 검산 λ₁λ₂ = |Σ| = 3, λ₁+λ₂ = tr Σ = 4. 양의 상관(1/2)이라 대각선 방향으로 늘어난다. ④ (연결) LDA의 Σ⁻¹는 이 타원을 원으로 펴는 백색화이며, Mahalanobis 거리가 가장 가까운 클래스 중심으로 분류하는 것이 LDA의 기하학적 해석이다.

Q35. (10점) 로지스틱 회귀와 LDA의 공통점과 차이점을 (a) 모형 형태, (b) 추정 대상과 방법, (c) 가정, (d) 안정성·계산, (e) 교수님의 실무 평가 관점에서 비교하라. [S26·S43·S45·노트 p.8·녹음1 25:20]

(a) 둘 다 log[p₁(x)/p₂(x)]가 x의 선형함수 → 선형 결정경계. (b) 로지스틱: P(Y|X)의 조건부 우도를 최대화(판별적); LDA: 클래스별 정규 가정 아래 P(X,Y)의 완전 우도, 즉 평균·분산·비율을 추정해 계수 c₀, c₁을 계산(생성적). (c) 로지스틱: X의 분포 가정 없음; LDA: 클래스별 X ~ N(μ_k, Σ), 공통 Σ. (d) 클래스가 잘 분리되면 로지스틱은 추정이 불안정(complete separation)하지만 LDA는 아님; n이 작고 X가 정규이면 LDA가 안정; K>2에 LDA가 편리하고 저 차원 시각화 제공. 계산: 로지스틱은 반복(Newton–Raphson, 큰 역행렬)이고 LDA는 덧셈·뺄셈의 닫힌 식("산뜻한 formula"). (e) 교수님: 실무에서는 LDA·QDA를 거의 쓰지 않고 naive Bayes를 많이 쓴다 — LDA·QDA는 naive Bayes를 설명하기 위한 밑밥. 교재 요약(S45): K=2는 로지스틱, n 작고 정규·K>2는 LDA, p 매우 크면 naive Bayes, 경계가 매우 비선형이면 KNN.

#### 6-1. 객관식 (정답 하나)

Q1. Default 자료 LDA 혼동행렬(실제 No 9667·Yes 333, 오분류 23+252)에 대한 설명으로 옳은 것은? [교재 p.144–145·S36] ① 민감도는 99.8%이다 ② "항상 No" 분류기의 오류율은 2.75%이다 ③ 실제 default자 중 75.7%를 놓쳤다 ④ 훈련 오류율이므로 검정 오류율보다 높다

정답 ③. 252/333 = 75.7%. 민감도는 81/333 = 24.3%, 특이도가 99.8%. 항상 No의 오류율은 3.33%. 훈련 오류는 보통 검정 오류보다 낮다.

Q2. 이진 분류기의 점수 S에 대한 설명으로 옳은 것은? [노트 p.19·p.25·B04] ① 반드시 0~1의 확률이어야 한다 ② 임계값은 항상 ½이다 ③ 바이오마커 값처럼 확률이 아닌 연속 출력도 되고 임계값도 ½일 필요가 없다 ④ 점수가 같으면 ROC를 그릴 수 없다

정답 ③. 노트: "일반적으로 주어지는 score를 가지고 1, 0으로 분류" / "S 모델에서 나오는 output". 동점은 ½로 처리한다(B07).

Q3. c-통계량의 정의로 옳은 것은? [노트 p.26·B07] ① 전체 정확도 ② 환자 1명과 비환자 1명을 무작위로 뽑았을 때 환자의 점수가 더 클 확률 ③ 민감도와 특이도의 평균 ④ 예측확률과 관측빈도의 차이

정답 ②. P(S_D > S_D̄)(+½P(동점)). 노트: "질병에 걸린 사람에서 아무나 한 명 뽑고, 그렇지 않은 사람 아무나 하나 뽑았을 때 … 확률이 높을 확률".

Q4. AUC = ∫ P(S_D > s)·f_D̄(s) ds에서 f_D̄(s) ds가 뜻하는 것은? [판서 18:51·노트 p.26] ① 환자 점수의 밀도 ② 세로 띠의 높이(민감도) ③ 비환자 점수가 [s, s+ds]에 들어갈 확률 = 세로 띠의 너비 dFPR ④ 임계값의 개수

정답 ③. 노트: "밑에 있는 길이는 자세히 보면 D가 아니라 D bar임 … Y축에 해당하는 것은 sensitivity". 높이 × 너비를 모든 s에 대해 더하면 P(S_D > S_D̄).

Q5. 모든 환자·비환자의 점수에 5를 더하고 2를 곱했다. AUC는? [노트 p.26] ① 커진다 ② 작아진다 ③ 변하지 않는다 ④ 0.5가 된다

정답 ③. 부등호가 바뀌지 않으므로 순위가 그대로 → AUC는 rank에만 의존.

Q6. 환자 점수 {0.90, 0.70, 0.55, 0.35}, 비환자 점수 {0.60, 0.40, 0.30, 0.15}에서 ĉ는? [슬라이드 B10] ① 0.75 ② 0.8125 ③ 0.875 ④ 1

정답 ②. 일치 쌍 4+4+3+2 = 13, 전체 쌍 16 → 13/16 = 0.8125. 사다리꼴 면적 .25×.5 + .25×.75 + .5×1도 0.8125.


Q7. 한 모형의 모든 예측확률에 0.5를 더했다(0.3 → 0.8, 0.1 → 0.6). 옳은 것은? [노트 p.28·B14] ① AUC가 오르고보정이 좋아진다 ② AUC는 그대로지만 보정이 깨진다 ③ AUC가 떨어진다 ④ 둘 다 그대로다

정답 ②. 노트: "0.5를 다 더해서 0.8과 0.6이라고 해도 AUC가 달라지지는 않는다 … 그거는 calibration measure 라고 해서 별도의 이름이 있음".

Q8. 민감도 0.99·특이도 0.98인 검사를 유병률 1/1000 집단에 쓸 때 PPV에 가장 가까운 값은? [판서 19:08·노트 p.29] ① 99% ② 50% ③ 20–30% ④ 5%

정답 ④. PPV = 0.99×0.001/(0.99×0.001 + 0.02×0.999) = 0.00099/0.02097 ≈ 4.7%. 유병률 1%이면 33%, 10% 이면 85%.

Q9. 교수님이 "3번이 굉장히 중요하다"고 한 AUC의 한계는? [노트 p.29·B15] ① 보정에 눈멂 ② 전 구간 임계값 평균 ③ odds ratio가 큰 변수를 넣어도 순위가 안 바뀌어 AUC 증분이 작음 ④ 비용 무시

정답 ③. "Odds ratio가 커도 AUC를 높이지는 않는다. Probability를 적당히 옮겨 주는 역할은 하지만 rank가 변하지는 않는다."

Q10. 경험분포함수 F̂ₙ(x) = (1/n)Σ 1(Xᵢ ≤ x)에 대한 설명으로 틀린 것은? [노트 p.32·T03] ① 각 관측값에서 1/n씩 뛰는 계단함수다 ② nF̂ₙ(x)는 Binomial(n, F(x))를 따른다 ③ 밀도함수다 ④ n이 커지면 모든 x에서 동시에 F에 가까워진다

정답 ③. 노트: "밀도함수가 아니라 누적분포임". ④는 Glivenko–Cantelli("sup은 maximum이라고 생각하면 됨").

Q11. 부트스트랩 복제값 1000개로 95% 백분위 구간을 만드는 방법은? [노트 p.35·T10] ① θ̂ ± 2·ŝe ② 정렬 후 앞·뒤 25개씩 잘라 25번째~975번째 값 ③ 평균 ± 표준편차 ④ 최소값~최대값

정답 ②. 노트: "순위를 쫙 세우고, 앞에서 25번째 뒤에서 25번째를 자르면 그 가운데는 95% confidence interval". ①은 정규 구간.

Q12. 크기 n의 자료에서 n개를 복원추출할 때 특정 관측이 한 번도 안 뽑힐 확률의 극한값과 그 쓰임은? [판서 21:04·노트 p.38] ① 0.5, 검증셋 반분 ② e⁻¹ ≈ 0.368, out-of-bag 평가 ③ 0.632, 훈련 ④ 0, 무시해도 됨

정답 ②. (1−1/n)ⁿ → e⁻¹. 약 63%가 뽑히고 37%는 안 뽑히므로 그 37%로 평가(OOB).

Q13. 교차검증에 관한 교수님의 말로 옳은 것은? [노트 p.42] ① R²가 가장 큰 모형을 고른다 ② R²로 모형을 고르는 것은 금기이며 검정오차나 AIC·BIC로 고른다 ③ 훈련오차가 가장 작은 모형을 고른다 ④ 변수가 많을수록 좋다

정답 ②. "R2로 모델 고르는 건 금기입니다. 절대 하면 안 됩니다. 테스트 에러로 보는 것. AIC 또는 BIC."

Q14. LOOCV에 대한 설명으로 틀린 것은? [노트 p.44·46·교재 p.179–180] ① n-fold CV다 ② 반복해도 결과가 같다 (분할의 randomness 없음) ③ 적합을 n번 해야 해 시간이 오래 걸린다 ④ k-fold보다 추정치의 분산이 작다

정답 ④. n개 적합이 거의 같은 자료로 이루어져 상관이 커 분산이 크다. 노트: "Randomness가 큰 편이다. 그래서 그것이 대략 이론적으로 실패함. 그 다음에 10으로 많이 썼더니 나쁘지는 않았다."

Q15. 혼동행렬(S36)에서 FPR과 FNR을 계산하라. [교재 p.145]

FPR = 23/9667 = 0.2%(= 1 − 특이도), FNR = 252/333 = 75.7%(= 1 − 민감도).

Q16. 임계값을 0.5 → 0.2로 낮췄을 때 default자 중 놓친 비율과 전체 오류율(Table 4.5). [교재 p.146]

75.7% → 41.4%(138/333); 전체 오류 2.75% → 3.73%.

Q17. c-통계량 정의의 ½·P(S_D = S_D̄) 항은 왜 들어 있는가? [노트 p.26]

점수가 이산이어서 동점이 날 때 누가 큰지 말할 수 없으므로 절반을 주기로 한 기술적 약속. 연속 점수면 생기지 않으며 본질적으로 중요하지 않다.

Q18. AUC = c를 보이는 판서 두 줄을 쓰라. [판서 18:51]


AUC = ∫₀¹ P(S_D > s) f_D̄(s) ds = P(S_D > S_D̄) (= ∫ P(S_D > s ∣ S_D̄ = s) f_D̄(s) ds, 전확률 법칙).

Q19. 표본 c-통계량과 같은 비모수 통계량의 이름. [노트 p.27·B10]

Mann–Whitney U(÷ n₁n₀); Wilcoxon 순위합의 재척도.

Q20. 보정 플롯을 만드는 절차를 한 문장으로. [노트 p.29·판서 19:08]

예측확률 0~1을 10등분하여 각 구간에 모인 사람들 중 실제 발병 비율을 세어 예측값(구간 평균)과 비교한다.

Q21. PPV를 민감도·특이도·유병률 π로 쓰라. [판서 19:06·추가]

PPV = sens·π / [sens·π + (1−spec)(1−π)].

Q22. 분류 모형 학습에 쓰는 손실 두 가지(이진·연속)와 평가에 흔히 쓰는 지표. [노트 p.30·판서 19:20]

이진: 0–1 손실의 대용인 교차엔트로피(이항 우도 ∏pʸ(1−p)^{1−y}); 연속: Σ(y−ŷ)²; 평가: AUC(순위 기반) — 둘이 다르다는 것이 "철학적 issue".

Q23. 부트스트랩 알고리즘 4단계(노트). [노트 p.33]

① Compute the empirical CDF ② 다시 항아리에 집어넣기(복원추출) ③ Recompute(통계량 재계산) ④ Repeat(보통 1000번).

Q24. 부트스트랩 표준오차 ŝe_boot의 식. [교재 (5.8)·T06]

ŝe_boot = √[ (1/(B−1)) Σ_b (θ̂ᵇ − θ̄_B)² ], θ̄_B = (1/B)Σ_b θ̂ᵇ.

Q25. 회귀 자료 (xᵢ, yᵢ)의 부트스트랩에서 재표집 단위는 무엇이며 컴퓨터에서는 무엇을 뽑는가? [노트 p.37]

단위는 쌍 (xᵢ, yᵢ)(벡터); 컴퓨터에서는 index만 복원추출해 해당 행을 가져온다.

Q26. (1−1/n)ⁿ의 n → ∞ 극한과 부트스트랩 표본에 포함되는 원자료 비율. [판서 21:04·T16]

e⁻¹ ≈ 0.368; 포함 비율 1 − e⁻¹ ≈ 63.2%.

Q27. 최소제곱에서 LOOCV를 한 번의 적합으로 계산하는 식. [슬라이드 V14·교재 (5.2)]

CV_(n) = (1/n) Σᵢ [(yᵢ − ŷᵢ)/(1 − hᵢ)]², hᵢ = 지렛값.

Q28. k-fold CV 추정치 CV_(K)의 식과 분류 문제에서의 변형. [슬라이드 V10·V18]

CV_(K) = Σ_{k=1}^{K} (n_k/n)·MSE_k; 분류에서는 MSE_k 대신 Err_k = Σ_{i∈C_k} I(yᵢ ≠ ŷᵢ)/n_k.

Q29. 교수님이 말한 "평가 자료의 원칙"을 한 문장으로. [노트 p.41]

평가할 때 사용하는 데이터셋은 모형의 학습에 (어떤 단계에서도) 절대 사용해서는 안 된다.
