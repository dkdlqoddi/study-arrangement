## 답안 평가 기준(채점표)과 모의고사 — 2026-10-28 중간고사 대비

> 세 가지 용도로 씁니다. ① **자기 채점**: 연습 답안을 10점 척도로 매긴다. ② **ChatGPT 답변 검증**: AI가 준 답을 믿기 전에 통과해야 할 기준. ③ **모의고사**: 이론형 A(100점)·AI 실습형 B(50점)를 시간 재고 풀고 채점 포인트로 매긴다. 기준은 교수님이 반복·강조한 내용과 기존 예상문제의 배점(10·15점)을 참고해 AI가 만든 [추가] 자료입니다. 문항별 상세 답안 핵심은 「예상 시험 질문 Top 42」(Q 번호)에 있습니다. 작성 2026-10-25.

### 1. 공통 채점 기준 (서술형 10점 척도)

| 영역 | 배점 | 만점 기준 | 0점 기준 |
|---|---|---|---|
| 정확성 | 4 | 결론·식·숫자·방향이 모두 맞음(부호, 극한, 조건 포함) | 결론이 틀리거나 핵심 식이 틀림 |
| 근거·유도 | 3 | 가정 → 전개 → 결과가 끊김 없이 이어지고, 항이 사라지는 이유·조건을 밝힘 | 결과만 적음 |
| 수업 맥락 | 2 | 교수님이 쓴 표현·예(Credit, 남아공, V23 퀴즈, Default)·강조점("무조건 CV", "percentile이 무조건 좋음")을 정확히 씀 | 교재 일반론만 있고 수업 연결 없음 |
| 구조·표현 | 1 | 결론 먼저, 번호 매긴 이유, 기호 정의, 단위·소수점 | 두서없음 |

등급 환산: 9~10 = 그대로 제출 가능 / 7~8 = 한 포인트 보강 / 5~6 = 유도 다시 / 4 이하 = 해당 절 다시 읽기.

**감점 항목(각 −1, 중복 가능)** — 라쏘 문턱 λ와 λ/2 혼동(손실 척도 미표기) · s와 λ의 방향 반대 · log n의 밑(상용로그) · AIC의 p와 2p 척도 혼동 · "LOOCV는 분산이 작다"를 교재 기준 답에 그대로 씀 · (1 − 1/n)ⁿ → 0.632라고 씀 · PPV가 유병률과 무관하다고 씀 · 환자-대조군에서 절편·예측확률을 믿음 · "Bayes 분류기 = 베이지안" · 능형이 계수를 0으로 만든다고 씀 · scikit-learn alpha와 glmnet alpha 혼동 · 출처 없음(AI 답을 검증할 때).

### 2. 유형별 체크리스트

- **유도형** ☐ 가정과 기호 정의 ☐ 출발 식(손실·우도·Bayes 정리) ☐ 미분/전개의 각 단계 ☐ 사라지는 항과 이유 ☐ 결과 식 ☐ 극한·특수 경우 검산 ☐ 한 줄 해석.
- **계산형** ☐ 식 ☐ 대입 ☐ 중간값 ☐ 답(단위·소수 둘째 자리) ☐ 상식 점검(예: 유병률↓ → PPV↓).
- **서술형** ☐ 결론 한 문장 ☐ 이유 2~3개 ☐ 수업의 예·수치 ☐ 교수님 결론 문장 ☐ 한계·주의.
- **비교형** ☐ 기준 행(가정·목표·식·장단점·언제) ☐ 양쪽 모두 채움 ☐ 실무 평가 한 줄.
- **실습 해석형** ☐ 방법 고정 ☐ λ 격자·CV 곡선(격자 끝?) ☐ 표준화 ☐ 재적합 ☐ 반복·seed ☐ 기본 벌점·alpha 의미 ☐ 의심 → 재실행 지시 → 재해석 ☐ 리포트 문장.
- **AI 사용 리포트** ☐ 도구 ☐ 프롬프트 2~3개 원문 ☐ 확인한 설정 ☐ 고친 것 ☐ 내가 판단한 것 ☐ 참고 자료.

### 3. ChatGPT 답변을 믿기 전 통과 기준 (각 0~2점, 8점 이상이면 채택)

| 기준 | 2점 | 0점 |
|---|---|---|
| 출처 | "N차시 §x.y"를 적고 그 절에 실제로 그 내용이 있음 | 출처 없음 또는 확인 불가 |
| 범위 | 자료에 없는 부분을 [일반]으로 구분 | 수업과 다른 표기·결론을 수업 내용처럼 서술 |
| 일관성 | 수업 표기(λ/2 문턱, (y − β)² 손실, 교재 방향의 K 편향–분산)와 일치 | 다른 교재 관습을 섞음 |
| 수치 | 중간값이 있고 재계산해도 같음(PPV·BF·λ* 등) | 숫자만 있고 검산 불가 |
| 완결성 | 「예상 질문」의 답안 핵심 항목을 모두 포함 | 절반 이하 |

### 4. 모의고사 A — 이론형 (90분, 100점, AI 사용 가능)

문항은 「예상 질문 Top 42」의 Q 번호에 대응한다. 채점 포인트의 괄호가 배점이다.

**A1. (15점, Q1·Q10)** (y − β)² + λ|β|의 해를 경우를 나눠 유도하고, λ = 2에서 y = 3, 0.8, −5의 라쏘 해와 능형 해를 구하라.
- 채점: 세 경우의 조건과 해(6) · soft thresholding 식 sgn(y)(|y| − λ/2)₊(2) · 숫자 6개 — 라쏘 2, 0, −4 / 능형 1, 0.27, −1.67(4) · "작은 값은 0, 큰 값은 λ/2만큼"과 변수 선택 연결(2) · 문턱 척도 명시(1).

**A2. (10점, Q2)** 관측 하나 y = β + ε(분산 σ²)에서 능형 해의 편향·분산·MSE와 최적 λ를 구하고 β = 2, σ² = 1에서 값을 구하라.
- 채점: β̂ = y/(1 + λ)(1) · E, 편향(2) · Var = σ²/(1 + λ)²(2) · MSE 식(1) · λ* = σ²/β²(2) · 0.25와 0.80, OLS 1과 비교(1) · "매 문제마다 풀 수 없어 CV"(1).

**A3. (15점, Q4·Q5)** 능형·라쏘의 제약형과 벌점형을 쓰고 라그랑지안으로 연결하라. p = 2 그림으로 라쏘만 정확한 0을 만드는 이유와, 제약이 예측을 개선할 수 있는 이유(편향–분산)를 설명하라.
- 채점: 두 형태 식(2) · 라그랑지안·s↔λ 방향·극단값(3) · 등고선 + 원/마름모 + 처음 닿는 점(3) · 꼭짓점 → 0, 확률이 0으로 가지 않음, 능형은 0 안 됨(3) · 분산↓ 편향↑, 편향² + 분산 + σ², "공짜 없음"(3) · 십자가/elastic net 한 줄(1).

**A4. (10점, Q6)** 척도 동변성을 정의하고 OLS와 능형에서의 성립 여부를 식으로 보인 뒤, 표준화 식과 glmnet·scikit-learn의 차이를 쓰라.
- 채점: 정의(1) · OLS 상쇄(2) · 능형 λ/c²(2) · 표준화 식과 중심화(2) · glmnet 기본 표준화·역변환 vs StandardScaler(2) · 범주형 가변수(1).

**A5. (10점, Q13)** AIC·BIC 식, 철학(참 모형 가정·목표·효율성·일치성), 벌점 비교(n ≥ 8), Credit 결과, "둘 다 갖는 기준은 없다".
- 채점: 식과 d(2) · AIC 철학(KL·예측)(2) · BIC 철학(참 모형·확률 1)(2) · log n > 2 ⟺ n ≥ 8, 4 < 6 < 7(2) · 불가능성과 선택 기준(1) · 임상에서 일치 요구 비판(1).

**A6. (10점, Q16·Q14)** adjusted R²가 "2가 없는 AIC"임을 보이고, KL 발산이 거리가 아닌 이유와 AIC 유도에서 공통항이 상쇄되는 이유를 쓰라.
- 채점: adj R² ⟺ RSS/(n − d − 1)(1) · 1/(1 − x) 근사 → (RSS/n)(1 + d/n)(2) · 로그 → 벌점 1 vs 2 vs log n(2) · "AIC·BIC로 충분"(1) · KL 비대칭·삼각부등식(2) · E_g log g 공통 → 로그가능도 비교(2).

**A7. (10점, Q21)** 5000개 변수·50명에서 전체 자료로 선별 후 CV하는 설계의 오류, 올바른 절차, 최종 모형, 무관 변수에서의 두 CV 오류.
- 채점: leakage·대원칙 위반(3) · 선별을 fold 안에서, 40명/10명(3) · 전체 재적합·nested(2) · 0.5 vs ≈ 0(1) · Ambroise & McLachlan(1).

**A8. (5점, Q24)** (1 − 1/n)ⁿ의 극한과 뜻, OOB, 결론.
- 채점: e⁻¹ ≈ 0.368, 63%/37%(2) · 훈련이 평가셋에 섞임(1) · OOB(1) · "예측오차는 CV, 불확실성은 부트스트랩"(1).

**A9. (10점, Q27·Q28)** AUC = c 증명과 rank 불변, 그리고 AUC의 한계 중 교수님이 중요하다고 한 것.
- 채점: c 정의·동점 ½(1) · 높이 = TPR, 너비 = f_D̄ ds(3) · 전확률·독립(2) · 단조변환 불변(1) · 증분이 작다(ΔAUC ≈ 0.01, rank 기반)(2) · 보정·부분 AUC·비용 한 줄(1).

**A10. (5점, Q29)** 민감도 0.99·특이도 0.98, 유병률 1/1000에서 PPV.
- 채점: Bayes 전개(2) · 0.00099/(0.00099 + 0.01998) ≈ 0.047(2) · 민감도·특이도는 유병률과 무관, PPV는 아님(1).

**배점 분포** — 축소법 50 · 모형 선택 20 · CV·부트스트랩 15 · 분류 성능 15. 1~5차시 기초·분류 모형은 A에 넣지 않았으므로 Q32–Q42는 요약표로 따로 점검한다.

### 5. 모의고사 B — AI 활용 실습형 (60분, 50점, ChatGPT 필수 · AI 사용 리포트 포함)

**B1. (15점)** 주어진 자료(또는 모의자료 n = 200, p = 30)에 라쏘를 적합해 λ를 CV로 고르고 계수와 검정 MSE를 보고하라. 프롬프트 북 P6-1을 사용한다.
- 채점: 방법 고정 명시(2) · 표준화 파이프라인(2) · 넓은 로그 격자(2) · CV 곡선 제시와 격자 끝 여부 판단(3) · 재적합과 보고(2) · seed(1) · 출력 검토(P7) 수행 흔적(3).

**B2. (10점, Q12)** 첫 실행에서 선택된 λ가 격자 끝이었다고 하자. 어떻게 대응했는지와 재실행 결과 비교를 쓰라.
- 채점: 격자 끝의 의미(2) · 범위 확대·곡선 재확인(3) · 두 결과 비교(검정 MSE)(2) · seed 변경·λ = 0이 답이 아닌 이유(1) · 리포트 문장(2).

**B3. (15점, Q8)** sparse·dense 100회 시뮬레이션(P6-3)을 시키고 결과 표를 해석하라. 믿기 전에 코드에서 확인할 것 4가지를 쓰라.
- 채점: sparse에서 라쏘 우세·dense에서 능형 우세와 이유(4) · σ² 하한과 OLS 최악 이유(2) · λ_min이 잡음 변수를 남김·1-SE(2) · 확인 4가지(모형 고정·λ 절차·표준화·학습/검정 분리/seed)(4) · "모르면 둘 다 돌려 CV"(1) · 교수님의 "3번은 lasso, 4번째부터 ridge" 경고 인용(2).

**B4. (10점)** B1~B3에 대한 AI 사용 리포트를 프롬프트 북 4절 템플릿으로 작성하라.
- 채점: 프롬프트 2~3개 원문(3) · 확인한 설정 5항목(3) · 고친 것(2) · 내가 판단한 것(2). 로그 통째 제출은 0점 처리(교수님 권고).

### 6. ChatGPT에 채점을 시키는 프롬프트 (복붙용)

```
채점: 다음은 「보건학을 위한 기계학습」 시험 답안이다. 채점표(정확성 4 · 근거/유도 3 · 수업 맥락 2 · 구조 1 = 10점, 감점 항목 포함)로 채점해 줘. 반드시 허브 https://raw.githubusercontent.com/dkdlqoddi/study-arrangement/main/llms.txt 에서 해당 절을 열어 대조하고, (1) 항목별 점수와 근거 (2) 빠진 핵심 포인트 (3) 틀린 문장과 교정문 (4) 대조한 출처(N차시 §x.y)를 써 줘. 자료에 없는 보충은 [일반]으로 표시해.
[문제] …
[내 답안] …
```

모범답안 자체를 먼저 보여 주지 않게 하려면 끝에 "모범답안은 내가 요청하기 전에는 쓰지 마"를 덧붙인다.

### 7. 기계 채점 도구 (저장소 tools/)

- `tools/eval/eval_set.json` — 예상 질문 중 30문항에 대해 **반드시 들어가야 할 키워드**(동의어는 `|`로 구분), 근거 파트 URL, 허브에서 찾아갈 때 보이는 라우팅 용어, 배점을 적어 둔 평가 세트.
- `python3 tools/eval_grade.py --template answers.md` → 답안 틀을 만들고, ChatGPT 답(또는 내 답)을 각 `## Q번호` 아래 붙여 넣은 뒤 `python3 tools/eval_grade.py answers.md` → 문항별 키워드 커버리지·출처 인용 여부·점수를 표로 출력(총점 100 환산). `--routing`은 허브(llms.txt)만으로 각 문항의 근거 파트를 찾을 수 있는지(라우팅 용어와 URL이 허브에 있는지) 점검한다. `--judge Q7`은 6절의 채점 프롬프트를 그 문항용으로 채워 출력한다.
- 키워드 채점은 "핵심 용어가 들어갔는가"만 보는 거친 척도다. 7점 이상이면 사람이 1절 기준으로 다시 본다.
