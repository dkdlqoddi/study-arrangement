### 1. 강의 개요

7차시(2026-10-14)는 강의 1에서 6차시에 V16까지 진행한 교차검증 덱(V01–V23)을 처음부터 다시 정리하며 k-fold·LOOCV와 k의 편향–분산, 분류 문제의 CV와 1-SE 규칙, 올바른 CV와 틀린 CV까지 끝냈고(18:36–19:30), 강의 2에서 V23의 실제 사례 논문으로 마무리한 뒤 「Linear Model Selection and Regularization」 덱(M01–M53)으로 넘어가 세 방법군과 AIC vs BIC의 철학, 부분집합 선택, R² 금지, Cp·AIC·BIC·adjusted R², CV의 장점, 로그 변환과자코비안을 다루었다(19:41–20:38). 녹음3(20:48–)은 교수님 도입과 수강생 발표(ISLR 5장 연습문제 8번)로 시작해, 강의 3에서 축소(shrinkage) — 제약 영역의 모양, 능형회귀(라그랑지안, λ의 CV 선택), 라쏘(정확한 0과 변수 선택)를 진행했다(20:58–21:24). 녹음 3개(54.8·57.2·36.0분), 강의노트 39쪽(슬라이드 76장 캡처), 칠판 사진 10장을 함께 정리했다. 녹음3 35:44 "다음 시간에 계속 이어서 설명을 하겠습니다"로 끝났으므로 M34 이후(라쏘의 기하·λ 선택, PCR·PLS)는 다음 차시 범위이고, M29–M32는 화면만 넘기고 따로 설명하지 않았다.

### 2. 핵심 개념 정리

진행 순서대로 2.1~2.14. 괄호는 전체판 슬라이드 번호.

#### 2.1 교차검증의 목적·대원칙과 검증셋 접근 (V01–V08, 녹음1 00:00–07:34)

CV의 두 용도는 모형 평가(오차의 값)와 모형 선택(최솟값의 위치); "bootstrap은 통계적인 불확실성, cross validation은 모형의 예측 성능" [녹음1 00:22–01:03][교재 p.175].

대원칙: 적합에 쓴 자료로 평가하면 "너무 성능이 좋은 것처럼 나온다"(훈련오차는 검정오차를 극적으로 과소 추정) — split 평가를 "아직도 많은 [문헌]에서 틀리고 … 여러분들께서는 그러지는 않으시길" [노트 p.2–3][녹음 1 01:20–02:09][교재 p.176].

검증셋 접근: 한 번 섞어 한 번 나눈다; 비율(8:2·7:3·5:5)은 자료 크기에 따라 — "법칙이 있는 건 아니다" [노트 p.3][녹음1 02:46–02:59]. hp² 추가 여부를 통계학은 계수 = 0 검정으로, 머신러닝은 검증 MSE 비교로 ("computer science 스타일") [노트 p.4][녹음1 03:52–04:52][교재 p.177].

seed별 곡선(V07): "어디서 최적값을 갖냐"는 비슷하지만 "예측오차 값 자체는 상당히 변동" → 값으로 평가하기는 어렵고 모델을 고르는 데는 안정적 [노트 p.4][녹음1 06:11–06:29][교재 p.178 Fig 5.2]. [추가] 한 분할 안에서는 모든 차수가 같은 검증셋으로 평가되어 곡선이 통째로 오르내린다.

두 단점(V08): ① split의 randomness가 성능의 randomness로 옮겨감 ② 절반만 적합에 써서 검정오차를 과대 추정 → 둘을 줄이는 k-fold가 "자연스럽게 나옴" [노트 p.5][녹음1 07:16–07:34][교재 p.178].

#### 2.2 k-fold CV와 CV₍ₖ₎ 식 (V09–V11, 녹음1 07:34–11:35, 판서 18:49)

K개 조각 중 하나를 감추고 나머지 (K−1)/K로 적합, K번 반복. K는 "예전에는 10이었는데 … 요새는 5나 3까지"[노트 p.5][녹음1 07:49–07:56][교재 p.181: 보통 5 또는 10].

<!-- page 3 -->

판서 18:49: CV₍ₖ₎ = Σₖ (nₖ/n)·MSEₖ, MSEₖ = Σ(i ∈ Cₖ)(yᵢ − ŷᵢ)²/nₖ — Cₖ = k번째 조각, nₖ = 그 크기, ŷᵢ = k번째 조각을 뺀 자료로 적합한 모형의 예측("이건 진짜 prediction error입니다") [판서 18:49][노트 p.5–6][녹음1 09:22–09:41].

"식을 좀 약간 괴팍하게 써서 그런데" nₖ가 약분 → CV₍ₖ₎ = (1/n)·Σᵢ(yᵢ − ŷᵢ)²(각 관측이 감춰졌을 때의 예측) = "예측오차의 total sum을 샘플 사이즈로 나눈 것"; n이 K의 배수면 (1/K)ΣMSEₖ [노트 p.6][녹음1 10:09–11:24][교재 p.181 식 (5.3)].

cross의 뜻(V11): 모든 자료가 정확히 한 번 검증, K−1번 훈련 — "데이터를 굉장히 효과적으로 사용", "윗줄에서는 training … 아랫줄에서는 validation" [노트 p.6][녹음1 08:32–08:42].

[추가] 훈련 몫은 K = 3·5·10에서 67·80·90%; n이 크면 작은 K의 손해(편향)가 작고 계산 절약이 크다. 분류는 (yᵢ − ŷᵢ)² 대신 I(yᵢ ≠ ŷᵢ)(2.4).

#### 2.3 LOOCV, 지름길 공식(hᵢ), k의 편향–분산 (V12–V15, 녹음1 11:43–25:30, 녹음3 01:00–09:41)

LOOCV: k-fold에도 남는 randomness를 "아예 없앨 수 있지 않을까?" → 1개씩 빼고 n번 적합 — seed와 무관하게 "누구라도 다 똑같은 결과", 대신 "1억 개면 … 1억 번". 교수님 실무는 5·10-fold(더 크면 3-fold), LOOCV는 관측 수백 개일 때만 [노트 p.7][녹음1 11:43–13:49][교재 p.178–179].

지름길(V14): 최소제곱에서는 한 번 적합으로 CV₍ₙ₎ = (1/n)Σ((yᵢ − ŷᵢ)/(1 − hᵢ))², hᵢ = H = X(XᵀX)⁻¹Xᵀ의 대각(레버리지) — "Gaussian outcome에 대한 선형회귀 모형에서만 존재" → 일반적으로는 "K는 5-fold, 10-fold가 recommend" [노트 p.8][녹음1 20:51–21:45][교재 p.180 식 (5.2)].

K의 편향–분산: 강의 — LOOCV는 "variance가 없잖아요 … bias가 굉장히 큰 값 … overlap이 너무 커요", K = 2 는 "변동성이 크지만 … bias는 굉장히 없어요" [노트 p.8][녹음1 22:05–22:54]. 교재(p.183–184)는 반대 방향: LOOCV = 편향↓·분산↑(적합 간 상관), K = 2 = 편향↑. 답안 요령 [추가]: 교재 방향으로 쓰고 결론은 K = 5 또는 10; 강의 표현의 'variance 없음'은 분할(seed)의 무작위성이 없다는 뜻임을 밝힌다.

CV 값 ≠ 최종 예측오차(V15): 10-fold는 seed가 달라도 stable하지만 "주의해야 될 것은 … prediction error를 보여준다는 뜻은 아닙니다", CV가 19라고 "예측성능이 19인 거냐, 그렇게는 설명을 안 해" → "어디서 최소값을 갖는가만 중요하게 판단" [노트 p.8][녹음1 24:01–24:45].

발표(녹음3): 연습문제 8번을 GPT·Claude·Gemini로 풀자 LOOCV는 같았지만 같은 seed의 10-fold MSE는 달랐다 — fold 번호의 섞기 전 순서가 달라 "실제로 묶이는 관측치가 다른" 것; 후보 모형은 fold 배정을 공유해야한다 [녹음3 03:45–07:58]. 교수님: "모든 방법이 올바른 결과이긴 한데 그래도 다르게 나올 수 있다" [녹음3 09:07].

#### 2.4 CV 곡선 vs 참 검정곡선, 분류 문제의 CV와 1-SE 규칙 (V16–V22, 녹음1 25:40–39:19)

세 모의자료(V17): LOOCV ≈ 10-fold이고 참 검정곡선과는 차이 — 고른 모델은 "큰 무리가 없는 모델"이지만 "커브 자체가 일치하지 않는다" → 선택(위치)은 믿고 평가(값)는 조심 [노트 p.9][녹음1 26:16–27:28][교재 p.182–183 Fig 5.6].

분류의 CV(V18): Errₖ = Σ(i ∈ Cₖ) I(yᵢ ≠ ŷᵢ)/nₖ, CVₖ = Σ(nₖ/n)·Errₖ — "loss function만 change". ŜE = √(Σ(Errₖ − Ērr)²/(K−1))는 fold 오류들이 "correlation이 있는 quantity … 독립은 아니기 때문에" "추천하지는 않습니다"(슬라이드 "Why not?"의 답) [노트 p.10][녹음1 27:37–29:14][교재 p.184 식 (5.4)].

1-SE 규칙: 곡선 하나만 보면 "생각보다 복잡한 모형을 고를 수 있는 가능성" → 최솟값 ± 1 SE 안은 성능이 "거의 같다"고 보고 제일 단순한 모델(ŜE를 "proxy로"); 연구자는 해석·계산 때문에 단순한 모델을 선호 [노트 p.10] [녹음1 30:49–32:36][교재 p.214].

차수 선택(V20–V22): 제곱항 검정 대신 10-fold 오류가 작은 것 — "가설검정은 잘 안 따지고" [노트 p.11][녹음 1 34:41]; 검정 오류율 0.201·0.197·0.160·0.162, Bayes 0.133 [교재 p.185]. 훈련오류가 아래에 있는 간격 = "prediction error에 대한 bias", 복잡도가 클수록 증폭 [노트 p.12][녹음1 35:50–37:35].

#### 2.5 올바른 CV와 틀린 CV — p = 5000, n = 50 (V23, 녹음1 39:32–54:20, 녹음2 00:00–08:01)

설정: 설명변수 5000개·표본 50개 = 고차원 자료(자료 행렬이 옆으로 길다), 로지스틱이 "안 돌아가니" 상관 상위 100개("10개라고 합시다")를 고른 뒤 분류기·CV 보고 — 2000년대 초반부터 흔한 설계 [노트 p.12–13][녹음1 39:32–42:56][슬라이드 V23].

틀린 이유("모두 다 틀린 방식"): 50명 전체로 선별 — "나중에 평가할 데이터셋이 활용되고 있는가의 여부가 제일 중요" → information leakage, "무조건 reject", 대원칙을 위반한 디자인 [노트 p.13][녹음1 44:29–45:38].

옳은 방법: 5-fold면 10명을 떼고 40명만으로 선별 + 적합, 10명으로 평가 × 5 — "이 모든 step이 cross validation 안쪽에" [노트 p.13][녹음1 47:02–48:22]. 최종 모형은 "모든 데이터를 다 써서 … 한 번 더 fitting" [녹음1 49:41]; 선별까지 튜닝하면 nested CV [녹음1 52:14]. [추가] fold마다 선별 변수가 다른 것은 정상(평가 대상 = 절차 전체).

정답 0.5: 무관한 난수 변수면 올바른 CV 오분류율은 0.5, 틀린 CV는 "마치 0처럼" — "여러분 직접 한번 생성해서 한번 해보세요" [노트 p.13][녹음2 00:04–00:36]. [추가] 전체판 모의실험: 틀린 방법 0.00–0.01, 옳은 방법 0.52–0.54.

사례: CV 밖에서 변수를 고른 Nature·PNAS 논문들이 "싹 다 틀렸다"; Ambroise & McLachlan(PNAS 2002)이 selection bias를 지적했고, Nature는 이후 "심사도 안 하겠다"고 공표 [노트 p.13][녹음2 01:05–07:36].

#### 2.6 왜 모형 선택인가 — 세 방법군, AIC vs BIC의 철학 (M01–M05, 녹음2 08:08–22:31)

선형모형으로 설명하지만 "deep learning에서 다 활용되고 있는 내용 … 아이디어가 뭔지를 이해하는 게 여러분들이 해야 하는 일" [녹음2 08:11–08:25]. 목표 = 예측 성능 + 해석 가능성; feature = variable = model selection(model은 "함수 형태를 결정하는 것까지") [노트 p.14–15][녹음2 13:22–14:05][교재 p.203–204].

세 방법군: ① 부분집합 선택 ② 축소 = regularization(ridge·lasso — "2번을 되게 중요하게") ③ 차원축소(키·몸무게 → BMI 하나; PCR·PLS) [노트 p.15–16][녹음2 19:49–21:04][교재 p.204]. 핵심은 forward·backward가 아니라 정보기준 — "AIC가 제일 작은 모델은 뭐가 좋아요?" [녹음2 15:05–15:46].

AIC: 후보 중 "참인 모형은 일단 없다" → 예측이 제일 좋은 것, "Kullback–Leibler divergence로 측정하면 AIC"(노트의 "cool back libral(???)") [노트 p.15][녹음2 16:11–16:48]. BIC: "참인 모형이 적어도 하나" → 그것을 찾는 것, "예측성능을 보지 않습니다", 고를 확률 → 1(일치성) [노트 p.15][녹음2 17:11–17:40].

거꾸로: AIC는 참 모형이 있어도 "못 골라요"(증명), BIC는 참 모형이 없으면 예측 최선을 "못 골라요"; 두 장점을 동시에 갖는 정보기준은 "존재하지 않는다는 게 증명" → 철학으로 고른다 [노트 p.15][녹음2 17:42–19:11]. [추가] AIC는 불필요한 변수를 n과 무관하게 P(χ²₁ > 2) ≈ 0.157로 넣는다(Yang 2005).

의료·임상에서 AIC와 BIC가 일치하기를 요구하는 것은 "말도 안 되는 얘기 … 비교하지 말아야 할 거 비교" [노트 p.15][녹음2 19:15].

#### 2.7 부분집합 선택 — best subset·forward·backward (M06–M13, 녹음2 22:36–28:43)

best subset: 변수마다 있다/없다 → 곱의 법칙으로 2ᵖ개; p = 100이면 "죽을 때까지 컴퓨터를 돌려도" 불가 [노트 p.16][녹음2 23:03–23:52][교재 p.205: p = 20이면 100만 개 이상]. 크기별로 RSS 최소 Mₖ를 고른 뒤 M₀…Mₚ 중 하나를 CV·Cp(AIC)·BIC·adj R²로 [슬라이드 M07].

forward: 첫 변수는 outcome과 correlation이 가장 큰 것, 다음부터는 "잔차를 구한 다음에" 잔차와 가장 센 것 → "대략 p의 제곱 개"(정확히 1 + p(p+1)/2) [노트 p.18][녹음2 24:01–25:36][교재 p.207–208].

forward의 단점: "앞에 게 불필요하더라도 계속 fix" → 대가는 "검토하지 않은 모형 가운데 더 좋은 모형이 있을 가능성" [노트 p.18][녹음2 25:40–26:47]; Credit의 4변수 모형에서 best subset과 갈린다 [교재 p.209 Table 6.1].

backward: 완전모형에서 하나씩 빼며 검토 수는 같다; 70–80년대에는 forward가 "너무 단순한 모델에서 멈춰 버릴 때가 많아서" backward가 지지받았다 [노트 p.19][녹음2 26:51–27:56].

modern era: p > n이면 완전모형을 적합할 수 없어 backward 불가 — "가능한 방식은 둘 중에 forward밖에 없다" [노트 p.19][녹음2 27:58–28:43][교재 p.209].

#### 2.8 RSS·R²로 고르면 안 되는 이유, 검정오차 추정의 두 접근 (M14–M15, 녹음2 28:47–33:20)

"R²로 절대 모델을 고르면 안 됩니다 … 쓰레기 변수를 집어넣기만 해도 R²는 무조건 커집니다" — R²는 "마치 training error 같은 형태" [노트 p.20][녹음2 28:47–29:08][교재 p.210]. [추가] 변수를 더해도 RSS는 늘지 않으므로 R²는 줄지 않는다(변수 n−1개면 R² = 1).

검정 자료에서 구한 predictive R²도 "좋은 아이디어가 아니에요" — "그냥 AIC랑 BIC 쓰세요" [노트 p.20][녹음 2 29:30–30:19].

두 접근(M15): 직접 = 검증셋·CV로 숨긴 자료의 오차 / 간접 = 훈련오차가 "too optimistic"한 만큼 보정 = AIC·BIC — "뒤에 2p가 어디서 나왔을까요?" → 훈련오차와 검정오차의 차이를 보정하는 값 [노트 p.20][녹음2 30:30–31:45][교재 p.210].

간접의 장점: "cross validation처럼 10번씩 fitting하는 일이 없어요"(10시간 vs 1시간) → "AIC가 더 그 문제에 적절한 solution일 때가 있다" [노트 p.20][녹음2 32:36]. [추가] 선형회귀의 기대 낙관 ≈ 2dσ²/n이 Cp의 벌점이다.

#### 2.9 Cp·AIC·BIC·adjusted R² — 식, d, 2 vs log n, Credit 결과 (M16–M20, 녹음2 33:26–45:25, 판서 20:25)

식: Cp = (1/n)(RSS + 2dσ̂²) · AIC = −2logL + 2d · BIC = −2logL + (log n)·d(앞의 1/n은 "중요하지 않습니

다") · adj R² = 1 − [RSS/(n−d−1)]/TSS/(n−1) [판서 20:25][노트 p.22][녹음2 42:19][교재 p.211–212].

AIC의 구성: −2logL = goodness of fit(변수를 넣으면 무조건 ↓), 2d = penalty(↑) → U자("test error가 보여주는 일반적인 shape", bias를 보정한 식); 2는 관습, 작을수록 좋고 패키지 부호 주의 [노트 p.22][녹음2 38:01–41:10]. d = 추정한 모수 수: 로지스틱 β₀·β₁·β₂ "3개 … 더하기 6" [판서 20:25][노트 p.21–22][녹음2 37:01]. BIC vs AIC: d 앞 숫자만 다르다 — log n을 "10이라고 합시다", "AIC는 2배씩 … BIC는 10배씩 … 일찍부터 올라간다" → BIC가 더 단순한 모형 [판서 20:25][노트 p.22][녹음2 43:11–45:18]. log n > 2 ⇔ n > 7 [교재 p.212].

Credit(M17): BIC 4 < Cp(AIC) 6 < adj R² 7 — "BIC가 거의 항상 단순한 모델", adj R²는 "AIC보다 더 복잡한 모델" → "Adjusted R square를 쓸 거면 AIC를 쓰세요" [노트 p.21][녹음2 34:24–36:19][교재 p.211 Fig 6.2]. [추가] 변수를 받아들이는 문턱은 대략 F > 1 < 2 < log n.

Cp = AIC?: "엄밀하게 똑같지는 않아요" — Cp는 σ²가 모든 모형에서 같다고 놓고 AIC는 모형마다 σ²를 다르게 둔다; σ²를 알면 같다 → "잊어버려라" [녹음2 35:01, 49:06–49:48]. BIC = SIC(Schwarz) [노트 p.21][녹음2 33:26].

#### 2.10 CV의 장점, 변환한 y의 AIC와 자코비안, Credit의 CV와 1-SE (M21–M23, 녹음2 45:34–57:03)

CV가 universal한 이유: σ²가 필요 없다(변수를 다 넣으면 "σ²가 0이 나와요" → 고차원에서 AIC·BIC 곤란), ridge·lasso용 AIC는 "표준적인 AIC는 아니에요", 원리가 하나 → "아무것도 안 떠오르고 cross validation만 떠오르면 공부를 제대로 한 겁니다" [노트 p.23][녹음2 45:34–48:31][교재 p.213]. AIC의 σ²는 "L 안에 있어요" [녹음2 48:41].

자코비안 함정: 양수 y(연봉·lab 값)에서 log y 정규모형의 AIC와 감마·로그정규 모형의 AIC를 그대로 비교하면 틀림 — "Y에 대한 likelihood하고 log Y에 대한 likelihood는 다른 likelihood", "Jacobian이라고 하는 것이 AIC 할 때 무조건 따라와야" [노트 p.24][녹음2 50:12–53:24]; "몇 달 전에도 내가 reject를 내린 논문" [녹음2 52:03].

#### 2.11 축소의 발상 — 편향을 내주고 분산을 줄인다 (M24–M25, 녹음3 09:48–21:44, 판서 21:07)

lasso는 "21세기 통계학의 3대 혁명" 중 하나로 꼽히고 인용 약 7만 6천 번(Tibshirani) — "되게 중요한 아이디어 … 그런데 아이디어는 엄청 쉬워요" [녹음3 09:57–12:10].

문제: 변수가 많으면 계수 하나에 쓰이는 "샘플 사이즈가 점점 줄어들어요"(100 → 33·33·33) → 추정치가 "왔다 갔다"; 다중공선성도 원인 [노트 p.25][녹음3 12:24–14:11]. [추가] Var(β̂) = σ²(XᵀX)⁻¹. 해결 = 제약: RSS를 정해 둔 영역 안에서만 최소화(constrained optimization) — 예 ∣β₁∣ ≤ 3, ∣β₂∣ ≤ 2(사각형) [판서 21:07][노트 p.25][녹음3 14:39–17:26]. '정규화'라는 번역은 "단어가 올바르진 않습니다"; shrinkage 는 값을 0 쪽으로 "압축" [녹음3 13:36, 21:17].

대가: "세상에 공짜가 없습니다 … bias가 생깁니다" — 그래도 variance가 크게 줄면 MSE 관점에서 이득("할만하죠") [노트 p.25][녹음3 15:42–16:19].

모양 = 방법: 원 β₁² + β₂² ≤ 1 = ridge, 마름모 ∣β₁∣ + ∣β₂∣ ≤ 1 = lasso, 원을 붙인 마름모 = elastic net, 십자가 = "best subset selection입니다"(노트의 "(?)"는 녹음상 단정) [판서 21:07][노트 p.26][녹음3 17:46–19:54].

#### 2.12 능형회귀 — 제약 ⇔ 벌점(라그랑지안), λ의 CV 선택 (M26–M30, 녹음3 21:45–33:47, 판서 21:11)

제약형(판서 21:11): min Σ(yᵢ − xᵢᵀβ)² s.t. β₁² + … + βₚ² ≤ C — "sphere 안에서만 해를 찾는 것"이 ridge(능형회귀; 70년대 p > n인 스펙트럼 분석 분야에서 시작) [판서 21:11][노트 p.26][녹음3 21:45–23:19].

라그랑지안: 제약 문제를 "제약조건이 없는 다른 형태의 최적화 문제로 바꾸는" 방법 — C에 대응하는 λ를 곱해 RSS + λΣβⱼ²를 제약 없이 최소화하면 동치("핵심적인 결론은 딱 하나") [노트 p.26][녹음3 24:22–26:14][교재 p.215, 221]. [추가] C ↑ ⇔ λ ↓; λ = 0이면 최소제곱, λ → ∞면 βⱼ → 0; 절편은 벌하지 않는다.

λ 선택: λ = tuning(hyper) parameter, λ 결정 = 모델 결정 → "CV라고 얘기하면 답이 되는 것처럼" CV; 격자의 각 λ에서 CV 오차 → 최소 λ → "데이터를 다 써서 맨 마지막에 적합" [노트 p.26][녹음3 27:15–29:41][교재 p.227].

실무 경고: 패키지는 fold 수와 λ 탐색 범위를 디폴트로 정해 둔다 — "바운더리에 있는 값이 최적 값으로 리포트가 되면 항상 의심", "충분하게 범위를 잡아주는 게 practice에서는 매우 중요", lasso도 같다 [노트 p.26][녹음 3 29:11–31:13].

solution path(M28): λ ≈ 0이면 선형회귀, λ가 매우 크면 모두 0, 도중에 커지기도 한다; CV로 고른 λ에서 중요한 변수만 큰 계수 [노트 p.27][녹음3 31:38–33:29][교재 p.216 Fig 6.4]. M29(ridge는 척도 등변이 아님 → 표준화 후 적용)·M30(편향–분산, 최소 MSE λ ≈ 30)은 녹음 설명 없음 [교재 p.217–218].

#### 2.13 라쏘 — ℓ1 벌점, 정확한 0과 변수 선택 (M31–M33, 녹음3 33:48–35:44)

ridge는 모든 변수를 남기므로 lasso는 RSS + λΣ∣βⱼ∣(ℓ1)을 최소화한다 [슬라이드 M31][교재 p.219]. "ridge는 0으로 가까이는 가지만 … 0을 직접 건드리지는 않습니다", 마름모꼴은 "정확하게 회귀계수가 0이 되는 애들"을 준다 → automatic variable selection, 희소 모형 [노트 p.29][녹음3 33:57–34:23].

변수 만 개도 "초 단위로 나와요 … 이 방법의 가장 큰 기여"(best subset 2ᵖ, stepwise p²와 대비) [노트 p.29][녹음3 34:23–34:43].

단점: "샘플 사이즈에 약해요 … 아래쪽으로 길어지면 맥을 못 춰요" — 옆으로 긴(p 큰) 자료는 빠르지만 아래로 긴(n 큰) 자료에는 약하다는 계산 얘기 [노트 p.29][녹음3 34:56]. [추가] 교과서적 약점(p > n이면 최대 n개 선택, 상관 묶음 중 하나만) → elastic net.
