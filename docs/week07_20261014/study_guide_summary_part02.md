#### 2.14 라쏘의 기하·λ 선택, 차원축소 PCR·PLS — M34–M53 (이번 차시 미진행 — 교재 기준)

라쏘의 기하(M34–M35): 예산 s의 제약형으로 쓰면 RSS 타원이 영역에 처음 닿는 점이 해 — 마름모는 꼭짓점이 축 위라 계수가 0이 된다; X = I이면 ridge yⱼ/(1 + λ), lasso는 soft-thresholding sign(yⱼ)·max(∣yⱼ∣ − λ/2, 0) [교재 p.220–226].

선택(M36–M39): 희소하면 lasso, 작은 효과가 많으면 ridge — 실제로는 모르므로 CV; λ 격자 → CV 최소 → 전체 재적합; 희소 모의자료에서 CV + lasso가 신호 변수 둘만 남긴다 [교재 p.223–228].

PCR·PLS(M40–M53): M < p개 선형결합 Zₘ에 최소제곱(βⱼ = Σθₘφₘⱼ 제약). PCR은 X만 보는 분산 최대 방향(비지도), M은 CV, 변수 선택이 아니고 M = p면 최소제곱; PLS는 Y와의 상관으로 방향을 잡지만(지도) ridge·PCR 보다 크게 낫지 않다 [교재 p.228–238]. 교수님은 M05의 BMI 예로 발상만 설명 [노트 p.16].
