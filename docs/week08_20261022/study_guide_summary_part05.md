#### 6-1. 객관식 (정답 하나)

Q1. adjusted R²에 대한 교수님 메모와 판서(18:44)의 내용과 맞는 것은? [노트·판서] ① 클수록 나쁜 기준이라 후보 중 값이 가장 작은 모형을 고른다 ② RSS/(n − d − 1) ≈ (RSS/n)(1 + d/n)이라 모수당 벌점이 약 1로 AIC(2)보다 약하고, 그래서 AIC보다 복잡한 모형을 고르는 경향이 있다 ③ KL 발산을 최소화하도록 유도된 기준이라 AIC보다 이론적 근거가 강하다 ④ p ≫ n인 고차원 자료에서 가장 믿을 만한 기준이다

정답 ②. 노트: "AIC 앞에. 2d 인데 2가 없다는 것은 AIC 보다 더 복잡한 complex한 모델을 골라주겠다 … 그래서 결론은 AIC BIC로 충분히 족하다." 로그를 취하면 n·log[RSS/(n − d − 1)] ≈ n·log(RSS/n) + (d + 1)이라 벌점의 기울기가 1, AIC는 2, BIC는 log n이다. Credit 자료에서 adjusted R² 7변수 > Cp 6변수 > BIC 4변수가 이 순서 그대로다. ① adjusted R²는 클수록 좋은 기준이다. ③ 노트 "근거가 없다. 대략 만든 것이다." ④ p > n이면 값이 1 인 모형을 쉽게 얻는다(교재 p.241). [근거: M17·M20, 노트 p.8–9, 판서 18:44, 교재 p.212–213]

Q2. 환자 n = 200명, SNP p = 500,000개 자료로 혈압 예측 모형(또는 라쏘의 λ)을 고를 때 가장 적절한 기준은? [노트·판서·교재] ① 훈련 자료의 R² ② 완전모형의 잔차로 σ̂²를 추정한 Cp ③ adjusted R² ④ K-fold 교차검증 오차

정답 ④. p ≫ n이면 완전모형이 자료를 그대로 지나가 σ̂² = Σ(yᵢ − ŷᵢ)²/n ≃ 0이 된다(판서 18:44). 그러면 Cp의

벌점 2dσ̂²가 사라지고, AIC·BIC의 n·log(RSS/n)은 −∞로 가며, 훈련 R²는 1이다. CV = (1/n)ΣLoss(yᵢ, ŷ₋ᵢ)에는 σ²도

d도 없다. 노트: "설명변수가 샘플 사이즈보다 크다면 0 같이 나오니까 쓰기가 곤란하다 … Cross validation을 해 나간다. 주된 현재 흐름." [근거: M21, 노트 p.9, 판서 18:44, 교재 p.241·p.244]

Q3. AI가 준 Python·R 코드를 읽을 때 매개변수에 대한 설명으로 옳은 것은? [실습·추가] ① scikit-learn의 alpha는 벌점의 크기 λ이고, R glmnet의 alpha는 라쏘·능형을 섞는 비율이다 ② scikit-learn의 Ridge·Lasso는 glmnet처럼 설명변수를 자동으로 표준화한다 ③ glmnet에서 alpha = 0은 라쏘다 ④ scikit-learn LogisticRegression()은 아무것도 지정하지 않으면 벌점이 없는 보통의 로지스틱 회귀다

정답 ①. ② scikit-learn은 표준화하지 않으므로 make_pipeline(StandardScaler(), …)을 직접 붙여야 한다(실습 2). glmnet은 기본 standardize = TRUE이고 노트대로 "단위를 없애고 분석한 다음에 다시 결과값을 단위에 맞게 바꿔서 답을 줌". ③ glmnet은 alpha = 1이 라쏘, alpha = 0이 능형이다(교재 p.251). ④ 기본값이 C = 1.0, l1_ratio = 0.0, 곧 ℓ2(능형) 벌점이다(실습 5 출력). 덧붙여 두 패키지는 목적함수 척도(1/2n 유무)가 달라 같은 λ 숫자를 그대로 옮기면 안 된다. [근거: 6장 6-7, 실습 2·5, 노트 p.12 M29 메모, 교재 p.251]

Q4. AIC 유도에서 편향 b ≈ tr(J⁻¹I)가 정확히 모수 개수 p가 되는 조건은? [노트·슬라이드] ① n/p ≥ 40일 때 ② 모수의 사전분포가 균등할 때 ③ 모형이 올바르게 지정되어(g = f(· ∣ θ₀)) 정보 항등식 I = J가 성립할 때 ④ 테일러 전개의 3차 항이 정확히 0일 때

정답 ③. I = J이면 J⁻¹I = 단위행렬이므로 tr(J⁻¹I) = p — 슬라이드 "이 하나의 항등식이 '2p'가 나오는 곳이다". 노트: "대략적으로 bias B가 tr(J^(-1) I). 그래서 P가 나오게 된다." 오지정이면 일반형 TIC = −2ℓ(θ̂) + 2tr(Ĵ⁻¹Î)를 쓴

다(노트 "현재 miss specified model을 쓰는 사람은 없고 거의 대부분 correctly specified model을 쓴다"). ① n/p < 40은 AICc를 쓰는 기준이다. ② 사전분포는 BIC 쪽 이야기다. ④ 3차 이상의 항은 n → ∞에서 무시되는 것이지 조건이 아니다. [근거: AB05·AB06·AB10, 노트 p.24·p.26]

Q5. KL 발산에 대한 설명으로 옳은 것은? [노트·판서·추가] ① 대칭(KL(g‖f) = KL(f‖g))이므로 수학적인 거리다 ② KL(g‖f_θ) = E_g[log g] − E_g[log f_θ]의 첫 항은 모든 후보 모형에 공통이라 두 모형을 비교할 때 상쇄된다 ③ 분포족이 다른 정규 모형과 감마 모형은 KL로 비교할 수 없다 ④ 표본에서 KL을 최소화하는 것은 로그가능도가 가장 작은 모형을 고르는 것이다

정답 ②. 칠판(18:59)의 빗금 친 동그라미 ◯가 이 공통 항이다 — 노트 "결과적으로는 똑같은 양이 뒤에 있고". 그래서 KL 최소 ⟺ E_g[log f] 최대이고, 표본에서는 (1/n)Σlog f̂로 근사한다. ① KL은 비대칭이다(예: g = N(0, 1),

f = N(0, 4)이면 KL(g‖f) ≈ 0.318, KL(f‖g) ≈ 0.807) — 교수님은 "Variation을 재는 measure"라고 불렀다. ③ 노트 "Gamma, normal 분포가 달라도 AIC를 쓸 수 있다"(같은 반응 척도일 때). ④ 반대 — 로그가능도가 큰 쪽이 KL이 작다. [근거: AB03·AB10, 노트 p.24·p.26, 판서 18:59]

Q6. BIC 벌점 p·log n의 log n은 어디서 나오는가? [노트·슬라이드] ① 두 2차 전개의 이차형식이 크기가 같고 부호가 반대이기 때문에 ② 모수 사전분포의 로그 log π(θ̂)가 n에 비례해 커지기 때문에 ③ AICc의 보정항 2p(p + 1)/(n − p − 1)에서 ④ 주변가능도를 Laplace 근사할 때 곡률 행렬 A ≈ nĴ의 행렬식이 ∣nĴ∣ = nᵖ∣Ĵ∣이기 때문에

정답 ④. Laplace 근사의 로그에는 −½log∣A∣가 있고 −½log∣nĴ∣ = −(p/2)log n − ½log∣Ĵ∣이므로, −2를 곱한 척도에서 +p·log n이 된다. 노트: "N을 집어넣는 순간. P by p matrix. 그게 n의 p승. P log n. 패널티 폼." ① AIC의 인수 2가 나오는 이유다. ② 사전분포 항은 O(1)이라 버린다 — 그래서 BIC는 사전분포를 지정하지 않아도 된다. [근거: AB14–AB16, 노트 p.27]

Q7. 능형·라쏘의 제약 형태와 벌점 형태에 대한 설명으로 옳은 것은? [노트·판서·교재] ① 두 문제는 해가 달라서 연구 목적에 따라 하나를 골라야 한다 ② 예산 S가 클수록 대응하는 λ도 크다 ③ 각 S마다 같은 해를 주는 λ ≥ 0이 있고, S가 최소제곱 해의 벌점 크기 이상이면 λ = 0이다 ④ λ → ∞이면 최소제곱 해가 나온다

정답 ③. 노트: "같은 문제를 loss function + lambda. 이 s에 대응되는 lambda가 있는데", "직관적인 것은 판서의 위쪽. 계산은 판서의 아래." 교재도 "모든 λ마다 같은 추정치를 주는 s가 있다"(p.221)고 쓴다. 예산이 넉넉할수록 제약이 느슨하므로 S↑ ⟺ λ↓이고, S ≥ P(β̂_OLS)이면 최소제곱 해가 이미 영역 안이라 λ = 0이다. ①② 틀림. ④ λ → ∞이면 모든 계수가 0으로 간다. [근거: M26·M34, 노트 p.11, 판서 19:24·19:33, 교재 p.220–221]

Q8. 능형회귀에 대한 설명으로 틀린 것은? [노트·판서·교재] ① λ가 충분히 크면 일부 계수가 정확히 0이 되어 변수 선택을 한다 ② λ = 0이면 보통 최소제곱과 같다 ③ 벌점은 기울기 계수에만 걸고 절편 β₀에는 걸지 않는다 ④ λ > 0이면 XᵀX + λI는 항상 역행렬이 있어 p > n에서도 해가 유일하다

정답 ①. 노트(M28): "0이 달라붙는데 중간에 0을 터치하지 않는다. 유한한 매우 작은 값에 붙어 있다." 1차원 해 y/(1 + λ)는 y ≠ 0이면 결코 0이 아니다. 계수를 정확히 0으로 만드는 것은 라쏘다. ② 노트 "Lambda=0일 때 ordinary square". ③ 교재 p.215. ④ XᵀX의 고윳값 dⱼ²에 λ가 더해져 dⱼ² + λ > 0(판서 19:54). [근거: M26–M28, 노트 p.11–12, 판서 19:54·20:13, 교재 p.215–216]

Q9. 1차원 라쏘 (y − β)² + λ∣β∣에서 λ = 4일 때, y = −1.5와 y = 5에 대한 해 β̂를 순서대로 고르면? [판서·교재]

① −1.5와 5 ② −0.3과 1 ③ 0과 1 ④ 0과 3

정답 ④. β̂ = sgn(y)(∣y∣ − λ/2)₊이고 문턱은 λ/2 = 2다. ∣−1.5∣ ≤ 2이므로 0, 5 > 2이므로 5 − 2 = 3. ①은 최소제곱 해, ②는 능형 해 y/(1 + λ) = −1.5/5, 5/5다. 라쏘는 작은 값은 지우고 큰 값은 같은 양 λ/2만큼만 줄인다 (soft thresholding). [근거: M34, 판서 20:47, 교재 식 (6.15) p.225]

Q10. 키를 m에서 cm로 바꿔 넣고(다른 변수는 그대로, 표준화 없음) 같은 λ로 다시 적합했다. 옳은 것은? [노트·교재·실습] ① OLS의 키 계수는 100배가 된다 ② OLS의 예측값은 그대로지만, 같은 λ의 능형 예측값은 달라질 수 있다 ③ 능형의 키 계수는 정확히 1/100배가 된다 ④ R glmnet 기본 설정(standardize = TRUE)으로 적합해도 예측이 크게 달라진다

정답 ②. OLS는 척도 동변이라 계수가 1/100배가 되고 예측은 그대로다(노트 p.12 손글씨 "X₁ 만약 10배 커지면 → β₁ 1/10배 … 이 개념을 scale equivariant라고 함"; 실습 2: 비율 100.0, 예측 차이 2.84e-14). 능형은 벌점 때문에 성립하지 않는다 — 실습 2에서 λ = 10의 키 계수는 m 단위 1.053, cm 단위 35.657(m 환산)이고 예측값이 최대 6.390 달라졌다. ④ glmnet은 표준화한 뒤 원래 단위로 되돌려 주므로 단위의 영향을 받지 않는다. 노트: "우리가 x에 cm와 m로 넣었을 때 예측모델의 성능이 바뀔 거라고 얘기 안 하잖아요." [근거: M29, 노트 p.12, 교재 p.217, 실습 2]

Q11. 참 계수의 모양(설정)과 유리한 방법의 짝으로 옳은 것은? [노트·판서·교재] ① 희귀 유전 질환처럼 한두 개 변이만 원인 — 능형 ② 흔한 변이 여러 개가 조금씩 기여 — 라쏘 ③ 흔한 변이 여러 개가 조금씩 기여 — 능형 ④ 어느 설정인지 모를 때는 항상 라쏘를 쓴다

정답 ③. dense 설정이다 — 노트 "릿지는 강제로 shrinkage를 빡 해준다. 자잘자잘한 0이니까 shrinkage하고 variance를 잡아준다. Dense한 상황에서는 ridge가 잘함." ① sparse에는 "뒤에 불필요한 거는 날려버리니까" 라쏘가 맞다. ④ 노트 "dense와 sparse 감이 없음. 그래서 한 번은 릿지 한 번은 라쏘 둘 다 돌리고 CV를 해서 더 나

은 모델을 고르는 작업을 한다." 교재 Fig 6.8(45개 모두 관련 → 능형 약간 우세)·Fig 6.9(2개만 관련 → 라쏘 우세)와 같다. [근거: M31·M36, 노트 p.13, 판서 20:20, 교재 p.223–224]

Q12. 조절모수 λ를 교차검증으로 고르는 이유로 가장 알맞은 것은? [노트·추가] ① RSS + λP(β)를 β와 λ에 대해 함께 최소화하면 P(β) ≥ 0이라 항상 λ = 0(최소제곱)이 답이 되므로, 훈련에 쓰지 않은 자료에서의 예측 성능이라는 바깥 기준이 필요하다 ② λ는 자료 생성 모형을 기술하는 모수이므로 최대가능도로 추정해야 한다 ③ 능형은 닫힌 해가 있으므로 λ도 닫힌 해로 구할 수 있다 ④ AIC·BIC는 벌점 회귀에서 어떤 경우에도 계산할 수 없다

정답 ①. 노트: "모델을 description 하기 위해 사용하는 것은 아니다. 제약조건 하에서 답을 구할 것이라는 연구자의 마음에서 나온 것이다 … 예측 성능을 제일 좋게 하는 람다로 바꿔버림. 그래서 CV로 퉁쳐버린다." ② λ는 모형의 모수가 아니다. ④ 라쏘의 자유도를 0이 아닌 계수 수로 세면 AIC·BIC도 계산할 수 있고, 노트(M37)는 "AIC를 선택하면 적합시키면 계산됨. 시간이 경우에 따라 1000배씩 빨라지기도 한다"고 했다. 다만 범용으로는 CV다. [근거: M26–M27·M37, 노트 p.11·p.15, 판서 19:24]

Q21. 관측 하나 y = β + ε, Var(ε) = σ²에서 (y − β)² + λβ²를 최소화하는 β̂, 그 기댓값·분산·MSE를 쓰고, MSE를 최
