Q28. (15점) 능형회귀와 라쏘를 (a) 제약 형태와 (b) 벌점 형태로 쓰고 두 형태가 같은 해를 주는 이유를 설명하라 (예산 S와 λ의 대응 방향, 극단값 포함). 이어서 p = 2의 RSS 등고선과 제약 영역(원·마름모) 그림으로 라쏘만 계수를 정확히 0으로 만드는 이유를 설명하고, 같은 사실을 1차원 해로 확인하라. 교수님이 두 형태의 역할을 어떻게 나누었는지도 쓰라. [노트·판서 19:24·19:33·20:47·교재]

① 두 형태: 능형 — 제약형 min RSS s.t. Σβⱼ² ≤ S, 벌점형 min RSS + λΣβⱼ². 라쏘 — 제약형 min RSS s.t. ② 왜 동치인가(라그랑지안): L(β, λ) = RSS(β) + λ(P(β) − S), λ ≥ 0. λ를 고정하면 −λS는 β와 무관한 상수이므로 β 에 대한 최소화는 벌점형과 같다. 거꾸로 벌점형의 해 β̂_λ에 대해 S = P(β̂_λ)로 두면 β̂_λ는 제약형의 해다(더 작

은 RSS를 주는 허용점이 있다면 벌점형의 최소성에 모순). RSS와 P가 볼록이므로 각 S에 같은 해를 주는 λ가 존재한다 — 노트 "이 s에 대응되는 lambda가 있는데 … 대략적으로 S에 대응되는 란다를 찾아서". 방향: λ₁ < λ₂의해를 β₁, β₂라 하면 두 최적성 부등식을 더해 (λ₂ − λ₁)(P(β₂) − P(β₁)) ≤ 0, 곧 λ가 클수록 쓰는 예산이 작다 → S가 클수록 λ가 작다. S ≥ P(β̂_OLS)이면 λ = 0(OLS 그대로), S → 0이면 λ → ∞(모든 βⱼ → 0).

④ 원 vs 마름모: 원(능형)은 경계가 매끄러워 타원이 어느 방향에서 오든 접점이 축 위에 올 이유가 없다 — 접점이 정확히 축 위이려면 β̂가 특정한 선(넓이 0) 위에 있어야 하므로 확률 0, 두 계수 모두 0이 아니다. 마름모(라쏘) 는 꼭짓점 (±S, 0), (0, ±S)가 축 위에 뾰족하게 튀어나와 있어, 꼭짓점 바깥쪽 쐐기 모양 영역(넓이 > 0)의 β̂는 모

⑤ 1차원 해로 확인(칠판 20:13·20:47): 능형 (y − β)² + λβ² → β̂ = y/(1 + λ) — 같은 비율로 줄여 y ≠ 0이면 0이 아니다(노트 M28 "중간에 0을 터치하지 않는다"). 라쏘 (y − β)² + λ∣β∣ → β > 0이면 β = y − λ/2(y > λ/2일 때), β < 0이면 β = y + λ/2(y < −λ/2일 때), 그 사이는 β = 0(0에서의 부분미분 −2y + λ[−1, 1]이 0을 포함) → β̂

= sgn(y)(∣y∣ − λ/2)₊. 직관: 능형 벌점의 기울기 2λβ는 β → 0이면 함께 0이 되어 마지막 한 걸음을 밀지 못하지만, 라쏘 벌점의 기울기 크기는 0 근처에서도 λ로 일정해 자료가 끌어당기는 힘 2∣y∣가 λ보다 약하면 β를 0 에 붙잡아 둔다 — 마름모 꼭짓점의 '뾰족함'을 대수로 쓴 것이다.

⑥ 의미와 확장: 라쏘는 추정과 변수 선택을 한 번에 하고 해석이 쉬운 sparse 모형을 준다. 손실을 로지스틱 음의 로그가능도로 바꿔도 그림의 논리는 같다 — 노트 "Binary data에서의 shrinkage 문제를 푸는 것임. 중요를 강조. 거기에 해의 제약조건만 달리는 문제". 꼭짓점을 더 뾰족하게(오목한 별, bridge q < 1) 하면 선택은 강해지지만 비볼록이라 "어디서 시작하냐에 따라 수렴하는 곳의 위치가 바뀌게 된다"(M39). λ(또는 S)는 CV로 고른다.

Q29. (15점) AIC가 추정하는 목표량을 KL 발산으로 정의하고, 최대 로그가능도가 왜 낙관적인지, 그 편향이 왜 tr(J⁻¹I) = p가 되어 벌점 2p가 나오는지 단계별로 설명하라. BIC의 p·log n이 어디서 나오는지도 쓰고, 두 기준의 철학(참 모형에 대한 가정·목표·대표본 성질)을 비교하라. [노트·판서 18:59·19:24·슬라이드]

① 설정과 KL: 자료 y₁, …, yₙ은 미지의 참 밀도 g에서 나온 i.i.d.이고, 후보 모형 f(· ∣ θ)는 g를 포함하지 않을 수도 있다(오지정 허용). KL(g‖f_θ) = E_g[log g(Z)] − E_g[log f(Z ∣ θ)] ≥ 0이며 같을 때만 0이다(노트 "F theta 1 이 g 이면. 같은 거에 같은 거 빼니까 0. 다르면 0보다 커지기 시작한다"). 첫 항은 모든 모형에 공통이므로 비교에서 상쇄되고, KL 최소 ⟺ 기대 로그가능도 E_g[log f] 최대다. g를 모르므로 대수의 법칙으로 (1/n)Σlog f(yᵢ ∣ θ)로 근사한다(칠판 18:59). 같은 잣대이므로 정규·감마처럼 분포족이 다른 모형도 비교할 수 있다.

② 목표량: 실제로 쓰는 것은 추정한 θ̂(Y)이므로 AIC가 노리는 양은 η = E_Y E_Z[log f(Z ∣ θ̂(Y))] — 안쪽은 독립

인 새 관측 Z에 대한 기댓값(고정된 모형의 예측 성능), 바깥은 θ̂가 표본마다 달라지므로 한 번 더 취한 기댓값이

다. 노트: "그놈 자체가 변동성이 있으니까 expectation을 한 번 더 취해준 양이 예측 성능을 비교할 때 필요한 양이다." η 최대화 ⟺ 기대 KL 최소화.

③ 낙관 편향: 순진한 추정 ℓ(θ̂)/n은 θ̂를 고르는 데 쓴 y로 다시 평가하므로("y를 두 번 쓴다") 부풀려진다. 편향 b

= E_Y[ℓ(θ̂)] − nη > 0 — 훈련오차가 검정오차를 과소추정하는 것과 같은 현상이다.

④ 두 번의 2차 전개: Step 1 — 모집단 곡선을 그 최대점 θ₀에서 전개: E_Z[log f(Z ∣ θ̂)] ≈ E_Z[log f(Z ∣ θ₀)] − ½(θ̂ − θ₀)ᵀJ(θ̂ − θ₀)(1차 항은 θ₀가 최대점이라 0). Step 2 — 표본 곡선을 그 최대점 θ̂에서 전개: ℓ(θ₀) ≈ ℓ(θ̂) − ½(θ̂ − θ₀)ᵀ(nJ)(θ̂ − θ₀)(점수가 0). 다리: θ₀는 고정값이라 E_Y[ℓ(θ₀)] = n·E_Z[log f(Z ∣ θ₀)]. 새 자료에서 보면 θ̂는 꼭대기보다 낮고 학습 자료에서 보면 θ̂가 꼭대기라 높다 — 두 이차형식은 크기가 같고 부호가 반대라 빼면 더해

진다: b ≈ n·E[(θ̂ − θ₀)ᵀJ(θ̂ − θ₀)] = tr(J·J⁻¹IJ⁻¹) = tr(J⁻¹I)(샌드위치 분산 Var(θ̂) ≈ J⁻¹IJ⁻¹/n). 3차 이상은 n(1/√n)³ = 1/√n → 0이라 버린다 — 노트 "테일러 전개 2차 전개밖에 없다. 주의하세요", "그냥 용기를 내세요. 3번째는 사라진다고."

⑤ p와 2p: 모형이 올바르면 정보 항등식 I = J(∫f dz = 1을 두 번 미분)로 tr(J⁻¹I) = p. 보정 추정 nη̂ = ℓ(θ̂) − p에 −2를 곱하면 AIC = −2ℓ(θ̂) + 2p(칠판 19:24 "E(log f) ⟵ (1/n)Σlog f_θ̂(yᵢ) − b, b → p", "−2ℓₙ + 2p"). 오지정이 의심되면 TIC(2tr(Ĵ⁻¹Î)), 소표본(n/p < 40)이면 AICc. ⑦ 철학 비교: 노트 AB03 "데이터를 직접 생성해주는 density function이 있을 수도 있고 없을 수도 있고 … 그게 AIC와 BIC의 차이를 만듦." Q30. (10점) 척도 동변성(scale equivariance)을 정의하고 최소제곱에서는 성립하지만 능형회귀에서는 성립하지 않음을 보여라. 그 결과 생기는 실제 문제, 해결책(표준화 식, 범주형 변수 처리), 그리고 R glmnet과 Python scikit-learn에서 확인할 점을 쓰라. [노트·교재·판서 19:54·실습]

① 정의: 설명변수 Xⱼ에 상수 c를 곱했을 때 계수 추정치가 정확히 1/c배가 되어 Xⱼβ̂ⱼ(예측)가 변하지 않는 성질. 노

트 p.12 손글씨: "Y = β₀ + β₁X₁ — X₁ 만약 10배 커지면 → β₁ 1/10배 … 이 개념을 scale equivariant라고 함." 노트 메모 "설명변수가 변하는 만큼 정확한 배수로 회귀계수가 변한다"의 '배수'는 반대 배수(1/c)로 읽는다.

② OLS는 성립: X → XC(C = diag(c₁, …, cₚ))이면 ((XC)ᵀXC)⁻¹(XC)ᵀY = C⁻¹(XᵀX)⁻¹C⁻¹CXᵀY = C⁻¹β̂, 예측 (XC)(C⁻¹β̂) = Xβ̂ 불변.

③ 능형은 깨짐: (CXᵀXC + λI)⁻¹CXᵀY = C⁻¹(XᵀX + λC⁻²)⁻¹XᵀY. 이것이 C⁻¹β̂ᴿ = C⁻¹(XᵀX + λI)⁻¹XᵀY와 같으려면 모든 cⱼ = 1이어야 한다 — λI가 C를 통과하지 못해 λC⁻²로 바뀐다. 해석: 원 단위로 보면 변수 j에만 벌점 λ/cⱼ²를 준 능형이다(라쏘는 λ/cⱼ). 노트: "그런데 이게 ridge regression에서 적용이 안 된다 … 그 결과가 설명변수가 c 배가 된다고 해서 회귀변수가 c배가 되지는 않는다."

④ 실제 문제: 단위(cm·m)라는 임의의 선택이 어떤 변수를 얼마나 줄일지를 정한다. 노트: "우리가 x에 cm와 m로 넣었을 때 예측모델의 성능이 바뀔 거라고 얘기 안 하잖아요", "괜히 작은 값 고르면 그 변수가 중요하지 않다고 생각하는 오해가 생길 수 있기 때문에." 실습 2: λ = 10 능형의 키 계수가 m 단위 1.053(거의 0으로 눌림), cm 단위 35.657(m 환산)이었고 같은 사람의 예측이 최대 6.390 달랐다. 반면 OLS는 계수 비율 100.0, 예측 차이 2.84e-14(반올림 오차).

Q31. (10점) sparse 설정과 dense 설정을 정의하고 각각에서 라쏘와 능형 중 무엇이 유리한지 이유와 함께 쓰라. 설명변수끼리 상관된 묶음이 있을 때의 라쏘의 문제와 elastic net의 처방(목적함수, α의 뜻, 비용)을 쓰고, 실제 자료에서 어느 방법을 쓸지 정하는 절차를 쓰라. [노트·판서 20:20·20:25·교재·실습]

① 정의(칠판 20:20): y = β₀ + β₁x₁ + … + βₚxₚ + ε에서 sparse는 p개 중 소수(a few)만 βⱼ ≠ 0이고 나머지는 정확히 0(노트 "딱 한두 개만 0이 아니고 나머지가 다 0인 경우. 특수 유전 질환 문제 같은 것"), dense는 거의 모든 βⱼ ≠ 0이지만 각각 작음(노트 "common variant에 영향을 받는 것. 다 조금 자잘자잘할 때").

② sparse → 라쏘: 노트 "위쪽 setting에서 작동 잘하는 것은 lasso이다. 왜냐면 lasso는 뒤에 불필요한 거는 날려 버리니까." 0인 변수를 0으로 만들고 남은 소수만 추정해 분산이 준다. 이상적으로는 참으로 0이 아닌 변수만 알고 적합한 것처럼 행동하는 oracle property("마치 신이 있다면")를 지향한다(엄밀하게는 조건부 — AI 보충).

dense → 능형: "릿지는 강제로 shrinkage를 빡 해준다. 자잘자잘한 0이니까 shrinkage하고 variance를 잡아준다." 작은 진짜 효과를 잘라 버리면 편향이 커지므로 모두 남겨 고르게 줄이는 편이 낫다. 교재 Fig 6.8(45개 모두 관련 → 능형 약간 우세), Fig 6.9(2개만 관련 → 라쏘가 편향·분산·MSE 모두 우세).
