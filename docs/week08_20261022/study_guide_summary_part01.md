### 2. 핵심 개념 정리

#### 2.1 M14–M23 복습 — adjusted R²는 2가 빠진 AIC, CV가 가장 일반적 (M14–M23, 녹음1 00:00–09:13, 판서 18:44)

출발점: "예측 관점에서 좋은 모형을 평가하는 가장 범용적인 방식은 크로스 밸리데이션"이고, CV는 계산이 K 배라 훈련오차의 bias를 보정한 AIC·BIC도 쓴다 [녹음1 00:08–01:03]. AIC = −2logL + 2d, BIC = −2logL + (log n)·d, Cp = (1/n)(RSS + 2dσ̂²), adj R² = 1 − [RSS/(n − d − 1)]/[TSS/(n − 1)]; Credit에서 BIC 4 < Cp 6 <

adj R² 7 [교재 p.210–212][슬라이드 M16–M17].

adj R² ≈ 2가 빠진 AIC(M20): TSS/(n − 1)은 고정 → RSS/(n − d − 1) 최소화와 같고, ∣x∣ ≪ 1이면 1/(1 − x) ≈ 1 + x이므로 RSS/(n(1 − d/n − 1/n)) ≈ RSS(1 + d/n) — "앞에가 2d 대신에 d밖에 없어요" [판서 18:44][노트

p.8 손글씨][녹음1 01:48–03:00]. [추가] 로그를 취하면 n·log(RSS/n) + d 대 AIC의 + 2d, 곧 모수당 벌점 1 대 2 라 더 복잡한 모형을 고른다(Credit 7 > 6). adj R²는 "이 근거가 없어요. 약간 대[략] 만든 거예요. 그럴싸하게"→ "AIC, BIC로 충분히 족하다" [노트 p.8–9][녹음1 04:24–05:47].

CV가 가장 일반적(M21): AIC·BIC는 σ²가 필요하고("이 L 안에 시그마 스퀘어가 다 있습니다") p ≫ n이면 σ̂² ≈

0이라 곤란한데, CV = (1/n)Σ Loss(yᵢ, ŷ₋ᵢ)에는 σ²가 없다 → 지금의 주된 흐름 [판서 18:44][노트 p.9][녹음1 06:20–08:49]. "그래서 뭔가 떠오르는 게 없다 [하면] 크로스 밸리데이션 하면 돼요. 그럼 틀릴 게 거의 없다."[녹음1 07:37].

#### 2.2 AIC·BIC 유도의 출발 — 설정과 KL 발산 (AB01–AB03, 녹음1 09:22–24:42, 판서 18:59)

덱 소개: 교수님이 Claude·GPT로 만든 슬라이드 — LLM 결과의 "신뢰도는 검토가 좀 필요하거나 심층[적으로] 필요한 건 사실입니다" [녹음1 09:48–12:28]. "증명과정은 여러분들이 자세하게 보시고. 저는 크게 얘기하겠습니다. AIC BIC는 굉장히 중요한 quantity입니다." [노트 p.23][녹음1 13:08–13:20].

설정: 자료는 참 밀도 g에서 i.i.d., 모형 f(·∣θ)는 "특별한 밀도 함수 하나". 참 밀도가 모형 클래스 안에 있느냐에 대한 입장 차이가 AIC와 BIC를 가른다(오지정 허용). 수학은 테일러 전개면 된다 — "그런데 그냥 용기를 내세요" [노트 p.24][녹음1 13:28–16:34][슬라이드 AB03].

KL 발산: KL(g‖f_θ) = E_g log g − E_g log f ≥ 0(같을 때만 0). "근데 이거는 자리를 바꾸면 달라[요]. 그래서 이거는 distance가 아니에요." — 대칭·삼각부등식이 없다(노트의 "항상 똑같다"·"삼각법(?)"은 받아쓰기 착오) [노트 p.24][녹음1 17:18–18:41]. 첫 항은 모든 모형에 공통이라 대수의 법칙으로 "log likelihood의 [합]이 누가 더 큰지만 비교하면 되겠죠. 그게 끝입니다." → MLE = KL 최소화 추정량, 분포족이 다른 정규 vs 감마도 (1/n)Σ log f̂로 비교 [판서 18:59][노트 p.24][녹음1 21:46–24:18].

#### 2.3 AIC — 편향 tr(J⁻¹I) → p, 그리고 해석 (AB04–AB11, 녹음1 24:42–37:49, 판서 19:24 위쪽)

문제와 목표량: "이게 MLE가 들어갔을 때도 이게 [그리로 가]냐 이거예요." [노트 p.24][녹음1 25:16] — 목표 η = E_Y E_Z[log f(Z∣θ̂(Y))], 곧 독립인 새 자료 Z에서의 기대 로그가능도; ℓ(θ̂)/n은 y를 두 번 써서 낙관적, 편향 b = E_Y[ℓ(θ̂)] − nη > 0 [슬라이드 AB05]. 노트: "expectation을 한 번 더 취해준 양이 예측 성능을 비교할 때 필요

한 양이다" [노트 p.24].

편향 = tr(J⁻¹I): J = 기대 헤시안, I = 점수의 분산. 2차 전개 두 개(E_Z log f(Z∣θ̂)를 θ₀ 주위에서, ℓ(θ₀)를 θ̂ 주위에서; 1차 항은 0)를 빼면 공유항이 지워지고 이차항 둘이 더해져 b ≈ tr(J⁻¹I), 모형이 맞으면 I = J라 = p [슬라이드 AB06–AB09][녹음1 28:29–28:56, 34:37]. "테일러 전개 2차 전개밖에 없다. 주의하세요.", "디테일은 직접 살펴보시기 바랍니다." [노트 p.25][녹음1 34:06–34:57].

기준: ℓ(θ̂) − p에 −2를 곱해 AIC = −2ℓ(θ̂) + 2p — 노트 "bias가 대략 2p 정도 됨 … 대략 -P 정도"는 로그가능도

척도 p, −2배 척도 2p라는 뜻 [노트 p.24][판서 19:24 "b → p, −2ℓₙ + 2p"][녹음1 25:44]. 오지정용 TIC = −2ℓ(θ̂)

+ 2tr(Ĵ⁻¹Î)는 "이게 생각보다 안 달라요" — 쓰는 사람이 없고, 이유를 GPT·클로드로 찾으면 "우리한테 발표해도 되게 재미있게 될 것 같습니다" [노트 p.26][녹음1 36:20–37:05][슬라이드 AB10].

해석: AIC 최소 = "Kullback–Leibler divergence 센스에서 true 모델의 제일 가까운 모델", 분포가 달라도 비교할 수 있고 true 모델이 후보에 없어도 된다. 그러나 relative criteria — "내가 비교하는 모델 전체가 garbage 안에 있다면 거기서 고른 최고 좋은 모델도 garbage일 뿐입니다", "면죄부는 아닙니다" [노트 p.26][녹음1 29:45–33:02].

#### 2.4 BIC — 사후 모형확률의 Laplace 근사 → p·log n (AB12–AB18, 녹음1 37:49–46:36)

목표: 사후확률 P(M_k∣y) ∝ p(y∣M_k)π(M_k); 사전확률은 "줄 수 없으면 다 똑같이 주면 된다" → 주변가능도 p(y∣M_k) = ∫exp{ℓ(θ) + log π(θ)}dθ를 비교 [노트 p.26–27][녹음1 37:49–39:39][슬라이드 AB13].

Laplace 근사: 지수 안을 2차 전개하면 가우스 적분 → ∣A∣^(−1/2), A ≈ nĴ("하나를 두 번 미분한 거의 n번과 비슷하다") → ∣nĴ∣ = nᵖ∣Ĵ∣ → p log n → BIC = −2ℓ(θ̂) + p log n, BIC 최소 ⟺ 사후확률 최대; 사전분포
