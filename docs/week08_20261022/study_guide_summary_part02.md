#### 2.16 시험장 점검표 — AI로 능형·라쏘를 돌릴 때 (전체판 6장)

교수님 경고(★)와 실습 결과를 시험장에서 바로 쓰도록 줄인 것이다 [추가].

| 점검 | 확인하는 법 |
| --- | --- |
| ★ 라쏘/능형(섞는 비율)을 명시하고 반복 내내 고정했나 | 코드의 Lasso·Ridge·ElasticNet(l1 ratio), glmnet(alpha = 1 라쏘, 0 능형) _ |
| ★ λ 격자가 넓고 CV 곡선이 U자인가 | "cross validated curve를 나한테 보여줘"로 곡선 확인, 최솟값이 격자 끝이면 범위 확대 [녹음2 26:36] |
| ★ 설명변수를 표준화했나 | scikit-learn은 StandardScaler 필요, glmnet은 기본 표준화 |
| ★ CV로 고른 λ로 전체 자료를 재적합했나 | LassoCV(…).fit, cv.glmnet → lambda.min(간결하게는 lambda.1se) |
| 이진 반응이면 손실과 기본 벌점 확인 | LogisticRegression()은 기본 C = 1(λ = 1/C)의 ℓ2 — 실습 6-6: 계수 1.65 → 1.52, 라쏘로지스틱은 C = 0.57에서 10개 중 8개 |

AI 사용 리포트에는 주로 쓴 프롬프트 2~3개와 위 점검(방법 고정, 격자 범위·곡선, 표준화, 재적합)을 어떻게 했는지 결과와 함께 남긴다 [녹음3 34:17][추가].

### 5. 교수님이 강조한 포인트 (녹음 기반)

받아쓰기에서 확인한 발언만 모았고, 노트·교재로 보충한 해석은 "(AI 보충)"·"(AI 판단)"으로 표시했다.

녹음 3개(총 153분: 58.8분·54.8분·39.3분)에서 교수님이 반복·강조했거나 학생에게 직접 물은 것, 그리고 시험·평가·과제·AI 사용에 관한 발언을 모았다. 시각은 각 녹음 파일의 처음을 00:00으로 한 mm:ss이고(녹음1 18:35:04, 녹음2 19:44:01, 녹음3 20:45:55 시작 — 시계 시각은 시작 시각 + mm:ss, 예: 녹음3 31:18 ≈ 21:17), 인용은 본문 초록 박스에 실린 문장과 같다(자동 받아쓰기에서 뜻이 분명한 부분만, 명백한 오기만 바로잡음; […]는 편집자 보충, "…"는 생략). 학생 말은 "(학생)"으로 구분했다. 받아쓰기 전문은 강의 폴더의 20261022-k 받아쓰기(자동).txt .
