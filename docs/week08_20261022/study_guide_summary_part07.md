Q34. ChatGPT에게 능형회귀의 λ를 CV로 골라 달라고 했더니 RidgeCV()를 써서 아래 첫 두 줄을 주며 "최적 λ = 10"이라고 했다. 넓은 격자로 다시 돌린 결과가 셋째·넷째 줄이다. (a) 첫 결과에서 무엇을 의심해야 하나 (b) 다시 돌린 결과를 해석하라 (c) AI 사용 리포트에 쓸 문장을 한두 줄로 쓰라. [실습·노트·녹음]

RidgeCV() 기본 alphas: (0.1, 1.0, 10.0) 좁은 격자 [0.1, 1.0, 10.0] -> 선택 λ = 10.0 (격자의 끝인가? True) 넓은 격자 10^-2~10^5 (60개) -> 선택 λ = 47.6 검정 MSE: OLS(λ≈0) = 60.86, 좁은 격자 λ = 51.01, 넓은 격자 λ = 45.57

(a) RidgeCV의 기본 후보는 0.1, 1, 10 세 개뿐이고 선택된 10은 그 최댓값(격자 끝)이다. CV 곡선이 λ = 10에서 아직 내려가는 중일 수 있어 진짜 최솟값은 10보다 큰 쪽에 있을 수 있다 — 교수님이 말한 "Lambda를 자기가 특정한 범위로 정해놓고 보기 시작한다 … 모델 검토를 못하면 오류가 생긴다"의 전형이며, 프로그램은 경고를 내지 않는다(녹음2 25:50 "오류라고 뜰 수가 없는"). (b) 10⁻²–10⁵ 60개로 넓히자 λ = 47.6이 격자 안쪽에서 선택되어 U자의 바닥이 잡혔다. 새 자료의 검정 MSE도 51.01 → 45.57(약 10.7% 감소)로 좋아졌고, 둘 다 OLS(60.86) 보다 낫다 — 축소 자체는 도움이 되지만 λ를 잘못 고르면 이득의 일부를 놓친다. 노트 "튜닝 파라미터의 range 를 굉장히 넓게 잡아서 U shape을 놓치지 않게 … 내려갔다 올라오면 오케이." (c) 예: "RidgeCV 기본 격자(0.1, 1, 10)에서 격자 끝 λ = 10이 선택되어, 10⁻²–10⁵ 로그 간격 60개로 넓혀 다시 실행시키고 CV 곡선의 최솟값이 격자 안쪽(λ = 47.6)임을 확인했다. 표준화(StandardScaler)가 파이프라인에 있는지도 확인했다." [근거: M29·M37, 노트 p.12, 녹음2 25:11–26:15, 실습 1]

Q35. 키(m 또는 cm)와 나이로 y를 예측했다. 아래 출력의 (a) OLS 두 줄, (b) 표준화하지 않은 능형의 키 계수 1.053과 35.657, (c) 예측값 최대 차이 6.390, (d) 마지막 줄을 각각 해석하고, AI가 Python으로 능형·라쏘를 돌렸을 때 무엇을 확인해야 하는지 쓰라. [실습·노트·교재]

OLS 키 계수: m 단위 = 35.782, cm 단위 = 0.35782, 비율 = 100.0 OLS 예측값 최대 차이 = 2.84e-14 능형(λ=10, 표준화 안 함) 키 계수: m 단위 = 1.053, cm 단위 = 0.35657 (×100 = 35.657) 능형(표준화 안 함) 예측값 최대 차이 = 6.390 능형(표준화 후) 예측값 최대 차이 = 1.42e-14

(a) 단위를 m → cm(100배)로 바꾸자 OLS 계수가 정확히 1/100이 되고 예측 차이는 2.84e-14(컴퓨터 반올림 오차)뿐 — 척도 동변(노트 손글씨 "X₁ 만약 10배 커지면 → β₁ 1/10배"). (b) m 단위에서는 같은 효과를 내려면 계수가 커야(OLS 35.782) 하므로 벌점 λβ²를 크게 받아 1.053으로 거의 0까지 눌렸다. cm 단위의 계수 0.358은 작아서 벌점이 거의 걸리지 않아 OLS(0.35782)와 거의 같은 0.35657이 나왔다(m 환산 35.657). 같은 λ인데 단위에 따라 실효 벌점이 λ/c²로 달라진 것이다. m 단위 결과만 보면 "키는 중요하지 않다"고 잘못 읽게 된다 — 노트 "괜히 작은 값 고르면 그 변수가 중요하지 않다고 생각하는 오해가 생길 수 있기 때문에". (c) 같은 사람의 예측이 단위 선택만으로 최대 6.39 달라졌다 — 노트 "x에 cm와 m로 넣었을 때 예측모델의 성능이 바뀔 거라고 얘기 안 하잖아요." (d) 표준화한 뒤 적합하면 두 단위의 예측이 다시 같아진다(1.42e-14). 확인할 것: scikit-learn은 자동 표준화를 하지 않으므로 make_pipeline(StandardScaler(), Ridge(…))처럼 표준화가 들어 있는지, CV를 파이프라인째로 하는지, 범주형 변수를 가변수로 넣었는지. R glmnet은 기본 standardize = TRUE라 원래 단위의 계수를 돌려준다. [근거: M29, 노트 p.12, 교재 p.217·식 (6.6), 실습 2]

Q36. n = 100, p = 50인 자료를 sparse(50개 중 5개만 효과)와 dense(50개 모두 작은 효과) 두 설정으로 100번씩 만들어 OLS·능형·라쏘를 비교한 출력이다. (a) 각 설정의 순위를 노트 메모와 연결해 해석하라 (b) sparse에서 라쏘가 평균 15.7개 변수를 남긴 것의 의미는? (c) 모든 값이 9보다 큰 이유와 OLS가 가장 나쁜 이유는? (d) AI가 이런 표를 주었다면 표를 믿기 전에 확인할 것은? [실습·노트·녹음]

[sparse] 100회 평균 검정 MSE (괄호: 표준오차)

OLS 18.16 (0.27)

Ridge 14.59 (0.13)

Lasso 11.03 (0.09) 라쏘가 능형보다 나은 비율 = 1.00, 라쏘가 남긴 변수 수 평균 = 15.7 / 50 [dense] 100회 평균 검정 MSE (괄호: 표준오차)

OLS 18.87 (0.32)

Ridge 13.78 (0.12)

Lasso 14.86 (0.17) 라쏘가 능형보다 나은 비율 = 0.15, 라쏘가 남긴 변수 수 평균 = 28.1 / 50 참고: 오차분산 σ² = 9.0 (어떤 방법도 이보다 작을 수 없다)

(a) sparse: 라쏘 11.03 < 능형 14.59 < OLS 18.16, 라쏘가 100번 모두 능형보다 나았다. dense: 능형 13.78 < 라쏘 14.86 < OLS 18.87, 라쏘가 이긴 비율은 15%뿐. 노트 "Sparse가 기대되면 lasso를 한다. 뭘 버려야 할지 모르겠는데 모든 게 쪼금씩 영향을 미치면 ridge가 된다"가 그대로 재현된다. 표준오차(0.09–0.32)에 비해 차이가 커서 우연으로 보기 어렵다. (b) 진짜 효과는 5개인데 CV 최적 λ(λ_min)의 라쏘는 평균 15.7개를 남겼다 — 예측에 최적인 λ는 잡음 변수도 일부 남긴다. 더 간결한 모형을 원하면 λ_1se를 쓴다. dense에서는 28.1개를 남겼는데도 작은 효과들을 잘라 내 능형보다 못했다. (c) 검정 MSE는 줄일 수 없는 오차 σ² = 9.0보다 작을 수 없다. OLS는 p = 50, n = 100이라 추정할 계수가 많아 분산이 커서 두 설정 모두 가장 나쁘다(M30의 편향–분산). (d) 반복문 안에서 매번 같은 모형(라쏘는 끝까지 라쏘)을 썼는지 — 녹음2 15:52 "3번은 라쏘로 돌리다가 4번째부터는 릿지"—, λ를 매 반복 CV로 골랐는지와 격자 범위(능형 격자를 기본값이 아닌 넓은 범위로 지정했는지), 표준화, 검정 자료가 학습과 분리됐는지, 두 설정의 생성 방식과 seed가 기록됐는지를 코드로 확인한다. [근거: M29·M31·M36, 노트 p.12–13, 녹음2 15:52, 실습 4]

Q37. 보건 자료처럼 반응이 이진(질병 유무)인 자료에 ChatGPT가 scikit-learn LogisticRegression()을 그대로 써서 "로지스틱 회귀 계수"라며 기본값 줄의 계수를 주었다. (a) 무엇이 문제인가 (b) C와 λ의 관계와 선택된 C = 0.57의 뜻은? (c) 라쏘 로지스틱이 0이 아닌 계수 8개를 남긴 것(6장: 진짜 효과는 3개)을 해석하라 (d) 프롬프트에 무엇을 명시해야 하나? [실습·노트]

기본 LogisticRegression() 설정: C = 1.0 , l1_ratio = 0.0 벌점 없음(C=inf) 계수 : [ 1.65 -1.2 0.44 0.2 -0.08 0.05 -0.12 -0.05 0.08 0.29] 기본값(C=1, ℓ2) 계수 : [ 1.52 -1.1 0.41 0.19 -0.07 0.04 -0.12 -0.04 0.07 0.27] 라쏘 로지스틱(CV로 C 선택): 선택된 C = [0.57] → λ = 1/C = [1.74] 라쏘 로지스틱 계수(표준화 척도): [ 1.38 -0.97 0.36 0.14 -0. 0. -0.08 0. 0.02 0.2 ] → 0이 아닌 계수 수 = 8

(a) LogisticRegression()은 아무것도 지정하지 않아도 C = 1.0, l1_ratio = 0.0, 곧 ℓ2(능형) 벌점이 걸린 상태다. 그래서 기본값 계수(1.52, −1.1, 0.41, …)가 벌점 없는 계수(1.65, −1.2, 0.44, …)보다 모두 0 쪽으로 작다 — "보통의로지스틱 회귀"가 아니라 능형 로지스틱이고, 그 λ도 CV로 고른 것이 아니다. 보통의 최대가능도를 원하면 C = np.inf를 지정한다. 노트 M26 "Binary data에서의 shrinkage 문제를 푸는 것임 … 거기에 해의 제약조건만 달리는 문제"처럼 손실만 로지스틱으로 바뀐 같은 축소다. (b) C = 1/λ라 C가 클수록 벌점이 약하다(벌점 크기의 방향이 반대). CV로 고른 C = 0.57은 λ ≈ 1.74의 라쏘 벌점이다. (c) 10개 중 8개가 남았고 그중 −0.08, 0.02 같은 작은 값은 잡음 변수일 가능성이 크다 — 실습 4와 같은 λ_min의 경향(예측 최적 λ는 잡음 변수도 일부 남긴다). 간결한 모형이 목적이면 1-SE 규칙을 쓴다. (d) 벌점 종류를 명시(벌점 없음 C = np.inf / 라쏘 l1_ratio = 1과 solver = "saga" / 능형), 설명변수 표준화, C(또는 λ) 격자를 넓게 잡아 CV로 고르고 CV 곡선 확인, 평가 손실(log-

### 7. 셀프 체크리스트 (괄호 = 해당 슬라이드)

**1장 · 모형 선택 복습(M01–M23)**

- [ ] 6장의 세 방법군과 공지된 시험 범위("lasso와 ridge까지")가 어디까지인지 말할 수 있다 (M02, M05, 노트 p.1)

- [ ] 최소제곱의 대안이 필요한 두 이유(예측 정확도·해석)를 p > n과 연결해 설명할 수 있다 (M03–M04)

- [ ] best subset(2ᵖ)과 forward·backward(1 + p(p+1)/2)의 모형 수와 backward의 n > p 요구를 안다 (M07–M13)

- [ ] RSS·R²로 크기가 다른 모형을 고르면 항상 완전모형이 뽑히는 이유를 안다 (M14)

- [ ] Cp·AIC·BIC 식을 쓰고, Cp와 AIC가 비례하는 조건을 안다 (M18–M19)

- [ ] BIC의 벌점 log n이 n ≥ 8에서 2보다 커서 더 작은 모형을 고르는 이유와 Credit 결과(BIC 4, Cp 6, adjusted R² 7)를 안다 (M17, M19)

- [ ] adjusted R² ≈ (RSS/n)(1 + d/n)을 유도하고 모수당 벌점 ≈ 1, "AIC BIC로 충분히 족하다"를 설명할 수 있다 (M20, 판서 18:44)

- [ ] p ≫ n에서 σ̂² ≃ 0이 되어 Cp·AIC·BIC가 무너지고 CV가 "주된 현재 흐름"인 이유를 설명할 수 있다 (M21, 판서

18:44)

- [ ] one-standard-error rule의 절차·근거와 lambda.1se의 관계를 안다 (M23)

**2장 · AIC·BIC 유도(AB01–AB18)**

- [ ] AIC가 추정하는 것(η, 기대 KL)과 BIC가 근사하는 것(주변가능도, 사후 모형확률)을 한 문장씩 말할 수 있다 (AB02, AB05, AB13)

- [ ] KL 발산의 정의, 첫 항이 상쇄되는 이유, KL이 거리가 아닌 이유를 설명할 수 있다 (AB03, 판서 18:59)

- [ ] 정규·감마처럼 분포족이 다른 모형도 AIC로 비교할 수 있는 이유와 척도 주의(야코비안)를 안다 (AB03, AB10, 판서 18:59)

- [ ] ℓ(θ̂)가 낙관적인 이유("y를 두 번 쓴다")와 편향 b의 정의를 쓸 수 있다 (AB05)

- [ ] J·I의 정의와 정보 항등식 I = J가 "2p가 나오는 곳"인 이유를 안다 (AB06)

- [ ] 두 2차 전개의 이차형식이 부호가 반대라 b ≈ tr(J⁻¹I)가 되는 흐름을 말로 설명할 수 있다 (AB07–AB11)

- [ ] 2차에서 멈추는 이유(3차 이상 O(1/√n))를 차수로 설명할 수 있다 (AB03, AB09)

- [ ] TIC·AICc의 식과 쓰는 상황(오지정, n/p < 40)을 안다 (AB10)

- [ ] "AIC는 상대적 기준"(garbage 비유)의 뜻을 설명할 수 있다 (AB10)

- [ ] Laplace 근사에서 ∣nĴ∣ = nᵖ∣Ĵ∣ → p·log n이 나오는 과정을 쓸 수 있다 (AB13–AB15)

- [ ] AIC(효율성, 과대선택 확률 0.157, LOOCV 동등)와 BIC(일치성)를 비교하고 log BF₁₂ ≈ −½(BIC₁ − BIC₂)를 계산할 수 있다 (AB16–AB17)

**3장 · 능형회귀·라쏘(M24–M39) — 시험의 중심**

- [ ] 축소가 "문제를 변환시키는 방식"(제약 → 동치인 벌점)임을 두 단계로 설명할 수 있다 (M24–M25)

- [ ] 능형·라쏘의 제약형과 벌점형을 쓰고 라그랑지안으로 연결할 수 있다 (M26, M34, 판서 19:24·19:33)

- [ ] S와 λ의 방향(S↑ ⟺ λ↓)과 λ = 0, λ → ∞의 극한을 안다 (M26–M27)

- [ ] RSS 등고선이 타원인 이유와 "처음 닿는 점이 해"를 그림으로 설명할 수 있다 (M26, M35, 판서 19:33)
