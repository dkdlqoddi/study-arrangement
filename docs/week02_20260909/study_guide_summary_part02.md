### 3. 핵심 개념 한 장 요약표

전체판 8.1의 요약표를 옮기고 쪽 나눔으로 반복된 머리행만 합쳤다. 한 줄 답은 1~7장의 교수님 말씀과 교재를 시험용으로 압축한 것[추가]이고, 원출처는 출처 열을 따른다(노트 = 강의노트 쪽수, P1/P2 슬 = Part I/II 슬라이드 번호, 교재 = ISLR 1판 쪽수).

| 질문 | 답 (시험용 한 줄) | 출처 |
|---|---|---|
| 회귀함수 f(x)는 무엇이고 왜 "최적"인가? | f(x) = E(Y\|X=x). 제곱오차 E[(Y−g(X))²\|X=x]를 모든 g 중에서 최소화하는 함수 | P1 슬7, 노트 p.18 |
| Parametric 방법의 2단계는? | ① f의 함수형 가정(예: 선형 f = β0+β1X1+…+βpXp) ② 훈련자료로 모수 추정(보통 OLS). f 추정이 p+1개 계수 추정으로 축소 | P1 슬20~21, 교재 p.21 |
| "선형"모형이 직선만 뜻하나? | 아니다. 계수에 대해 선형이면 된다. x², log x, √x, 교호항을 넣으면 곡선·곡면도 표현. 단, 그러면 "x1이 1 증가 → y가 β1 증가"식 해석은 깨진다 | 노트 p.19 |
| ML 관점에서 회귀 문제는? | Ŷ = f(x), L(y,f(x)) = (y−f(x))²의 총합(평균)을 최소화하는 f를 찾는 문제. 손실함수를 갈아 끼우면 다른 문제가 된다 | 노트 p.19, 30 |
| Non-parametric 방법의 장단점? | 함수형 가정 없음 → 넓은 형태 적합(장점). 매우 많은 관측치 필요, 고차원에서 취약(단점). 데이터가 많으면 non-parametric | P1 슬23, 노트 p.21, 교재 p.23 |
| 왜 non-parametric이 결국 선형모형처럼 표현되나? | 함수가 매끄러우면 Taylor 전개 f(x) ≈ f(0)+f'(0)x+f''(0)x²/2+…로 적절한 차수의 다항식(=선형모형)으로 근사되기 때문 | 노트 p.21 |
| KNN 회귀란? | x에서 가장 가까운 k개 관측의 y 평균으로 E(Y\|X=x)를 추정: f̂(x) = Ave(Y\|X∈N(x)). k는 hyperparameter(tuning parameter) | P1 슬25, 노트 p.22~23 |
| k가 작을 때/클 때? | k=1: 점을 잇는 지그재그(과적합, low bias·high variance). k=n: 전체 평균의 평평한 선(high bias·low variance) | 노트 p.23, 교재 p.40 |
| 차원의 저주란? | p가 크면 "가까운 이웃"이 local하지 않다. 단위 입방체에서 자료의 r 비율을 잡으려면 변의 길이 r^(1/p): r=0.1, p=2→0.32, p=3→0.46, p=10→0.79, p=100→0.98 | P1 슬26~27, 노트 p.23~24 |
| 고차원에서 거리·각도는? | 성분이 N(0,1)이면 d(X,0)≈√p, d(X,Y)≈√(2p), 두 벡터는 거의 직교(90°). LLN(과 CLT)로 설명. 모든 점이 비슷하게 멀어 이웃 평균이 부담 | P1 슬28, 노트 p.25 |
| 유연한 방법을 항상 쓰지 않는 두 이유? | ① 해석력: 선형모형의 βⱼ = 다른 변수 고정 시 Xⱼ 1단위 증가당 Y 평균 증가 ② 예측만 목적이어도 단순 모형이 더 정확할 수 있음(과적합·표본 수) | P1 슬29~30, 노트 p.26~28, 교재 p.25~26 |
| 유연성–해석력 지도 순서? | Subset selection·Lasso(해석↑) → Least squares → GAM·Trees → Bagging·Boosting → SVM(유연↑). 딥러닝은 더 오른쪽 | P1 슬31, 노트 p.27 |
| 교수님이 강조한 표본 수 이야기? | 표본 수에 따라 허용되는 모형 복잡도가 제한된다. 50~100개면 유연한 모형은 돌아가도 성능 기대 못 함. 암·희귀질환처럼 표본이 적으면 단순 모형이 잘 작동할 때가 많다 | 노트 p.28 |
| 통계학 vs ML이 보는 회귀의 차이? | Stat: βⱼ, β̂, s.e., 신뢰구간. ML: Ŷ = xβ̂(예측) | 노트 p.29 |
| 문헌을 읽을 때 가장 먼저 볼 것? | Loss function. 연구자가 어떤 오차를 줄이려 하는지, 문제를 어떻게 정의했는지가 거기 있다 | 노트 p.30 |
| MSE 정의와 training/test 구분? | MSE = (1/n)Σ(yᵢ−f̂(xᵢ))². 훈련자료로 계산하면 training MSE. 정말 중요한 것은 훈련에 쓰지 않은 (x0,y0)에 대한 test MSE = Ave(y0−f̂(x0))² | P2 슬3~4, 교재 p.29~30 |
| Generalization vs generalizability(교수님 용어)? | Generalization: 같은 분포의 자료를 나눠 훈련/시험했을 때 잘 되는 것. Generalizability: 다른 시기·다른 인구집단(2026→2027년, 한국→미국)에서도 잘 되는 것. 후자는 훨씬 어렵고 weighting·modification 전략이 필요 | 노트 p.30 |
| 유연성이 커질 때 training/test MSE? | training MSE는 단조 감소(변수를 늘리면 0까지 가능, interpolation). test MSE는 U자: 처음 감소 후 다시 증가. 최소점이 best prediction, 그 위치를 hyperparameter로 찾는 것이 과제 | P2 슬5~6, 노트 p.31~32, 교재 p.31~32 |
| Overfitting이란? | 교수님: 훈련자료를 너무 따라가 오차 ε까지 적합한 것. 교재: training MSE는 작은데 test MSE가 큰 상태, 특히 덜 유연한 모형이 더 작은 test MSE를 줬을 경우 | 노트 p.32, 교재 p.32 |
| 세 예(그림 2.9~2.11)의 교훈? | 참 f가 거의 선형이면 선형회귀가 최선, 매우 비선형이면 유연한 모형이 최선. test MSE 최소점의 유연성은 자료마다 다르다 → 실제로는 교차검증(5장)으로 추정 | P2 슬6~8, 노트 p.33, 교재 p.33 |
| Bias와 variance 정의? | Bias: 복잡한 실제 문제를 단순 모형으로 근사해 생기는 오차(유연할수록↓). Variance: 훈련자료가 바뀔 때 f̂이 변하는 정도(유연할수록↑) | P2 슬10~11, 교재 p.34~35 |
| 기대 test MSE 분해식? | E(y0−f̂(x0))² = [Bias(f̂(x0))]² + Var(f̂(x0)) + Var(ε). ε이 f̂과 독립·평균 0이라 교차항 0. test MSE는 Var(ε) 아래로 못 내려감. 교수님: "꼭 유도해 보라" | P2 슬12, 노트 p.36, 교재 p.34 |
| U자가 생기는 이유? | 유연성↑ 초기에는 bias가 variance 증가보다 빨리 줄어 test MSE↓, 이후 bias는 거의 안 줄고 variance가 크게 늘어 test MSE↑. "U shape은 universal" | 노트 p.34, 36, 교재 p.35 |
| 분류에서 정확도 척도? | Error rate = (1/n)ΣI(yᵢ≠ŷᵢ) (0-1 loss의 평균). 틀리면 1점 벌점. 미분 불가하지만 직관적. 문제 맥락에 맞는 loss를 고르는 것이 중요 | P2 슬14, 노트 p.37, 교재 p.37 |
| Bayes classifier와 Bayes error rate? | P(Y=j\|X=x0)가 가장 큰 범주로 분류(이진이면 P(Y=1\|x) > 1/2 → 1). 0-1 손실의 기대값을 최소화. 그 오류율 1−E[maxⱼP(Y=j\|X)]이 Bayes error rate(=분류판 irreducible error). 실제로는 계산 불가한 금본위. "베이즈 통계와는 상관없다" | P2 슬15~16, 노트 p.38, 교재 p.37~39 |
| 확률 추정 vs 결정경계 추정? | 확률 P(Y=1\|x)를 모형화하는 쪽(로지스틱 회귀와 그 변형) vs 경계만 찾는 쪽(SVM, 확률 해석 없음). "큰 역사의 분기점" | 노트 p.38 |
| KNN 분류란? | x0의 최근접 K개 중 범주 j의 비율로 P(Y=j\|x0)를 추정하고 다수결(k=5에서 1이 3개면 1). K가 작을수록 유연. K=1이면 훈련오류 0이지만 test error는 높을 수 있음 | P2 슬17~20, 노트 p.39, 교재 p.39~40 |
| 근본적인 그림(fundamental picture)? | 가로 모형 복잡도, 세로 예측오차. 훈련오차는 계속 감소, 시험오차는 U자(왼쪽 high bias·low variance, 오른쪽 low bias·high variance). "더 복잡한 것이 항상 더 좋지는 않다" | P2 슬21~22, 노트 p.37, 43 |
| 현대판(2019) trade-off? | Belkin 외: interpolation threshold(훈련오차 0)를 넘어 더 과모수화하면 test risk가 다시 내려가는 double descent. 교수님: "2019년에 (고전적 그림이) 깨짐, technical함" | P2 슬23, 노트 p.32, 44 |

### 4. 용어 정리

전체판 8.2의 용어표를 옮기고, 전체판에 나온 통계학↔기계학습 표현 대응을 앞에 따로 모았다.

**통계학 ↔ 기계학습 표현 대응**

| 통계학 | 기계학습 | 뜻 / 교수님 설명 | 출처 |
|---|---|---|---|
| Estimation (추정) | Training (학습) | 훈련자료로 f̂을 구하는 과정. "통계에서는 estimation을 한다고 보통 얘기합니다 … 같은 말" | 노트 p.30, 녹음2 08:26 |
| 관측치와 선 사이의 잔차(residue)를 가장 줄이는 방법(OLS) | L2 loss L(y, f(x)) = (y − f(x))²의 총합 최소화 | "계산 방식은 똑같음" | 노트 p.19~20 |
| 회귀계수의 causal meaning("x1이 1 증가하면 y가 β1 증가") | Linear model = 함수 형태를 제안하고 L2 loss를 최소화하는 방법 | ML sense에서는 계수의 의미에 "관심이 없음" | 노트 p.19 |
| 관심: βⱼ, β̂, s.e., C.I. | 관심: Ŷ = xβ̂ (예측) | 같은 회귀식을 보는 초점의 차이. "통계(하는 사람)은 β에 … 관심이 많아요" | 노트 p.29, 녹음2 00:05 |

**개념 용어**

| 용어 | 뜻 | 출처 |
|---|---|---|
| X / Y의 여러 이름 | X: feature, input, predictor, independent variable / Y: response, target, dependent variable | P1 슬4, 교재 p.15~16 |
| Training data (훈련자료) | f를 추정(train, 통계용어로 estimation)하는 데 쓰는 {(x1,y1),…,(xn,yn)} | P1 슬18, 노트 p.30, 교재 p.21 |
| Test data (시험자료) | f̂을 구할 때 쓰지 않은 새 자료 (x0,y0); 노트에서는 별표(*)로 표시 | P2 슬4, 노트 p.30 |
| Parametric / Non-parametric | f의 함수형을 가정하고 모수를 추정 / 함수형을 가정하지 않고 데이터를 따라감 | P1 슬20, 23 |
| OLS (ordinary least squares) | 잔차 제곱합을 최소화해 선형모형 계수를 구하는 가장 흔한 방법 | P1 슬21 |
| L2 loss, squared error loss | L(y,f(x)) = (y−f(x))². 회귀의 표준 손실 | 노트 p.19 |
| Loss function (손실함수) | 예측이 틀렸을 때의 벌점을 정의하는 함수. 연구자가 문제를 정의하는 곳. 문헌에서 가장 먼저 확인 | 노트 p.30, 37 |
| Hyperparameter / tuning parameter | KNN의 k, spline의 매끄러움처럼 모형 복잡도를 조절하는 값. 기분이 아니라 test MSE 최소화로 정함 | 노트 p.23, 32 |
| Neighborhood N(x) | x 근방의 관측 집합. KNN에서는 가장 가까운 k개 | P1 슬25 |
| Curse of dimensionality (차원의 저주) | p가 크면 국소 이웃이 더 이상 local하지 않고, 거리·각도가 모두 비슷해지는 현상 | P1 슬26~28, 노트 p.23~25 |
| LLN / CLT | 큰수의 법칙(표본평균→기댓값) / 중심극한정리. 교수님: "둘은 알아두라" | 노트 p.25 |
| Interpretability (해석력) | 변수 변화가 Y에 주는 효과를 사람이 읽을 수 있는 정도. 공식 정의는 없음(교수님) | P1 슬29, 노트 p.27 |
| Explainable AI, LIME | 유연한 모형의 예측을 국소적으로 설명하는 기법. LIME은 특정 점 근처에서 lasso 등 단순 모형을 적합 | 노트 p.28 |
| MSE (mean squared error) | (1/n)Σ(yᵢ−ŷᵢ)². training MSE와 test MSE를 구분 | P2 슬3, 교재 p.29 |
| Overfitting (과적합) | 오차까지 적합해 새 자료를 못 맞히는 상태; training MSE 작고 test MSE 큼 | 노트 p.32, 교재 p.32 |
| Interpolation (내삽) | f̂이 모든 훈련점을 정확히 지나 training MSE = 0이 된 상태 | 노트 p.32, P2 슬23 |
| Generalization / Generalizability | 같은 분포 안에서의 일반화 / 다른 시기·집단으로의 이전 가능성 (교수님 구분) | 노트 p.30 |
| Bias / Variance | 단순화에서 오는 체계적 오차 / 훈련자료 변화에 따른 f̂의 변동 | P2 슬10~11 |
| Irreducible error Var(ε) | f를 완벽히 알아도 남는 오차. test MSE의 하한(점선) | P2 슬6, 12, 교재 p.18, 34 |
| Error rate (오분류율) | (1/n)ΣI(yᵢ≠ŷᵢ). 0-1 loss의 평균 | P2 슬14 |
| 0-1 loss | 틀리면 1, 맞으면 0. 미분 불가. 표준적이지만 유일한 선택은 아님 | 노트 p.37 |
| Bayes classifier / Bayes decision boundary / Bayes error rate | 조건부확률 최대 범주로 분류 / P=1/2인 점들의 경계 / 그때의 최소 오류율 | P2 슬15~16, 교재 p.37~39 |
| Decision boundary | 두 범주의 예측이 갈리는 경계. SVM 등은 확률 없이 경계만 추정 | 노트 p.38 |
| KNN (K-nearest neighbors) | 회귀: 이웃 평균 / 분류: 이웃 다수결. K가 작을수록 유연 | P2 슬17, P1 슬25 |
| Double descent | 보간 임계점 이후 test risk가 다시 감소하는 현대적 현상 (Belkin 외 2019) | P2 슬23 |

### 5. 교수님이 강조한 포인트 (녹음·강의노트 기반)

녹음에서 확인된 말과 강의노트에 적힌 말을 근거로 골랐다. 녹음은 음질이 낮아 문장 전체가 또렷한 경우가 드물어 알아들은 구절만 인용했고, 시각은 각 녹음 파일 안의 위치다.

**시험·평가 관련 발언**

- 시험·평가에 대한 직접 언급(예: "시험에 낸다")은 이날 녹음 세 개에서 확인되지 않았다. 대신 교수님이 "꼭 해 보라", "알아 두라", "매우 중요", "제일 중요한 문제"처럼 강조 표현을 쓴 대목을 아래에 모았다.
- 직접 해 보라고 한 것은 bias-variance 분해 유도("연습 삼아서라도 유도를 해 보세요. 꼭 필요하다고 생각합니다."[노트 p.36])이고, 알아 두라고 한 것은 LLN과 CLT("LLN과 CLT는 알아야 함. 뭔진 알아두세요."[노트 p.25])다.
- 범위 판단에 참고할 말: P2 슬23(Belkin 외 2019)은 "약간 technical 함. 수리적이거나 통계 background 있는 사람 추천"[노트 p.44]. [추가] 논문 자체의 수식은 시험 범위로 보기 어렵고, "고전적 U자 + 현대판에서는 보간 임계점 이후 다시 감소" 한 줄 정도로 대비하면 된다.
- [추가] 수업 중 질문으로 던진 개념(overfitting의 뜻, k=5 KNN 다수결 예측)은 단답형으로, 분류에 들어가기 전에 먼저 보여 준 fundamental picture(P2 슬22)는 "그리고 설명하라"형 서술 문제로 나올 가능성이 높다.

### 6. 예상 시험 문제와 모범 답안

전체판 10장의 문제와 답안을 옮겼다. 근거 출처: [노트] 강의노트, [녹음] 녹음, [교재] ISLR, [P1/P2 슬N] 슬라이드, [추가] AI 보충(교수님 말씀 아님). 답안은 교수님·교재 표현을 우선했고, (→ 2.x)는 관련 소절이다. 답안을 가리고 먼저 풀어 본 뒤 비교하자.

#### 6.1 객관식

**M1.** 다음 중 parametric 방법의 설명으로 옳지 않은 것은? [교재 p.21~22][P1 슬20~21] (→ 2.2)

① f의 함수형을 먼저 가정한다. ② f 추정 문제가 소수의 모수 추정 문제로 축소된다. ③ 가정한 형태가 참 f와 다르면 추정이 나쁠 수 있다. ④ 정확한 추정을 위해 non-parametric보다 훨씬 많은 관측치가 필요하다.

답: ④. 많은 관측치가 필요한 것은 non-parametric의 단점(P1 슬23, 교재 p.23). ①~③은 parametric의 특징·위험(교재 p.21~22).

**M2.** 설명변수 p개가 각각 [0,1]에 균일하게 분포할 때, 전체 자료의 10%를 이웃으로 잡기 위해 각 축에서 필요한 범위의 길이는? [노트 p.24][P1 슬27] (→ 2.3)

① 0.1 ② 0.1/p ③ 0.1^(1/p) ④ 0.1^p

답: ③. 변의 길이 e에 대해 e^p = 0.1이므로 e = 0.1^(1/p). p=2에서 0.316, p=3에서 0.46, p=100에서 0.977(노트 p.24).

**M3.** 성분이 독립 N(0,1)인 p차원 벡터 X, Y에 대해 p가 매우 클 때 옳은 것은? [P1 슬28][노트 p.25] (→ 2.3)

① d(X,0) ≈ p ② d(X,Y) ≈ √p ③ X와 Y의 각은 거의 0° ④ X와 Y의 각은 거의 90°

답: ④. d(X,0) ≈ √p, d(X,Y) ≈ √(2p)이고 피타고라스 관계가 성립해 거의 직교(노트 p.25 "Root(P)는 직각삼각형의 성질을 만족", "거의 90도").

**M4.** 그림 2.7(유연성–해석력)에서 최소제곱 선형회귀보다 해석력이 높고 유연성이 낮은 것으로 표시된 방법은? [P1 슬31][교재 p.25] (→ 2.4)

① GAM ② Lasso ③ Boosting ④ SVM

답: ②. Lasso는 계수 여럿을 0으로 두어 선형회귀보다 더 제한적이고 더 해석하기 쉽다(교재 p.25).

**M5.** 모형 유연성이 커질 때 일반적으로 옳은 것은? [P2 슬5, 10~11][교재 p.32~35] (→ 2.5, 2.6)

① training MSE 증가, test MSE 감소 ② training MSE 단조 감소, test MSE는 U자 ③ bias 증가, variance 감소 ④ test MSE는 항상 단조 감소

답: ②. training MSE는 단조 감소, test MSE는 U자(교재 p.32). bias는 감소하고 variance는 증가(③은 반대).

**M6.** 기대 test MSE의 분해 E(y0−f̂(x0))² = A + B + C에서 어떤 방법으로도 줄일 수 없는 항은? [P2 슬12][교재 p.34] (→ 2.6)

① [Bias(f̂(x0))]² ② Var(f̂(x0)) ③ Var(ε) ④ 셋 다 줄일 수 있다

답: ③. Var(ε)은 irreducible error로 test MSE의 하한(교재 p.34, 그림 2.9의 점선).

**M7.** 이진 분류에서 0-1 손실의 기대값을 최소화하는 분류기는? [노트 p.38][교재 p.37] (→ 2.7)

① P(Y=1|X=x)가 가장 큰 x만 1로 분류 ② P(Y=1|X=x) > 1/2이면 1, 아니면 0 ③ 훈련자료의 1의 비율로 무작위 분류 ④ 항상 다수 범주로 분류

답: ②. Bayes classifier(교재 p.37~38). 노트 p.38 "1/2 이상이면 1이라고 예측하고 1/2 이하면 0".

**M8.** KNN 분류에서 K를 1에서 100으로 키울 때의 변화로 옳은 것은? [P2 슬20][교재 p.40] (→ 2.7)

① bias 감소, variance 증가 ② bias 증가, variance 감소 ③ 둘 다 증가 ④ 둘 다 감소

답: ②. K=1은 low bias·very high variance, K가 크면 거의 선형 경계로 low variance·high bias(교재 p.40).

**M9.** 교수님이 "문헌을 읽을 때 가장 먼저 확인하라"고 한 것은? [노트 p.30][녹음2 05:01~05:23] (→ 2.5)

① 표본 수 ② 손실함수 ③ 변수 수 ④ 소프트웨어

답: ②. "가장 먼저 확인해야 하는 것은 loss function이다. 이 사람이 어떠한 에러를 줄이려고 하는가"(노트 p.30, 녹음2 05:01~05:23).

**M10.** 다음 중 교수님의 설명과 맞지 않는 것은? [노트 p.19, 28, 38] (→ 2.2, 2.4, 2.7)

① 선형모형에는 제곱항·log 변환 항을 넣을 수 있다. ② 표본이 50개면 유연한 모형이 더 유리하다. ③ Bayes classifier는 Bayes 통계학과는 무관한 이름이다. ④ SVM은 확률 대신 결정경계를 직접 찾는다.

답: ②. "샘플 사이즈가 50개밖에 없으면 유연해도 그 50개 안에서 표현해 낼 길이 없음 … 희귀한 것에서는 심플한 모델이 작동을 잘할 때가 많음"(노트 p.28).

#### 6.2 단답형

**S1.** 회귀함수 f(x) = E(Y|X=x)가 제곱오차 기준으로 최적인 이유를 한 문장으로. [P1 슬7][추가] (→ 2.1)

답: 모든 함수 g에 대해 E[(Y−g(X))²|X=x]를 최소화하는 g(x)가 조건부 기대값이기 때문이다(완전제곱 전개에서 교차항이 0). [추가: 1차시 칠판 유도와 같은 논리]

**S2.** KNN 회귀에서 k=1과 k=n일 때 추정 곡선의 모양과 어느 쪽이 과적합인지. [노트 p.23] (→ 2.3)

답: k=1은 점을 왔다갔다 하는 지그재그(과적합), k=n(노트의 k=1000)은 모든 점에서 같은 평균이라 평평한 선(constant).

**S3.** k를 무엇이라 부르고 어떻게 정하는가. [노트 p.23, 32] (→ 2.3)

답: hyperparameter 또는 tuning parameter. 기분으로 정하지 않고, test MSE(별도 자료의 오차)가 가장 낮아지는 값을 찾는다(5장 교차검증이 그 도구 [교재 p.33]).

**S4.** p=10에서 자료의 10%를 이웃으로 쓰려면 각 축의 몇 %를 써야 하나. [노트 p.24][P1 슬27] (→ 2.3)

답: 0.1^(1/10) ≈ 0.79, 약 80%. 각 축의 80%를 쓰는 이웃은 더 이상 local이 아니므로 E(Y|X=x)를 국소 평균으로 추정한다는 정신을 잃는다(P1 슬26).

**S5.** 선형모형에서 βⱼ의 해석. [P1 슬29] (→ 2.4)

답: 다른 변수를 모두 고정했을 때 Xⱼ가 1단위 증가할 때 Y의 평균 증가량. 교호항·제곱항이 있으면 ∂f/∂xⱼ가 다른 변수 값에 따라 달라져 이 해석이 그대로 적용되지 않는다(노트 p.19).

**S6.** training MSE와 test MSE의 식과 선택 기준. [P2 슬3][교재 p.29~30] (→ 2.5)

답: training MSE = (1/n)Σᵢ(yᵢ−f̂(xᵢ))² (훈련자료), test MSE = Ave(y0−f̂(x0))² (훈련에 쓰지 않은 자료). test MSE가 가장 작은 방법을 고른다.

**S7.** 그림 2.9 오른쪽의 점선은 무엇이며 왜 그 아래로 못 가나. [P2 슬6][교재 p.32, 34] (→ 2.5, 2.6)

답: Var(ε), irreducible error. 기대 test MSE = Bias² + Var + Var(ε)이고 앞 두 항이 음수가 될 수 없으므로.

**S8.** Bias와 variance의 정의, 유연성에 따른 변화. [P2 슬10~11] (→ 2.6)

답: bias는 복잡한 실제 문제를 단순한 모형으로 근사해 생기는 오차(유연할수록 감소), variance는 훈련자료가 바뀔 때 f̂이 변하는 정도(유연할수록 증가).

**S9.** Bayes error rate의 정의와 회귀에서의 대응물. [P2 슬15][교재 p.38~39] (→ 2.7)

답: 참 조건부분포를 알 때 달성 가능한 최소 시험 오류율 1−E[maxⱼ P(Y=j|X)]. 회귀의 irreducible error에 대응. 실제 자료에서는 계산할 수 없다.

**S10.** 그림 2.14 왼쪽(K=3)에서 검은 ×의 예측과 추정 확률. [P2 슬18][교재 p.39] (→ 2.7)

답: 이웃 3개 중 파랑 2, 주황 1 → 파랑, 추정 확률 파랑 2/3, 주황 1/3.

**S11.** 고전적 그림과 double descent의 차이, interpolation threshold. [P2 슬23][노트 p.32, 44] (→ 2.7)

답: 고전적 그림은 복잡도에 따라 test risk가 U자. Belkin 외(2019)는 훈련오차가 0이 되는 interpolation threshold를 넘어 더 과모수화하면 test risk가 다시 내려가는 두 번째 하강을 보였다. 교수님: "2019년에 깨짐".

**S12.** 교수님이 "꼭 알아두라"고 한 두 정리와 그 쓰임. [노트 p.25] (→ 2.3)

답: 큰수의 법칙(LLN)과 중심극한정리(CLT). P1 슬28에서 (1/p)ΣXᵢ² → 1(LLN)로 d(X,0) ≈ √p를 얻는 데 쓴다.

#### 6.3 서술형

**E1. Parametric과 non-parametric 방법을 비교하고, 표본이 적은 희귀질환 자료에 어느 쪽이 유리한지 논하라.** [노트 p.19~21, 28][교재 p.21~24] (→ 2.2, 2.4)

모범답안: Parametric 방법은 ① f의 함수형(예: 선형)을 가정하고 ② 훈련자료로 모수를 추정(보통 OLS)한다. 장점은 f 추정이 p+1개 계수 추정으로 줄어 적은 자료로도 안정적이고 해석이 쉽다는 것, 위험은 가정한 형태가 참 f와 다르면 bias가 생긴다는 것이다[교재 p.21~22]. 교수님은 "선형"이 직선만 뜻하지 않으며 제곱항·log·root 등 변환 항으로 곡면도 표현할 수 있고, spline·kernel 같은 비선형 방법도 여기서 출발한다고 하셨다[노트 p.19]. Non-parametric 방법은 함수형을 가정하지 않고 데이터를 따라가므로 넓은 범위의 f를 적합하지만, 매우 많은 관측치가 필요하고(노트 p.21 "데이터가 많으면 non-parametric") 고차원에서는 차원의 저주로 취약하다[P1 슬23, 26]. 표본이 50~100개 수준인 희귀질환 자료에서는 "유연해도 그 안에서 표현해 낼 길이 없고" "심플한 모델이 작동을 잘할 때가 많다"[노트 p.28]. bias-variance 관점에서 표본이 적으면 유연한 모형의 variance가 커져 test MSE가 나빠지기 때문이다[추가].

**E2. 차원의 저주를 단위 입방체 예와 고차원 거리·각도 결과로 설명하고, KNN에 주는 함의를 쓰라.** [노트 p.23~25][P1 슬26~28] (→ 2.3)

모범답안: KNN은 x의 이웃 N(x)에서 y를 평균해 E(Y|X=x)를 추정한다. 분산을 낮추려면 자료의 일정 비율(예: 10%)을 평균해야 하는데, [0,1]^p 단위 입방체에서 자료의 r 비율을 담는 작은 입방체의 변 길이는 r^(1/p)이다. r=0.1일 때 p=2→0.316, p=3→0.46, p=10→약 0.8, p=100→0.977로 "전체의 10%를 덮고 싶은데 각 축의 98%를 커버해야" 하므로 local한 이웃이라는 말 자체가 성립하지 않는다[노트 p.24, P1 슬26~27]. 또 성분이 N(0,1)인 두 벡터는 LLN에 의해 d(X,0)≈√p, d(X,Y)≈√(2p)이고 피타고라스 관계가 성립해 거의 90°를 이룬다. 즉 고차원에서는 모든 점이 서로 비슷하게 멀고 직교하므로 "근처 데이터의 평균을 구하는 것에 부담을 준다"[노트 p.25, P1 슬28]. 따라서 KNN을 비롯한 거의 모든 non-parametric 방법은 p가 작을 때(p ≤ 4 정도)만 성능이 좋고, p가 크면 parametric의 힘(가정의 힘)이 필요하다[노트 p.23, 26].

**E3. training MSE와 test MSE의 관계, overfitting, 그리고 교수님이 말한 generalization과 generalizability의 차이를 설명하라.** [노트 p.30~32][녹음2 09:58~11:34][교재 p.30~32] (→ 2.5)

모범답안: 대부분의 방법은 훈련자료의 MSE가 작아지도록 설계되므로 유연성을 키우면 training MSE는 단조 감소해 변수가 충분히 많으면 0(interpolation)까지 간다. 그러나 정말 중요한 것은 훈련에 쓰지 않은 새 자료에서의 test MSE이며, 이는 처음에 줄다가 쓸모없는 변수가 추가되면서 다시 커지는 U자를 그린다[노트 p.31~32, 교재 p.31~32]. Overfitting은 훈련자료를 너무 따라가 오차 ε까지 적합한 상태로, training MSE는 작지만 test MSE는 크다[노트 p.32, 교재 p.32]. 그래서 모형 평가는 반드시 별도의 test data에서 해야 한다[노트 p.31, 37]. 교수님은 두 수준을 구분하셨다: generalization은 훈련과 시험 자료가 같은 분포에서 나왔을 때(자료를 반으로 나눌 때) 새 자료에서 잘 되는 것이고, generalizability는 학습자료와 평가자료의 분포가 다를 때(2026년 자료로 학습해 2027년에 적용, 한국 자료로 학습해 미국에서 평가) 잘 되는 것으로 훨씬 어렵고 weighting·modification 전략이 필요하다[노트 p.30, 녹음2 09:58~11:34].

**E4. x0에서의 기대 test MSE가 [Bias]² + Var + Var(ε)으로 분해됨을 유도하고, 이로부터 test MSE의 U자를 설명하라.** [노트 p.34, 36][녹음3 11:17~13:49][P2 슬12][교재 p.34~35][추가] (→ 2.6)

모범답안: Y = f(x0) + ε, E(ε)=0, Var(ε)=σ², f̂(x0)는 훈련자료에 따라 변하는 확률변수이고 ε과 독립이라 하자. m = E[f̂(x0)]라 두면 E(Y−f̂)² = E[(f−f̂)+ε]² = E(f−f̂)² + 2E[(f−f̂)ε] + σ² = E(f−f̂)² + σ² (ε이 f̂과 독립이고 평균 0이라 교차항 0). 또 E(f−f̂)² = E[(f−m)+(m−f̂)]² = (f−m)² + 2(f−m)E(m−f̂) + Var(f̂) = Bias² + Var (E(m−f̂)=0). 따라서 E(Y−f̂(x0))² = [Bias(f̂(x0))]² + Var(f̂(x0)) + σ²[추가: 교수님이 칠판에서 "빼고 더하기" 방식으로 전개(녹음3 11:17~13:49)]. 유연성을 키우면 bias는 줄고 variance는 는다. 처음에는 bias 감소가 빨라 test MSE가 내려가지만 필요한 변수가 다 들어온 뒤에는 bias는 거의 안 줄고 추정할 모수가 늘어 variance만 커지므로 test MSE가 다시 올라간다. 그래서 U자이며, 이는 f가 무엇이든 성립하는 "universal"한 결과이다[노트 p.34, 36]. Var(ε)은 어떤 방법으로도 줄일 수 없는 하한이다[교재 p.34].

**E5. 0-1 손실 아래에서 최적 분류기(Bayes classifier)를 유도하고, 그 뒤 분류 방법들이 두 갈래로 나뉜다는 교수님 설명을 쓰라.** [노트 p.38][교재 p.37~38][추가] (→ 2.7)

모범답안: 분류기 f의 risk는 R(f) = E[I(Y≠f(X))] = P(Y≠f(X))이고, 이는 x를 고정한 조건부 risk를 모든 x에 대해 평균한 것이므로 각 x에서 최소화하면 전체가 최소화된다. x에서 p = P(Y=1|X=x)라 하면 f(x)=1일 때 오류확률은 1−p, f(x)=0일 때 p이므로 r(f) = p + (1−2p)f(x). 후보 f*(x)와의 차이 r(f) − r(f*) = (1−2p)[f(x)−f*(x)]가 모든 f에 대해 0 이상이려면 p > 1/2일 때 f*(x)=1, p < 1/2일 때 f*(x)=0이어야 한다. 곧 P(Y=1|X=x) ≥ 1/2이면 1, 아니면 0으로 예측하는 것이 최적이며 이를 Bayes classifier, P = 1/2인 점들의 집합을 decision boundary라 한다[노트 p.38, 교재 p.37~38; 유도 정리는 추가]. 교수님: 이름과 달리 Bayes 통계학과는 상관없다. 이 결과 이후 연구는 둘로 갈린다. 확률 P(Y=1|x)를 추정해서 가는 쪽(logistic regression과 그 변형)과, 확률은 포기하고 결정경계만 찾는 쪽(support vector machine; 확률적 해석은 갖지 못한다)이다[노트 p.38]. KNN은 이웃의 범주 비율로 확률을 추정해 Bayes 규칙을 적용하는 유연한 근사이다[P2 슬17, 교재 p.39].

**E6. "근본적인 그림(fundamental picture)"을 그리고 설명하라. 이 그림이 2019년 이후 어떻게 수정되었는가?** [P2 슬22~23][노트 p.37, 43~44][교재 p.40~42] (→ 2.7)

모범답안: 가로축 모형 복잡도(유연성; KNN에서는 1/K), 세로축 예측오차. 훈련오차는 복잡도가 커질수록 항상 감소한다. 시험오차는 처음에는 bias 감소가 지배해 내려가다가, 이후 variance 증가가 지배해 다시 올라가는 U자를 그린다. 왼쪽 끝은 high bias·low variance(underfitting), 오른쪽 끝은 low bias·high variance(overfitting), 최적점은 그 사이[P2 슬22, 교재 p.40~42]. "더 유연하고 복잡한 것이 항상 더 좋은 것은 아니다"[P2 슬22]. 교수님은 이 그림을 분류에 들어가기 전에 먼저 보여 주며 "커브들이 이렇게 구해지는 거고 일반적인 접근 방식이 된다"고 하셨다[노트 p.37, 43]. Belkin 외(2019)는 훈련오차가 0이 되는 interpolation threshold를 넘어 과모수화를 계속하면 시험 risk가 다시 내려가는 double descent를 보였고, 교수님은 이를 "2019년에 깨짐, 하나가 더 있다"고 소개하셨다[P2 슬23, 노트 p.44].
